\begin{proof}[Proof of \cref{obj:thm:published-binary-collision-comparison}]
Fix \(\epsilon\in(0,1/2)\) and assume the published binary collision guarantee stated in the proposition.  We prove the simultaneous conclusion in three steps.

\begin{enumerate}
\item The assumed guarantee is exactly the first component of the simultaneous assertion: it supplies the stated constants \(C_\epsilon,b_\epsilon>0\) and the two displayed bias and variance bounds for every admissible \(n,d,P\), and \(\sigma_{\mathrm{bin}}\). % lean: CausalSmith.Stat.DiscreteAteHeterogeneityFrontier.published_binary_collision_comparison

\item For the pointwise algebraic comparison, fix \(n,d\in\mathbb N\) and \(\sigma\in\mathbb R\) in the stated range.  The defining order property of the minimum gives
\[
\min\{1,\min\{u_{n,d},h_{n,d,\sigma}\}\}
\le
\min\{u_{n,d},h_{n,d,\sigma}\}
\le
h_{n,d,\sigma}.
\]
This is the asserted pointwise inequality. % lean: CausalSmith.Stat.DiscreteAteHeterogeneityFrontier.published_binary_collision_comparison

\item For the asymptotic comparison, let \(d_n\) and \(\sigma_n\) satisfy the stated sequence hypotheses.  Limits along \(\mathbb N\) are unchanged by discarding finitely many initial indices, so work on the cofinal set \(n>0\).  There \(d_n>0\), and hence
\[
h_{n,d_n,\sigma_n}
=
\sigma_n^2+\frac{d_n}{n^2}
>
0.
\]
Also \(u_{n,d_n}\ge0\), \(h_{n,d_n,\sigma_n}\ge0\), and \(1\ge0\).  Therefore
\[
0
\le
\frac{\min\{1,\min\{u_{n,d_n},h_{n,d_n,\sigma_n}\}\}}
{h_{n,d_n,\sigma_n}}.
\]
The same minimum inequalities, now using the left branch of the inner minimum, give
\[
\min\{1,\min\{u_{n,d_n},h_{n,d_n,\sigma_n}\}\}
\le
\min\{u_{n,d_n},h_{n,d_n,\sigma_n}\}
\le
u_{n,d_n}.
\]
Dividing by the positive denominator \(h_{n,d_n,\sigma_n}\) yields, for all sufficiently large \(n\),
\[
0
\le
\frac{\min\{1,\min\{u_{n,d_n},h_{n,d_n,\sigma_n}\}\}}
{h_{n,d_n,\sigma_n}}
\le
\frac{u_{n,d_n}}{h_{n,d_n,\sigma_n}}.
\]
By hypothesis the right-hand side converges to \(0\), so the squeeze theorem gives
\[
\frac{\min\{1,\min\{u_{n,d_n},h_{n,d_n,\sigma_n}\}\}}
{h_{n,d_n,\sigma_n}}
\to0 .
\]
This proves the sequence comparison and completes the proof. % lean: CausalSmith.Stat.DiscreteAteHeterogeneityFrontier.published_binary_collision_comparison
\end{enumerate}
\end{proof}
