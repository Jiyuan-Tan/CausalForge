\begin{proof}[Proof of \cref{obj:lem:capped-exact-transport-package}]
Fix \(\epsilon\in(0,1/2)\).  Let \(a_\epsilon,b_\epsilon>0\) and \(N_\epsilon\in\mathbb N\) be the constants in \cref{obj:lem:zeng-binary-exact-homogeneity-lower}.  Set
\[
b_{\epsilon}^{\mathrm{ex}}:=\min\{b_\epsilon,1/2\},
\qquad
K_\epsilon:=1+N_\epsilon+\frac1{b_{\epsilon}^{\mathrm{ex}}},
\]
\[
c_{\epsilon}^{\mathrm{ex}}
:=
\min\left\{\frac{a_\epsilon b_{\epsilon}^{\mathrm{ex}}}{4},
\frac{1}{200K_\epsilon}\right\},
\qquad
N_{\epsilon}^{\mathrm{ex}}
:=
\max\left\{N_\epsilon,\left\lceil\frac1{b_{\epsilon}^{\mathrm{ex}}}\right\rceil\right\}.
\]
The two real constants have the asserted signs, and \(N_{\epsilon}^{\mathrm{ex}}\) is a natural cutoff. % lean: exists_capped_exact_transport_package

For \(n,d\ge1\), put
\[
x:=b_{\epsilon}^{\mathrm{ex}}n^2,
\qquad
d_{\mathrm{ex}}
:=
\min\{d,\max\{1,\lfloor x\rfloor\}\}.
\]
Since \(d\ge1\), immediately
\[
0<d_{\mathrm{ex}}\le d .
\]
If \(N_{\epsilon}^{\mathrm{ex}}\le n\), then \(1/b_{\epsilon}^{\mathrm{ex}}\le n\), so \(b_{\epsilon}^{\mathrm{ex}}n\ge1\).  Together with \(n\ge1\), this gives \(1\le x\), and therefore
\[
d_{\mathrm{ex}}
\le
\max\{1,\lfloor x\rfloor\}
=
\lfloor x\rfloor
\le x
=
b_{\epsilon}^{\mathrm{ex}}n^2 .
\]
% lean: capped_positive_mass_alphabet_bounds
% lean: exists_capped_exact_transport_package

It remains to construct \(L_{\mathrm{ex}}\).  First suppose
\[
N_\epsilon\le n
\qquad\text{and}\qquad
1\le x .
\]
Then
\[
d_{\mathrm{ex}}=\min\{d,\lfloor x\rfloor\}
\quad\text{and}\quad
d_{\mathrm{ex}}\le b_\epsilon n^2,
\]
because \(b_{\epsilon}^{\mathrm{ex}}\le b_\epsilon\).  Define
\[
s_{\mathrm{ex}}:=\frac1n+\frac{d_{\mathrm{ex}}}{n^2},
\qquad
L_{\mathrm{ex}}:=\frac{a_\epsilon}{2}s_{\mathrm{ex}} .
\]
The quantity \(s_{\mathrm{ex}}\) is positive.  Hence \(L_{\mathrm{ex}}\) lies strictly below
\(a_\epsilon s_{\mathrm{ex}}\), and \cref{obj:lem:zeng-binary-exact-homogeneity-lower} gives
\[
a_\epsilon s_{\mathrm{ex}}
\le
\inf_{\widehat\psi}
\sup_{R\in\mathcal H_{n,d_{\mathrm{ex}}}^{\mathrm{bin}}(\epsilon)}
\mathbb E_{Q_R^{(n)}}\!\left[
\{\widehat\psi-\psi(R)\}^2
\right].
\]
Since \(L_{\mathrm{ex}}\) is strictly below the displayed minimax lower bound, the definition of the infimum and supremum implies that every measurable estimator has some exactly homogeneous binary source law \(R\) over \(d_{\mathrm{ex}}\) cells such that
\[
L_{\mathrm{ex}}
\le
\mathbb E_{Q_R^{(n)}}\!\left[
\{\widehat\psi-\psi(R)\}^2
\right].
\]
% lean: exact_source_risk_of_binaryExact_lower

In this large-source case,
\[
\frac{b_{\epsilon}^{\mathrm{ex}}}{2}
\left\{\frac1n+\min\left(1,\frac d{n^2}\right)\right\}
\le
\frac1n+\frac{d_{\mathrm{ex}}}{n^2}.
\]
If \(d\le\lfloor x\rfloor\), then \(d_{\mathrm{ex}}=d\) and \(d/n^2\le1\).  If \(d>\lfloor x\rfloor\), then \(d_{\mathrm{ex}}=\lfloor x\rfloor\) and \(\lfloor x\rfloor\ge x/2\), so \(d_{\mathrm{ex}}/n^2\ge b_{\epsilon}^{\mathrm{ex}}/2\); together with \(b_{\epsilon}^{\mathrm{ex}}/2\le1\), this absorbs both terms on the left. % lean: half_le_natFloor_of_one_le

Since \(c_{\epsilon}^{\mathrm{ex}}\le a_\epsilon b_{\epsilon}^{\mathrm{ex}}/4\), the preceding display gives, for every \(M\in\mathbb R\),
\[
c_{\epsilon}^{\mathrm{ex}}M^2
\left\{\frac1n+\min\left(1,\frac d{n^2}\right)\right\}
\le
M^2L_{\mathrm{ex}} .
\]
% lean: exists_capped_exact_transport_package

Now consider the complementary case: either \(n<N_\epsilon\) or \(x<1\).  Define
\[
L_{\mathrm{ex}}:=\frac1{200n}.
\]
Since \(d_{\mathrm{ex}}>0\), the exact binary source class over \(d_{\mathrm{ex}}\) cells contains the following two uniform-mass endpoint laws.  In both laws the propensity is \(1/2\) in every cell and the control-arm binary mean is \(1/2\) in every cell.  Under \(R_0\), the treated-arm binary mean is \(1/2\); under \(R_1\), it is \(1/2+\delta\), where
\[
\delta:=\frac{2}{5\sqrt n},
\qquad
\delta^2=\frac{4}{25n}.
\]
The inequality \(n\ge1\) gives \(0<\delta\le2/5\), so both endpoint laws are valid binary laws with overlap \(\epsilon\) and a common cell effect.  Their source targets satisfy
\[
\psi(R_0)=0,
\qquad
\psi(R_1)=\delta .
\]
Moreover
\[
n\,\frac{(1/2)\delta^2}{(1/2)(1-1/2)}
=
\frac{8}{25}
\le \log 2,
\]
so the Bernoulli-product total-variation bound gives
\[
\operatorname{TV}\!\left(Q_{R_0}^{(n)},Q_{R_1}^{(n)}\right)\le\frac12 .
\]
The two-point testing bound therefore gives the exact-source minimax inequality
\[
\frac1{100n}
=
\frac{\delta^2}{16}
\le
\inf_{\widehat\psi}
\sup_{R\in\mathcal H_{n,d_{\mathrm{ex}}}^{\mathrm{bin}}(\epsilon)}
\mathbb E_{Q_R^{(n)}}\!\left[
\{\widehat\psi-\psi(R)\}^2
\right].
\]
Because \(1/(200n)<1/(100n)\), the same infimum-supremum argument yields: every measurable estimator has some exactly homogeneous binary source law \(R\) over \(d_{\mathrm{ex}}\) cells satisfying
\[
L_{\mathrm{ex}}
\le
\mathbb E_{Q_R^{(n)}}\!\left[
\{\widehat\psi-\psi(R)\}^2
\right].
\]
% lean: exact_source_risk_of_parametric_lower

In this fallback case,
\[
\frac1n+\min\left(1,\frac d{n^2}\right)
\le
\frac{K_\epsilon}{n}.
\]
Indeed, if \(n<N_\epsilon\), then \(N_\epsilon/n\ge1\); if \(x<1\), then \(1/(b_{\epsilon}^{\mathrm{ex}}n)\ge1\).  In either case the right side
\[
\frac{K_\epsilon}{n}
=
\frac1n+\frac{N_\epsilon}{n}
+\frac1{b_{\epsilon}^{\mathrm{ex}}n}
\]
dominates \(n^{-1}+1\), and the displayed bound follows. % lean: exists_capped_exact_transport_package

Because \(c_{\epsilon}^{\mathrm{ex}}\le 1/(200K_\epsilon)\), this gives
\[
c_{\epsilon}^{\mathrm{ex}}M^2
\left\{\frac1n+\min\left(1,\frac d{n^2}\right)\right\}
\le
M^2\frac1{200n}
=
M^2L_{\mathrm{ex}} .
\]
The two cases supply the same capped alphabet properties, the estimator-wise source risk, and the transport normalization for all \(n,d\ge1\). % lean: exists_capped_exact_transport_package
\end{proof}
