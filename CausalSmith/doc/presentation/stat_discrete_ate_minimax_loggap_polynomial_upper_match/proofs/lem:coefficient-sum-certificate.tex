\begin{proof}[Proof of \cref{obj:lem:coefficient-sum-certificate}]
All powers below have nonnegative integer exponents; in particular, the exponent \(M-2\) in the statement is interpreted as natural-number subtraction, so it equals \(0\) when \(M=1\).  Let \(T_M\) be the Chebyshev polynomial and let \(G_M\) be the polynomial continuation used in \cref{obj:def:hybrid-estimator-handle}.  The continuation has coefficients \(g_{M,j}\) satisfying
\[
T_M(1-2x)
=
1-2M^2x+2M^2x^2G_M(x).
\]
% lean: chebyshev_gPolynomial_identity

For these coefficients, the closed form is
\[
g_{M,j}
=
(-1)^j
\frac{2^{2j+3}}{M(M+j+2)}
{M+j+2\choose 2j+4}
\qquad (j\ge0).
\]
Because \(M>0\), the factor after \((-1)^j\) is nonnegative.  Hence
\[
|g_{M,j}|
=
\frac{2^{2j+3}}{M(M+j+2)}
{M+j+2\choose 2j+4}
=
(-1)^j g_{M,j},
\]
and therefore, for every \(z\),
\[
g_M^+(z)
=
\sum_{0\le j<M-1}|g_{M,j}|z^j
=
\sum_{0\le j<M-1}g_{M,j}(-z)^j
=
G_M(-z).
\]
% lean: abs_gCoefficient
% lean: sign_gCoefficient
% lean: gpos_eq

Taking \(z=1\) in this identity and substituting \(x=-1\) in the Chebyshev identity gives
\[
T_M(3)
=
1+2M^2+2M^2g_M^+(1).
\]
The sum defining \(g_M^+(1)\) is nonnegative.  Since \(M\ge1\), we have \(M^2\ge1\), and the displayed identity implies
\[
g_M^+(1)\le T_M(3).
\]
% lean: gpos_nonneg
% lean: chebyshev_gPolynomial_identity

The Chebyshev recurrence and the standard positivity bound \(T_m(x)\ge1\) for \(x\ge1\) give, at \(x=3\),
\[
T_0(3)=1,\qquad T_1(3)=3,\qquad
T_{m+2}(3)=6T_{m+1}(3)-T_m(3),\qquad T_m(3)\ge0.
\]
Induction using these facts yields
\[
T_M(3)\le 6^M.
\]
Consequently,
\[
g_M^+(1)\le 6^M.
\]
% lean: chebyshev_three_le

Now split according to \(z\).  If \(0\le z\le1\), then \(z^j\le1\) for every index in the sum, so
\[
g_M^+(z)
=
\sum_{0\le j<M-1}|g_{M,j}|z^j
\le
\sum_{0\le j<M-1}|g_{M,j}|
=
g_M^+(1)
\le 6^M
\le 6^M\max\{1,z^{M-2}\}.
\]
% lean: gpos_bound

If \(1\le z\), then every index in the finite sum satisfies \(j\le M-2\) with the same natural-number subtraction convention.  Hence \(z^j\le z^{M-2}\), and
\[
g_M^+(z)
\le
z^{M-2}\sum_{0\le j<M-1}|g_{M,j}|
=
z^{M-2}g_M^+(1)
\le
6^M z^{M-2}
\le
6^M\max\{1,z^{M-2}\}.
\]
% lean: gpos_bound

The two cases prove the claimed bound.
\end{proof}
