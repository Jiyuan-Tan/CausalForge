\begin{proof}[Proof of \cref{obj:lem:pilot-sandwich}]
Fix \(n,d,P,t\), and let \(\mu_n\) be a sample law satisfying \cref{obj:ass:iid-sampling}; thus \(\mu_n=P^{\otimes n}\). Write \(L=\log(en)\), \(m_0=|I_0|\), and \(p_k=P(X=k)\). For a category \(k\), set
\[
Z_{ik}=\mathbf 1\{X_i=k\},\qquad i\in I_0,
\]
so that
\[
N_k^{(0)}=\sum_{i\in I_0} Z_{ik}.
\]
Under \cref{obj:ass:iid-sampling}, the one-observation mean of this indicator is \(p_k\), and \(N_k^{(0)}\) is the Bernoulli count obtained from the deterministic pilot split of size \(m_0=\lfloor n/2\rfloor\). % lean: CausalSmith.Stat.DiscreteAteMinimaxLoggap.categoryIndicator_mean; CausalSmith.Stat.DiscreteAteMinimaxLoggap.pilot_count_eq_bernoulliCount

The pilot heavy and light sets used in the bad event are
\[
\widehat{\mathcal H}
=
\left\{k:\lfloor tL\rfloor<N_k^{(0)}\right\},
\qquad
\widehat{\mathcal L}=\widehat{\mathcal H}^{c}.
\]
Thus
\[
\mathcal B_t
=
\left\{
\widehat{\mathcal H}\not\subseteq\{k:p_k\ge tL/(2m_0)\}
\ \text{or}\ 
\widehat{\mathcal L}\not\subseteq\{k:p_k\le 2tL/m_0\}
\right\}.
\]
If the heavy-set condition fails, then for some \(k\),
\(p_k<tL/(2m_0)\) and \(\lfloor tL\rfloor<N_k^{(0)}\); since \(N_k^{(0)}\) is integer-valued, the latter implies \(tL<N_k^{(0)}\). If the light-set condition fails, then for some \(k\),
\(2tL/m_0<p_k\) and \(k\notin\widehat{\mathcal H}\); equivalently
\(\lfloor tL\rfloor\ge N_k^{(0)}\), which gives \(N_k^{(0)}\le tL\). Hence
\[
\mathcal B_t
\subseteq
\bigcup_{k=1}^d
\left\{p_k<\frac{tL}{2m_0},\ tL<N_k^{(0)}\right\}
\cup
\bigcup_{k=1}^d
\left\{\frac{2tL}{m_0}<p_k,\ N_k^{(0)}\le tL\right\}.
\]
% lean: CausalSmith.Stat.DiscreteAteMinimaxLoggap.pilotBadEvent_subset_cellwise

For any \(\ell\in\mathbb R\), the Bernoulli-count upper tail used here gives
\[
m_0p_k<\ell/2
\quad\Longrightarrow\quad
\mu_n\{\ell<N_k^{(0)}\}
\le
\exp\{-\ell(\log 2-1/2)\}.
\]
Applying this with \(\ell=tL\) bounds the upper-count branch whenever
\(p_k<tL/(2m_0)\). % lean: CausalSmith.Stat.DiscreteAteMinimaxLoggap.pilotCategory_upper_tail

Similarly, the lower-tail bound gives
\[
2\ell<m_0p_k
\quad\Longrightarrow\quad
\mu_n\{N_k^{(0)}\le \ell\}
\le
\exp\{-m_0p_k/8\}
\le
\exp\{-\ell/4\}.
\]
Applying this with \(\ell=tL\) bounds the lower-count branch whenever
\(2tL/m_0<p_k\). % lean: CausalSmith.Stat.DiscreteAteMinimaxLoggap.pilotCategory_lower_tail

Now fix a category \(k\). For the first cellwise event in the displayed union, either
\(p_k<tL/(2m_0)\), in which case the event is contained in \(\{tL<N_k^{(0)}\}\) and the upper-tail bound applies, or the mass inequality fails, in which case the event is empty. For the second cellwise event, either \(2tL/m_0<p_k\), in which case the event is contained in \(\{N_k^{(0)}\le tL\}\) and the lower-tail bound applies, or the mass inequality fails, in which case the event is empty. Taking the union bound over the \(d\) categories therefore yields, for \(t\ge0\), \(n\ge2\), and every \(\mu_n\) satisfying \cref{obj:ass:iid-sampling},
\[
\mu_n(\mathcal B_t)
\le
d\left[
\exp\{-(tL)(\log 2-1/2)\}
+
\exp\{-(tL)/4\}
\right].
\]
% lean: CausalSmith.Stat.DiscreteAteMinimaxLoggap.pilotBadEvent_probability

Now fix \(K>0\) and \(c>0\). Since \(\log 2-1/2>0\), set
\[
t_0
=
\max\left\{
\frac{K+4}{\log 2-1/2},\ 4(K+4)
\right\},
\qquad
C=2c,
\qquad
N=2 .
\]
For \(t\ge t_0\),
\[
K+4\le t(\log 2-1/2),
\qquad
K+4\le t/4 .
\]
Thus, whenever \(n\ge N\), \(d\le c\,nL\), and \(\mu_n\) satisfies \cref{obj:ass:iid-sampling},
\[
\begin{aligned}
\mu_n(\mathcal B_t)
&\le d\left[
e^{-(tL)(\log 2-1/2)}+e^{-(tL)/4}
\right] \\
&\le
c\,nL\cdot 2e^{-(K+4)L} \\
&\le 2c\,n^2 e^{-(K+4)L} \\
&=2c\,e^{-(K+4)}n^{-K-2} \\
&\le 2c\,n^{-K}.
\end{aligned}
\]
Here \(L\le n\) for \(n\ge1\), and
\[
e^{-qL}=e^{-q}n^{-q}
\]
has been used with \(q=K+4\), together with \(e^{-(K+4)}\le1\) and
\(n^{-K-2}\le n^{-K}\) for \(n\ge1\). This proves the arbitrary-polynomial assertion. % lean: CausalSmith.Stat.DiscreteAteMinimaxLoggap.exp_neg_mul_logScale; CausalSmith.Stat.DiscreteAteMinimaxLoggap.pilot_decay_bound; CausalSmith.Stat.DiscreteAteMinimaxLoggap.pilot_sandwich

For the fixed calibration, take \(K=4\) and \(t=256\). The numerical inequalities
\[
8\le256(\log 2-1/2),
\qquad
8\le256/4
\]
follow from \(0.6931471803<\log 2\) and elementary arithmetic. The same decay calculation gives, for every \(c>0\), the choices \(C=2c\) and \(N=2\), and hence
\[
\mu_n(\mathcal B_{256})\le Cn^{-4}.
\]
This is the stated fixed-calibration bound. % lean: CausalSmith.Stat.DiscreteAteMinimaxLoggap.pilot_sandwich; CausalSmith.Stat.DiscreteAteMinimaxLoggap.pilot_sandwich_256
\end{proof}
