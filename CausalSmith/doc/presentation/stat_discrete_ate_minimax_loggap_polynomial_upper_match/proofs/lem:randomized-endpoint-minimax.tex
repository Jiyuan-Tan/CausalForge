\begin{proof}[Proof of \cref{obj:lem:randomized-endpoint-minimax}]
\Cref{obj:lem:one-category-bernoulli-lower} gives the lower bound
\[
\frac1{100n}\le \mathsf R_{n,d,1/2}.
\]
% lean: CausalSmith.Stat.DiscreteAteMinimaxLoggap.one_category_bernoulli_lower; CausalSmith.Stat.DiscreteAteMinimaxLoggap.randomized_endpoint_minimax

For the upper bound, use the centered estimator
\[
\widehat\tau_{\mathrm{ctr}}
=
\frac1n\sum_{i=1}^n
2(2A_i-1)\left(Y_i-\frac12\right).
\]
It is measurable because the sample space is finite. Write, for a measurable estimator \(\widehat\tau\),
\[
W(\widehat\tau)
=
\sup_{P^{\otimes n}\in\mathcal E_{n,d,1/2}}
E_P\!\left[(\widehat\tau-\tau(P))^2\right].
\]
The real-valued range \(\{W(\widehat\tau):\widehat\tau\text{ measurable}\}\) is bounded below by \(0\). Indeed, if \(\mathcal E_{n,d,1/2}\) is empty, the defining supremum has the empty index set and equals \(0\). If the class is nonempty, then in the bounded-supremum case \(W(\widehat\tau)\) dominates the mean squared error at any class member, and that mean squared error is an integral of a square; in the remaining real-supremum convention branch the value is again \(0\). Hence the defining infimum for the minimax risk may be compared with the admissible estimator \(\widehat\tau_{\mathrm{ctr}}\):
\[
\mathsf R_{n,d,1/2}\le W(\widehat\tau_{\mathrm{ctr}}).
\]

It remains to bound this worst-case risk. If \(\mathcal E_{n,d,1/2}\) is empty, then \(W(\widehat\tau_{\mathrm{ctr}})=0\le 1/n\). If the class is nonempty, then for each \(P^{\otimes n}\in\mathcal E_{n,d,1/2}\), \cref{obj:lem:near-randomization-linear-upper} gives
\[
E_P\!\left[
(\widehat\tau_{\mathrm{ctr}}-\tau(P))^2
\right]
\le
\frac1n+4\left(\frac12-\frac12\right)^2
=
\frac1n .
\]
% lean: CausalSmith.Stat.DiscreteAteMinimaxLoggap.near_randomization_linear_upper
Taking the supremum over the nonempty class therefore gives
\[
W(\widehat\tau_{\mathrm{ctr}})\le \frac1n .
\]
Consequently \(\mathsf R_{n,d,1/2}\le 1/n\), and combining this with the lower bound yields
\[
\frac1{100n}\le \mathsf R_{n,d,1/2}\le \frac1n .
\]
% lean: CausalSmith.Stat.DiscreteAteMinimaxLoggap.randomized_endpoint_minimax
\end{proof}
