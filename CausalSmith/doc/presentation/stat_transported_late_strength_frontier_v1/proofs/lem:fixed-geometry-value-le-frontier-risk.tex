\begin{proof}[Proof of \cref{obj:lem:fixed-geometry-value-le-frontier-risk}]
Fix an oracle-honest sequence \(C=(C_n)\in\mathfrak C^{\mathrm{or}}\).  Let \(\widetilde C\) be the same oracle procedure evaluated with the fixed geometry \(\mathfrak g\):
\[
\widetilde C_n\bigl((O_i^S)_{i=1}^n,(X_j^T)_{j=1}^{N_n}\bigr)
=
C_n\bigl((O_i^S)_{i=1}^n,(X_j^T)_{j=1}^{N_n},w,e\bigr),
\]
where \(w,e\) are the \(n\)th weight and propensity components of \(\mathfrak g\).  If \(P\in\mathcal P_n(\mathfrak g)\), then \(P\in\mathcal P_n\), the propensity input equals the \(n\)th geometry propensity, and the \(n\)th geometry weight is source-almost surely a valid transport-weight version for \(P\), by \cref{obj:def:fixed-geometry-slice}.  The oracle procedure is evaluated on admissible transport-weight versions modulo source-null changes, so under the two-sample law generated by such a \(P\),
\[
\mathbf 1\{\theta_T\in \widetilde C_n\}=\mathbf 1\{\theta_T\in C_n\},
\qquad
\lambda(\widetilde C_n)=\lambda(C_n)
\quad P\text{-a.s.}
\]
Consequently, for every \(P\in\mathcal P_n(\mathfrak g)\),
\[
P\{\theta_T\in \widetilde C_n\}=P\{\theta_T\in C_n\},
\qquad
\mathbb E_P[\lambda(\widetilde C_n)]=\mathbb E_P[\lambda(C_n)].
\]
% lean: OracleHonest.fixedGeometry

By \cref{obj:lem:fixed-geometry-slice-inhabited}, for all sufficiently large \(n\) there exists \(P_0\in\mathcal P_n(\mathfrak g)\) with \(t_n(P_0)\ge t_0\).  Hence the fixed-geometry slice and the global class are inhabited on those rows.  On such rows, the preceding coverage identity and the inclusion \(\mathcal P_n(\mathfrak g)\subseteq\mathcal P_n\) give
\[
\inf_{P\in\mathcal P_n}P\{\theta_T\in C_n\}
\le
\inf_{P\in\mathcal P_n(\mathfrak g)}P\{\theta_T\in \widetilde C_n\}.
\]
The same nonempty-row reduction gives the bounds used to pass this comparison to liminf:
\[
0\le \inf_{P\in\mathcal P_n}P\{\theta_T\in C_n\},
\qquad
\inf_{P\in\mathcal P_n(\mathfrak g)}P\{\theta_T\in \widetilde C_n\}\le 1
\]
for all sufficiently large \(n\), since coverage probabilities lie in \([0,1]\).  Therefore the eventual row comparison yields
\[
\liminf_{n\to\infty}
\inf_{P\in\mathcal P_n(\mathfrak g)}
P\{\theta_T\in \widetilde C_n\}
\ge
\liminf_{n\to\infty}
\inf_{P\in\mathcal P_n}
P\{\theta_T\in C_n\}
\ge 1-\alpha,
\]
and the \(0<\alpha<1\) clauses are inherited from \(C\in\mathfrak C^{\mathrm{or}}\).  Thus \(\widetilde C\in\mathfrak C^{\mathrm{or}}(\mathfrak g)\) by \cref{obj:def:fixed-geometry-honesty}. % lean: OracleHonest.fixedGeometry

The eventual strength-restricted fixed-geometry rows are also nonempty by \cref{obj:lem:fixed-geometry-slice-inhabited}.  On those rows, the expected-length identity and the inclusion of the fixed slice into the global class give
\[
\sup_{P\in\mathcal P_n(\mathfrak g):\,t_n(P)\ge t_0}
\mathbb E_P[\lambda(\widetilde C_n)]
\le
\sup_{P\in\mathcal P_n:\,t_n(P)\ge t_0}
\mathbb E_P[\lambda(C_n)].
\]
For every set \(A\subseteq\Theta=[-1,1]\), the restricted length satisfies \(0\le\lambda(A)\le2\).  For the displayed real suprema over strength-restricted rows, an empty indexing set gives the real supremum of the empty set, which is \(0\); on nonempty rows, the same length bound makes each fixed-geometry row nonnegative and each global row bounded above by \(2\).  These bounds are the hypotheses needed to pass the eventual row comparison through limsup, so
\[
\limsup_{n\to\infty}
\sup_{P\in\mathcal P_n(\mathfrak g):\,t_n(P)\ge t_0}
\mathbb E_P[\lambda(\widetilde C_n)]
\le
R((C_n),t_0).
\]
% lean: OracleHonest.fixedGeometry

It remains to take the infimum over fixed-geometry honest procedures.  For any oracle procedure \(E\), the same real-supremum convention and the bound \(0\le\lambda(A)\le2\) imply that each strength-restricted fixed-geometry risk row for \(E\) lies in \([0,2]\), and hence
\[
0\le
\limsup_{n\to\infty}
\sup_{P\in\mathcal P_n(\mathfrak g):\,t_n(P)\ge t_0}
\mathbb E_P[\lambda(E_n)].
\]
Thus the collection of fixed-geometry risks over \(\mathfrak C^{\mathrm{or}}(\mathfrak g)\) is bounded below by \(0\).  Since the constructed \(\widetilde C\) belongs to \(\mathfrak C^{\mathrm{or}}(\mathfrak g)\), \cref{obj:def:fixed-geometry-value} gives
\[
V_{\mathfrak g}^\star(t_0)
\le
\limsup_{n\to\infty}
\sup_{P\in\mathcal P_n(\mathfrak g):\,t_n(P)\ge t_0}
\mathbb E_P[\lambda(\widetilde C_n)].
\]
Combining this inequality with the preceding risk comparison gives
\[
V_{\mathfrak g}^\star(t_0)\le R((C_n),t_0).
\]
% lean: fixedGeometryValue_le_frontierRisk
\end{proof}
