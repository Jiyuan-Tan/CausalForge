\begin{proof}[Proof of \cref{obj:lem:exact-risk-envelope-upper}]
Write \(s=\sigma_0^2/n\), where division by \(n\) is real division by the natural cast of \(n\) used in the real-valued risk definitions; when \(n=0\), this quotient is the total real quotient and equals \(0\). Since \(\sigma_0^2\ge0\) and \((n:\mathbb R)\ge0\), we have \(s\ge0\). By \cref{obj:def:exact-nested-risk}, \(\Gamma_P(p)\) is the design covariance matrix of \((\bar Y_0,\ldots,\bar Y_k)\), so that for every weight vector \(w\)
\[
w^\prime\Gamma_P(p)w
=
\operatorname{Var}_\pi\!\left(\sum_{j=0}^k w_j\bar Y_j\right).
\]
All infima and suprema below are the real-valued operations appearing in \cref{obj:def:exact-nested-risk} and \cref{obj:def:amplification-criterion}. Thus an empty law-value supremum has value \(0\), and if every element of a law-value set is at most a nonnegative number \(B\), then its supremum is at most \(B\).

\emph{An order-theoretic comparison of infima.}
Both assertions use the following elementary fact for these real-valued infima. Let \(F,G\subseteq\mathbb R\), let \(c\ge0\), suppose \(F\) is nonempty and bounded below and \(G\) is nonempty, and suppose that
\[
\text{for every }g\in G\text{ there is }f\in F\text{ with } f\le c\,g .
\]
Then
\[
\inf F\le c\,\inf G .
\]
Indeed, scalar multiplication by \(c\ge0\) commutes with the real-valued infimum in the form \(c\inf G=\inf\{c\,g:g\in G\}\). Since \(F\) is nonempty and bounded below, \(\inf F\) is a lower bound for \(F\). For each \(g\in G\), the witness \(f\in F\) gives \(\inf F\le f\le c\,g\), so \(\inf F\) is a lower bound for \(\{c\,g:g\in G\}\). Hence \(\inf F\le\inf\{c\,g:g\in G\}=c\inf G\). % lean: sInf_le_mul_sInf_of_forall_exists_le

\emph{Step 1: the fixed-schedule bound for every admissible schedule.}
Fix any \(p'\in S_{k,q}\) and apply the fact with \(c=s\) and
\[
F=\left\{
\sup_{P\in\mathcal P_\beta}
\operatorname{Var}_\pi\!\left(\sum_{j=0}^k w_j\bar Y_j\right):
w\in W_\beta(p')
\right\},
\qquad
G=\left\{
\left(\sum_{j=0}^k |w_j|\right)^2:
w\in W_\beta(p')
\right\}.
\]
Since \(\beta\ge1\), \(k\ge\beta\), and \(p'\in S_{k,q}\), \cref{obj:lem:unbiased-weight-set-nonempty} supplies some \(w\in W_\beta(p')\), so both \(F\) and \(G\) are nonempty. % lean: unbiased_weight_set_nonempty
Moreover \(F\) is bounded below by \(0\): every element of each law-value set is a design variance, hence is nonnegative, and the real-valued supremum of such a set is nonnegative, including the empty case. % lean: fixedRisk_nonneg
For the link condition, take \(g=\left(\sum_j|w_j|\right)^2\in G\) and let \(f\in F\) be the element indexed by the same \(w\). For every law value appearing in this supremum, \cref{obj:def:rollout-law-class} gives the round-mean variance envelope for \(\bar Y_0,\ldots,\bar Y_k\) with scale \(\sigma_0^2/n\). Hence \cref{obj:lem:variance-envelope-sharpness} gives
\[
\operatorname{Var}_\pi\!\left(\sum_{j=0}^k w_j\bar Y_j\right)
\le
s\left(\sum_{j=0}^k |w_j|\right)^2 .
\]
The right-hand side is independent of the law value and is nonnegative, so the real-valued supremum over the law-value set is at most this same quantity. Thus \(f\le s\,g\). % lean: variance_envelope_sharpness
The fact therefore applies, and since \(\inf G=A_\beta(p')\) by \cref{obj:def:amplification-criterion},
\[
\inf_{w\in W_\beta(p')}
\sup_{P\in\mathcal P_\beta}
w^\prime\Gamma_P(p')w
\le
s\,
\inf_{w\in W_\beta(p')}
\left(\sum_{j=0}^k |w_j|\right)^2
=
\frac{\sigma_0^2}{n}A_\beta(p').
\]
Applying this to the given schedule \(p\) proves the first assertion,
\[
\inf_{w\in W_\beta(p)}
\sup_{P\in\mathcal P_\beta}
w^\prime\Gamma_P(p)w
\le
\frac{\sigma_0^2}{n}A_\beta(p).
\]
% lean: exact_risk_envelope_upper

\emph{Step 2: passing to the nested risk.}
Apply the same fact a second time, now with \(c=s\) and
\[
F=\left\{
\inf_{w\in W_\beta(p')}
\sup_{P\in\mathcal P_\beta}
w^\prime\Gamma_P(p')w:
p'\in S_{k,q}
\right\},
\qquad
G=\left\{A_\beta(p'):p'\in S_{k,q}\right\}.
\]
By \cref{obj:def:exact-nested-risk} and \cref{obj:def:amplification-criterion}, \(\inf F=R_{\mathrm{exact}}(\beta,k,q)\) and \(\inf G=M_{\beta,k,q}\). Both sets are nonempty because the given schedule satisfies \(p\in S_{k,q}\). The set \(F\) is bounded below by \(0\): for each schedule \(p'\), every fixed-weight law supremum is nonnegative by the preceding nonnegativity argument, and the corresponding real-valued infimum over weights is therefore nonnegative. The link condition is exactly the fixed-schedule bound from Step 1: for \(g=A_\beta(p')\), take the element of \(F\) indexed by the same \(p'\). Hence
\[
R_{\mathrm{exact}}(\beta,k,q)
\le
\frac{\sigma_0^2}{n}
\inf_{p'\in S_{k,q}} A_\beta(p')
=
\frac{\sigma_0^2}{n}M_{\beta,k,q}.
\]
% lean: sInf_le_mul_sInf_of_forall_exists_le
\end{proof}
