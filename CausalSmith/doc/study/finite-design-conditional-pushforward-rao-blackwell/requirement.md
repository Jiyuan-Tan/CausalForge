# Substrate requirement: finite-design-conditional-pushforward-rao-blackwell

## Goal

Build conditional expectation along a deterministic pushforward of an arbitrary finite design, with zero-fiber guards, disintegration, range preservation, and covariate-parametric squared-loss contraction.

## Provides (API contract)

- `fiberMass D φ b`, the mass of a fiber of `φ : Ω → B` under an arbitrary `FiniteDesign Ω`, with a theorem identifying it with `(D.map φ).p b`.
- `conditionalMeanAlongMap D φ d h b v`, the guarded weighted conditional mean of `h ω v` on the fiber `φ ω = b`, returning default `d` on zero-mass fibers.
- Nonnegativity and normalization of the conditional fiber weights on positive-mass fibers, plus exact finite-sum/fiber disintegration and an `E_map`-compatible rewrite.
- `conditionalMeanAlongMap_mem_Icc`, preserving a closed real interval when the default and every source value lie in that interval.
- `E_map_conditionalMeanAlongMap_sq_le`, the covariate-parametric squared-loss Jensen/Rao--Blackwell contraction for arbitrary finite-design weights.
- If natural, a small action/minimax-compatible corollary; the core API must not require uniformity, independence, or positive mass for every fiber.

## Statement / milestones

For finite types `Ω`, `B`, and `V`, an arbitrary `D : FiniteDesign Ω`, a deterministic map `φ : Ω → B`, a default `d : ℝ`, and `h : Ω → V → ℝ`, define

`fiberMass D φ b = ∑ ω, if φ ω = b then D.p ω else 0`

and

`conditionalMeanAlongMap D φ d h b v = if fiberMass D φ b = 0 then d else (∑ ω, if φ ω = b then D.p ω * h ω v else 0) / fiberMass D φ b`.

Prove `fiberMass D φ b = (D.map φ).p b`, nonnegativity, positive-fiber normalization, zero-fiber numerator vanishing, and exact expectation disintegration.

The load-bearing theorem is:

```lean
theorem E_map_conditionalMeanAlongMap_sq_le
    (D : FiniteDesign Ω) (φ : Ω → B) (d : ℝ)
    (h : Ω → V → ℝ) (v : B → V) (t : ℝ) :
  (D.map φ).E (fun b =>
      (conditionalMeanAlongMap D φ d h b (v b) - t) ^ 2) ≤
    D.E (fun ω => (h ω (v (φ ω)) - t) ^ 2)
```

The default is irrelevant on zero-mass fibers. Prove the result by finite weighted square completion/Jensen after fiber disintegration, not by assuming equal weights.

Also prove the range companion, pointwise in `b` and `v`:

```lean
theorem conditionalMeanAlongMap_mem_Icc
    {l u : ℝ} (hd : d ∈ Set.Icc l u)
    (hh : ∀ ω v, h ω v ∈ Set.Icc l u) :
  conditionalMeanAlongMap D φ d h b v ∈ Set.Icc l u
```

## Standard reference

This is finite conditional expectation with respect to the sigma-field generated by a deterministic statistic, followed by conditional Jensen's inequality for the convex squared-loss function. In finite spaces it is weighted fiber averaging and elementary square completion.

## Intended reuse

The immediate consumer pushes an arbitrary, possibly dependent finite assignment law through a sign-group map while retaining an observed-data covariate. It needs a schedule-independent estimator obtained by conditioning over latent assignments and fair inactive-arm coins. The same API should apply to arbitrary finite randomized designs and deterministic coarsenings.

## May assume / must derive

May assume only finite carrier types and a valid `FiniteDesign`; `D.p_nonneg`, `D.p_sum`, `FiniteDesign.map`, and `FiniteDesign.E_map` may be reused.

Must derive fiber-mass/pushforward equality, positive-fiber normalization, zero-fiber safety, disintegration, interval preservation, and the squared-loss contraction for arbitrary nonnegative design weights. Must not assume uniformity, independence, surjectivity of `φ`, or positive mass of every fiber.
