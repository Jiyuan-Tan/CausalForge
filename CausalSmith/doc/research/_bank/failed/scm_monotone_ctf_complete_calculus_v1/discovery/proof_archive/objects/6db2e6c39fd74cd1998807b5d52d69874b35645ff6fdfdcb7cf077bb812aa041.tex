For a finite binary unnested conditional query whose numerator is the single literal \(L\), define the signed order closure of the conditioning conjunction \(B_Q\) as follows.  For each response variable \(W\), sign-normalize its monotone-parent assignment \(t\), hold its nonmonotone-parent assignment \(s\) fixed, and repeatedly apply
\[
 W_{t,s}=1,\ t\le t'
 \quad\Longrightarrow\quad W_{t',s}=1,
 \qquad
 W_{t,s}=0,\ t'\le t
 \quad\Longrightarrow\quad W_{t',s}=0.
\tag{1}
\]
Starting with all literals in \(B_Q\), the fixed point is denoted \(\operatorname{cl}_M(B_Q)\).  The order-closure precheck \(\mathsf{MID}^{+}\) returns the constant one if \(L\in\operatorname{cl}_M(B_Q)\), returns the constant zero if the complementary literal \(\overline L\in\operatorname{cl}_M(B_Q)\), and otherwise runs \(\mathsf{MID}(G,M,\mathcal Z,Q)\).  On a positive-denominator input the first two cases cannot conflict.  There are at most
\[
 2\sum_{v\in V}2^{|\operatorname{pa}_G(v)|}
\]
distinct binary full-parent response literals, so fixed-point saturation terminates after at most that many distinct insertions.
