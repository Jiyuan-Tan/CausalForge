Given the encoded oracle family \(\mathbf M\), write \(S_0(\mathbf M)=E(\mathcal M^{(0)})\) for its observational adjacency set.  For a directed acyclic graph \(E\) on \(V\) and a set \(A\subseteq V\), define
\[
B(E,A)=\left\{\{i,j\}\in\binom V2:
i\to j\in E\ \text{or}\ j\to i\in E\ \text{or}\
\exists c\in A:\ i\to c\leftarrow j\ \text{in }E
\right\}.
\]
An input-conditioned normalized Dai two-section certificate is
\[
\mathcal R_{\mathbf M}=\bigl(E,A,Q_{\mathbf M}(E,A),(T_k)_{k\in\mathcal K_+}\bigr),
\qquad
Q_{\mathbf M}(E,A)=S_0(\mathbf M)\setminus B(E,A),
\]
where \(\operatorname{an}_E(A)=A\), \(B(E,A)\subseteq S_0(\mathbf M)\), \(Q_{\mathbf M}(E,A)\subseteq\binom A2\), and \(T_k\subseteq V\) for every \(k\in\mathcal K_+\); set \(T_0=\varnothing\).  Thus \(Q_{\mathbf M}(E,A)\) is uniquely derived from \((\mathbf M,E,A)\) and is not an independently enumerated coordinate.  It records exactly those supplied observational adjacencies not already generated by a basal edge or by an observed collider child in \(A\).
