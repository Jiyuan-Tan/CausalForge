\textbf{Proof.}
Fix \(\eta\in\mathfrak C_D(\mathbf M)\).  Write
\[
E=\mathcal G_\eta[V],\qquad
U_\eta=\bigcup_{s\in S_\eta}\operatorname{pa}_{\mathcal G_\eta}(s),\qquad
A=\operatorname{an}_E(U_\eta),
\]
and define \(Q\) and \((T_k)_{k\in\mathcal K_+}\) as in the statement.  By \(\operatorname{ass{:}selection\text{-}parents}\), \(U_\eta\subseteq V\).  Hence \(A\subseteq V\), and idempotence of the ancestor operator gives
\[
\operatorname{an}_E(A)
=\operatorname{an}_E\!\bigl(\operatorname{an}_E(U_\eta)\bigr)
=\operatorname{an}_E(U_\eta)
=A.
\]
If \(\{i,j\}\in Q\), then \(i,j\in U_\eta\subseteq A\); therefore \(Q\subseteq\binom A2\).  The restriction of the finite DAG \(\mathcal G_\eta\) to \(V\) is the DAG \(E\), and each \(T_k=I_\eta^{(k)}\) is a subset of \(V\).  Thus \(\mathcal R_\eta=(E,A,Q,(T_k))\) satisfies every clause of \(\texttt{def:normalized-dai-certificate}\).

Construct \(\bar\eta\) by retaining \(E\) and the ordered target family, adding one binary childless selection node \(s_{ij}\) with parent set \(\{i,j\}\) for each \(\{i,j\}\in Q\), and adding one binary childless node \(s_i\) with parent set \(\{i\}\) for each \(i\in A\) whose degree in \(Q\) is zero.  No node is added for the empty parent set.  Let \(U_{\bar\eta}\) be the union of these reconstructed parent sets.  Every vertex incident to an edge of \(Q\) occurs in a pair parent set, while every remaining vertex of \(A\) occurs in its singleton parent set.  Since \(Q\subseteq\binom A2\), this proves
\[
U_{\bar\eta}=A,
\qquad
\operatorname{an}_E(U_{\bar\eta})=\operatorname{an}_E(A)=A.
\]
Two distinct observed vertices share a reconstructed selection child exactly when their unordered pair is an edge of \(Q\); singleton nodes introduce no such pair.  Thus the reconstructed two-section is exactly \(Q\).

The reconstruction is finite and acyclic because the new vertices are childless.  It preserves causal sufficiency on \(V\), and the new selection vertices are binary, childless, and have only observed parents.  The selected stratum, basal pre-treatment timing, empty observational target, and soft-intervention modularity are inherited with the unchanged ordered targets.  If a probabilistic realization of the selected stratum is required, assign each new binary selection node a parent-dependent conditional probability strictly between zero and one; finiteness then makes the joint selected event positive.  This is a witness choice, not an additional class assumption.

The two candidates have the same \(E\), \(A\), \(Q\), and \((T_k)\).  By \(\texttt{lem:dai-two-section-checker-characterization}\), selection enters every observational adjacency, intervention-induced path adjacency, indicator adjacency, and endpoint orientation only through \(A\) and \(Q\).  Consequently,
\[
\mathcal M_{\bar\eta}^{(k)}=\mathcal M_\eta^{(k)}
\qquad(k\in\mathcal K).
\]
Because \(\eta\) matches the supplied regime representatives, \(\bar\eta\) does as well, and hence \(\bar\eta\in\mathfrak C_D(\mathbf M)\).

Conversely, start with any normalized \(\mathcal R=(E,A,Q,(T_k))\) and apply the same reconstruction.  The two identities above show that its ancestrally selected set is exactly \(A\) and its selection two-section is exactly \(Q\), so its summary is \(\mathcal R\).  It uses \(|Q|\) pair-parent nodes and at most \(|A|\) singleton-parent nodes, whence
\[
|S_{\bar\eta}|\le |Q|+|A|\le\binom D2+D.
\]
The empty cases \(A=\varnothing\) and \(Q=\varnothing\) are covered by the same construction.  No overlap, rank, inverse, or division condition is used. \(\square\)
