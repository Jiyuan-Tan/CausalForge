Enumerate in a fixed lexicographic order all triples \((E,A,(T_k)_{k\in\mathcal K_+})\), where every unordered vertex pair has one of the three basal states absent, oriented one way, or oriented the other way, \(A\subseteq V\), and \(T_k\subseteq V\).  Reject cyclic \(E\), non-ancestor-closed \(A\), and every candidate failing \(B(E,A)\subseteq S_0(\mathbf M)\) or \(Q_{\mathbf M}(E,A)=S_0(\mathbf M)\setminus B(E,A)\subseteq\binom A2\).  For each survivor form the unique input-conditioned certificate
\[
\mathcal R_{\mathbf M}=\bigl(E,A,Q_{\mathbf M}(E,A),(T_k)_{k\in\mathcal K_+}\bigr)
\]
and retain it precisely when \(\operatorname{Check}_{D}(\mathcal R_{\mathbf M},\mathbf M)=1\).  Thus \(Q_{\mathbf M}(E,A)\) is computed and never independently enumerated.  If no certificate passes, return \(\mathsf{incompatible}\).  Otherwise, for every \(e=(k,u;uv)\in\mathcal E(\mathbf M)\), form
\[
B_e(\mathbf M)=\left\{\operatorname{mark}_e\bigl(\mathcal N^{(k)}(\mathcal R_{\mathbf M})\bigr):
\operatorname{Check}_{D}(\mathcal R_{\mathbf M},\mathbf M)=1\right\}
\subseteq\{\mathrm{tail},\mathrm{arrow}\}.
\]
Set the output mark at \(e\) to the unique element when \(B_e(\mathbf M)\) is a singleton and to a circle when it contains both marks.  For every circle, retain the first accepted tail certificate and the first accepted arrowhead certificate.  Define \(\operatorname{CDIS}^{\mathrm{cmp}}(\mathbf M)\) to be this partial-graph family together with those coupled certificates.  Its observational component is on \(V\); only a component indexed by \(k\in\mathcal K_+\) is on \(V\cup\{\zeta_k\}\).
