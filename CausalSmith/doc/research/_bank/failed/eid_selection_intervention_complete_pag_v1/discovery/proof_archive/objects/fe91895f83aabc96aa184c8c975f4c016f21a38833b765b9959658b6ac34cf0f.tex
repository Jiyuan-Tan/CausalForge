\textbf{Proof.}
Fix \(\eta\in\mathfrak C_D(\mathbf M)\), and put
\[
E=\mathcal G_\eta[V],
\qquad
U_\eta=\bigcup_{s\in S_\eta}\operatorname{pa}_{\mathcal G_\eta}(s),
\qquad
A=\operatorname{an}_E(U_\eta).
\]
By \(\operatorname{ass{:}selection\text{-}parents}\), \(U_\eta\subseteq V\).  Hence \(A\subseteq V\), and idempotence of the ancestor operator gives
\[
\operatorname{an}_E(A)
=\operatorname{an}_E\!\bigl(\operatorname{an}_E(U_\eta)\bigr)
=A.
\]
Because \(\mathcal G_\eta\) is a finite DAG, its restriction \(E\) is a DAG.  If \(\{i,j\}\in Q_\eta\), then \(i,j\in U_\eta\subseteq A\), so
\[
Q_\eta\subseteq\binom A2.
\]

Let \(S_0(\mathbf M)=E(\mathcal M^{(0)})\).  By the observational adjacency formula in \(\texttt{lem:dai-two-section-checker-characterization}\), the observational projection of \(\eta\) has adjacency set
\[
B(E,A)\cup Q_\eta.
\]
Membership \(\eta\in\mathfrak C_D(\mathbf M)\) and the observational-equivalence-match clause incorporated in \(\texttt{def:dai-compatible-class}\) imply equality of observational adjacency sets.  Therefore
\[
B(E,A)\cup Q_\eta=S_0(\mathbf M).
\]
In particular, \(B(E,A)\subseteq S_0(\mathbf M)\), and elementary set algebra yields
\[
Q_{\mathbf M}(E,A)
=S_0(\mathbf M)\setminus B(E,A)
\subseteq Q_\eta
\subseteq\binom A2.
\]
Together with \(T_k=I_\eta^{(k)}\subseteq V\), these identities verify every condition in \(\texttt{def:normalized-dai-certificate}\), so \(\mathcal R_\eta^*\) is input-conditioned normalized.

Write \(Q^*=Q_{\mathbf M}(E,A)\).  Construct \(\bar\eta\) by retaining \(E\) and the ordered target family, adding one binary childless selection node with parent set \(\{i,j\}\) for every \(\{i,j\}\in Q^*\), and adding one binary childless selection node with parent set \(\{i\}\) for every vertex \(i\in A\) of degree zero in \(Q^*\).  No node is added for an empty parent set.  The union \(U_{\bar\eta}\) of the reconstructed parent sets is exactly \(A\): every nonisolated vertex occurs in a pair parent set and every isolated vertex occurs in its singleton parent set.  Consequently,
\[
\operatorname{an}_E(U_{\bar\eta})
=\operatorname{an}_E(A)=A,
\]
and two distinct vertices share a reconstructed selection child exactly when their pair is in \(Q^*\).

The observational skeleton is unchanged because
\[
B(E,A)\cup Q^*
=B(E,A)\cup\bigl(S_0(\mathbf M)\setminus B(E,A)\bigr)
=S_0(\mathbf M)
=B(E,A)\cup Q_\eta.
\]
The observational endpoint at \(i\) depends only on whether \(i\in A\) or \(i\in\operatorname{an}_E(j)\), so all observational marks are unchanged.  For each \(k\in\mathcal K_+\), the set \(F_k=\operatorname{de}_E(T_k)\) is unchanged.  The nonobservational path adjacencies depend only on the unchanged observational graph, \(A\), and \(F_k\); the indicator adjacencies depend only on \(T_k\), \(F_k\), and \(A\); and the endpoint cases depend only on the unchanged observational orientation, ancestry in \(E\), and membership in \(F_k\).  The formulas in \(\texttt{lem:dai-two-section-checker-characterization}\) therefore give
\[
\mathcal M_{\bar\eta}^{(k)}=\mathcal M_\eta^{(k)}
\qquad(k\in\mathcal K).
\]

The reconstructed candidate is finite and acyclic because every new selection node is childless.  It is causally sufficient on \(V\), and every selection node is binary, childless, and has observed parents.  The selected stratum, pre-treatment timing, empty observational target, and soft-intervention modularity are inherited from the unchanged basal DAG and target family.  Choose each new binary selection kernel to take values strictly between zero and one for every parent configuration; finiteness makes the joint selected event have positive probability.  Thus all class conditions hold and \(\bar\eta\in\mathfrak C_D(\mathbf M)\).

Conversely, begin with any input-conditioned normalized certificate.  Applying the same pair-node and singleton-node construction makes the union of selection-parent sets exactly \(A\) and its two-section exactly \(Q_{\mathbf M}(E,A)\), so the reconstruction has precisely the advertised residual summary.  It uses at most
\[
\lvert Q_{\mathbf M}(E,A)\rvert+\lvert A\rvert
\le \binom D2+D
\]
selection nodes.  The cases \(A=\varnothing\), \(Q_{\mathbf M}(E,A)=\varnothing\), and \(K=0\) require no modification.  No overlap, rank, inverse, or division condition is used. \(\square\)
