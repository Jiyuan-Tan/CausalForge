Enumerate in a fixed lexicographic order all normalized Dai certificates \(\mathcal R=(E,H,(T_k)_{k\in\mathcal K_+})\) and retain precisely those satisfying \(\operatorname{Check}_{D}(\mathcal R,\mathbf M)=1\).  If none passes, return the flag \(\mathsf{incompatible}\).  Otherwise, for every \(e=(k,u;uv)\in\mathcal E(\mathbf M)\), form the nonempty feasible-mark set
\[
B_e(\mathbf M)=\left\{\operatorname{mark}_e\bigl(\mathcal N^{(k)}(\mathcal R)\bigr):\operatorname{Check}_{D}(\mathcal R,\mathbf M)=1\right\}\subseteq\{\mathrm{tail},\mathrm{arrow}\}.
\]
Set the output mark at \(e\) to the unique element when \(B_e(\mathbf M)\) is a singleton and to a circle when it contains both marks.  For every circle, retain the first accepted tail certificate and the first accepted arrowhead certificate in the enumeration order.  Define \(\operatorname{CDIS}^{\mathrm{cmp}}(\mathbf M)\) to be this partial-graph family together with those coupled certificates.  Its observational component is on \(V\); only a component indexed by \(k\in\mathcal K_+\) is on \(V\cup\{\zeta_k\}\).
