\textbf{Proof.}
The matrix family in \(\texttt{def:oracle-input-encoding}\) is exactly the input consumed by \(\texttt{def:complete-cdis}\).  Applying \(\texttt{thm:enumerative-si-pag-completeness}\) gives
\[
\operatorname{CDIS}^{\mathrm{cmp}}(\mathbf M)
=\mathcal P_{\mathrm{SI}}(\mathbf M),
\]
the candidate bound \(3^{\binom D2}2^D\), and the runtime bound
\[
O\!\left(3^{\binom D2}2^D
\left[D^2+(K+1)(D+1)^3+N_{\mathrm{end}}\right]\right).
\]
The endpointwise feasible-mark identity proved there establishes population soundness because every fixed output mark occurs in every compatible member.  It establishes population completeness because every invariant mark is fixed, while every residual circle is accompanied by accepted tail and arrowhead certificates.  By \(\texttt{thm:finite-common-realizability}\), those certificates reconstruct actual members of the full Dai compatibility class and are globally coherent across all regimes.

The domain statement follows from the two branches of \(\texttt{def:dai-certificate-checker}\): \(\mathcal N^{(0)}\) is on \(V\) and contains no intervention indicator, while \(\mathcal N^{(k)}\) is on \(V\cup\{\zeta_k\}\) only for \(k\in\mathcal K_+\).  When \(K=0\), this latter branch is absent.  Moreover,
\[
\log\!\left(3^{\binom D2}2^D\right)=O(D^2),
\]
so the search is singly exponential in \(D^2\), while \(K\) occurs only in the polynomial per-candidate factor.  The procedure starts from supplied oracle MAG matrices; its correctness and runtime exclude their discovery by conditional-independence or invariance queries.  No step invokes a complete fixed local calculus, which remains the separate open-ended question.  No numerical overlap, rank, inverse, division, or limiting condition is used. \(\square\)
