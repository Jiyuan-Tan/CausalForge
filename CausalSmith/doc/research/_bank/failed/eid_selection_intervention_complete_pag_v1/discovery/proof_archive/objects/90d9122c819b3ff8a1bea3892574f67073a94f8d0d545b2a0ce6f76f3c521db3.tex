Given \(\mathbf M\), a candidate \((E,A,(T_k)_{k\in\mathcal K_+})\) is rejected unless it satisfies the acyclicity, ancestor-closure, and residual-skeleton conditions in \(\texttt{def:normalized-dai-certificate}\).  For an admissible candidate set
\[
Q=Q_{\mathbf M}(E,A)=S_0(\mathbf M)\setminus B(E,A),
\qquad
\mathcal R_{\mathbf M}=\bigl(E,A,Q,(T_k)_{k\in\mathcal K_+}\bigr),
\qquad
F_k(\mathcal R_{\mathbf M})=\operatorname{de}_E(T_k).
\]
Construct \(\mathbf N(\mathcal R_{\mathbf M})=(\mathcal N^{(0)}(\mathcal R_{\mathbf M}),\ldots,\mathcal N^{(K)}(\mathcal R_{\mathbf M}))\) as follows.  The observational graph has vertex set \(V\); distinct \(i,j\in V\) are adjacent exactly when
\[
i\to j\in E\text{ or }j\to i\in E,
\quad\text{or}\quad
\exists c\in A:\ i\to c\leftarrow j\text{ in }E,
\quad\text{or}\quad
\{i,j\}\in Q.
\]
Equivalently, its adjacency set is \(B(E,A)\cup Q=S_0(\mathbf M)\).  At an observational adjacency, the endpoint at \(i\) is a tail exactly when \(i\in A\) or \(i\in\operatorname{an}_E(j)\), and is an arrowhead otherwise.

For \(k\in\mathcal K_+\), the graph \(\mathcal N^{(k)}(\mathcal R_{\mathbf M})\) has vertex set \(V\cup\{\zeta_k\}\).  Vertices \(i,j\in V\) are adjacent exactly when they are adjacent in \(\mathcal N^{(0)}(\mathcal R_{\mathbf M})\), or there is a path \((i=v_0,v_1,\ldots,v_m=j)\) in \(\mathcal N^{(0)}(\mathcal R_{\mathbf M})\) such that every \(v_\ell\) belongs to \(A\) and every internal vertex \(v_1,\ldots,v_{m-1}\) belongs to \(F_k(\mathcal R_{\mathbf M})\).  Also, \(\zeta_k\) is adjacent to \(j\) exactly when
\[
j\in T_k\cup\bigl(F_k(\mathcal R_{\mathbf M})\cap A\bigr),
\]
and every such edge is \(\zeta_k\to j\).  For an adjacency between \(i,j\in V\), preserve an observational directed orientation when one exists.  Otherwise orient it by the following exhaustive cases:
\[
\begin{array}{c|c}
\text{condition}&\text{orientation}\\ \hline
i,j\notin F_k(\mathcal R_{\mathbf M})&i\mathbin{-}j\\
j\in F_k(\mathcal R_{\mathbf M}),\ i\notin F_k(\mathcal R_{\mathbf M})\text{ or }i\in\operatorname{an}_E(j)&i\to j\\
i\in F_k(\mathcal R_{\mathbf M}),\ j\notin F_k(\mathcal R_{\mathbf M})\text{ or }j\in\operatorname{an}_E(i)&j\to i\\
i,j\in F_k(\mathcal R_{\mathbf M}),\ i\notin\operatorname{an}_E(j),\ j\notin\operatorname{an}_E(i)&i\leftrightarrow j.
\end{array}
\]
Define \(\operatorname{Check}_{D}(\mathcal R_{\mathbf M},\mathbf M)=1\) exactly when, for every \(k\in\mathcal K\), \(\mathcal N^{(k)}(\mathcal R_{\mathbf M})\) and \(\mathcal M^{(k)}\) have the same adjacency set and the same set of unshielded collider triples; otherwise set the checker to zero.  All rejection, ancestor, descendant, connectivity, adjacency, endpoint, and unshielded-collider tests are finite matrix computations.  Regime zero introduces no indicator, whereas only \(k\in\mathcal K_+\) uses \(\zeta_k\).
