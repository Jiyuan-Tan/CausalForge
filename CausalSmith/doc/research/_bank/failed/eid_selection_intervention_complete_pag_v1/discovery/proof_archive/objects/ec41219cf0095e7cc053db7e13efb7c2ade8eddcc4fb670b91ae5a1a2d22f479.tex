A normalized Dai certificate is a tuple
\[
\mathcal R=(E,H,(T_k)_{k\in\mathcal K_+}),
\]
where \(E\) is a directed acyclic graph on \(V\), \(H\subseteq 2^V\) is a set of distinct subsets of \(V\), and \(T_k\subseteq V\) for every \(k\in\mathcal K_+\); set \(T_0=\varnothing\).  A member \(h\in H\) represents the parent set of one binary childless selection node, and \(T_k\) represents the unknown soft-intervention target in regime \(k\).  In particular, \(|H|\le 2^D\).
