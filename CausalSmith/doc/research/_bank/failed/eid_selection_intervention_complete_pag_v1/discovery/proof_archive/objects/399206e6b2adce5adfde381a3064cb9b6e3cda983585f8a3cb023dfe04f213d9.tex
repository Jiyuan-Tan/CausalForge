For a normalized certificate \(\mathcal R=(E,H,(T_k)_{k\in\mathcal K_+})\), set
\[
A(\mathcal R)=\operatorname{an}_E\!\left(\bigcup_{h\in H}h\right),
\qquad
F_k(\mathcal R)=\operatorname{de}_E(T_k).
\]
Construct a fully oriented family \(\mathbf N(\mathcal R)=(\mathcal N^{(0)}(\mathcal R),\ldots,\mathcal N^{(K)}(\mathcal R))\) as follows.  The observational graph \(\mathcal N^{(0)}(\mathcal R)\) has vertex set \(V\).  Distinct \(i,j\in V\) are adjacent exactly when at least one of the following holds:
\[
i\to j\in E\text{ or }j\to i\in E;
\quad
\exists c\in A(\mathcal R):\ i\to c\leftarrow j\text{ in }E;
\quad
\exists h\in H:\ \{i,j\}\subseteq h.
\]
At an observational adjacency, the endpoint at \(i\) is a tail exactly when \(i\in A(\mathcal R)\) or \(i\in\operatorname{an}_E(j)\), and is an arrowhead otherwise.

For \(k\in\mathcal K_+\), the graph \(\mathcal N^{(k)}(\mathcal R)\) has vertex set \(V\cup\{\zeta_k\}\).  Vertices \(i,j\in V\) are adjacent exactly when they are adjacent in \(\mathcal N^{(0)}(\mathcal R)\), or there is a path \((i=v_0,v_1,\ldots,v_m=j)\) in \(\mathcal N^{(0)}(\mathcal R)\) such that every \(v_\ell\) belongs to \(A(\mathcal R)\) and every internal vertex \(v_1,\ldots,v_{m-1}\) belongs to \(F_k(\mathcal R)\).  Also, \(\zeta_k\) is adjacent to \(j\) exactly when
\[
j\in T_k\cup\bigl(F_k(\mathcal R)\cap A(\mathcal R)\bigr),
\]
and every such edge is \(\zeta_k\to j\).  For an adjacency between \(i,j\in V\), preserve an observational directed orientation when one exists.  Otherwise orient it by the following exhaustive cases:
\[
\begin{array}{c|c}
\text{condition}&\text{orientation}\\ \hline
i,j\notin F_k(\mathcal R)&i\mathbin{-}j\\
j\in F_k(\mathcal R),\ i\notin F_k(\mathcal R)\text{ or }i\in\operatorname{an}_E(j)&i\to j\\
i\in F_k(\mathcal R),\ j\notin F_k(\mathcal R)\text{ or }j\in\operatorname{an}_E(i)&j\to i\\
i,j\in F_k(\mathcal R),\ i\notin\operatorname{an}_E(j),\ j\notin\operatorname{an}_E(i)&i\leftrightarrow j.
\end{array}
\]
Define \(\operatorname{Check}_{D}(\mathcal R,\mathbf M)=1\) exactly when, for every \(k\in\mathcal K\), \(\mathcal N^{(k)}(\mathcal R)\) and \(\mathcal M^{(k)}\) have the same adjacency set and the same set of unshielded collider triples; otherwise set the checker to zero.  All ancestry, descendant, connectivity, adjacency, and unshielded-collider tests are finite matrix computations.  Regime zero introduces no indicator, whereas only \(k\in\mathcal K_+\) uses \(\zeta_k\).
