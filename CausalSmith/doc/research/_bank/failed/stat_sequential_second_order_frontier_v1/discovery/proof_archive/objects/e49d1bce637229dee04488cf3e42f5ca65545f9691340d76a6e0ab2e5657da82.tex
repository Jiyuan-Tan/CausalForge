Assume the variance range has nonempty interior.  Fix a nonzero constant \(w\) with \(|w|\leq W\), set \(\omega_{a_0}(x)=w\), and set \(\omega_a(x)=0\) for \(a\neq a_0\).  Then, for fixed \(r<s\),
\[
\mathsf Q_n^{\sigma}(s,r,d;\omega)\geq c n^{-2\beta_d}
\quad\text{but}\quad
\mathsf R_n(s,r,d;\omega)\leq C n^{-1-2\alpha_d}.
\]
Consequently no universal lower bound \(\mathsf R_n\geq c\mathsf Q_n^{\sigma}/n\), and no universal variance-driven lower bound of order \(n^{-1-2\beta_d}\), can hold under only the frozen weight conditions.
