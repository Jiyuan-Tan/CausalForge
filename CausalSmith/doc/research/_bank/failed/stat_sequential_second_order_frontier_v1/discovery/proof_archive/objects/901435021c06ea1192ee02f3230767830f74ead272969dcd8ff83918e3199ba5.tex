Under the active-weight-region condition, there are constants \(0<c<C<\infty\) and \(n_0\), depending only on the fixed class constants, such that for all \(n\geq n_0\),
\[
c n^{-2\alpha_d}
\leq \mathsf Q_n^{\mu}(s,d;\omega)
\leq C n^{-2\alpha_d},
\qquad \alpha_d=\frac{s}{2s+d}.
\]
This conclusion does not require \(v_{\min}<v_{\max}\).
