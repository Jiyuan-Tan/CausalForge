Fix \(P\in\mathcal P(\alpha,\beta,s,d,M_Y,L,pbar,c,t_0)\), and let \(m_P\) be the compatible conditional-mean version in the statement. Since both \(m_P\) and \(\mu_P\) take values in \([-M_Y,M_Y]\), their difference is integrable. The asserted compatibility and the lower positivity bound give
+\[
+0=\int_{[0,1]^d}\int_0^1
+ \lvert\mu_P(a,x)-m_P(a,x)\rvert\pi_P(a\mid x)\,da\,dP_X(x)
+\ge c\int_{[0,1]^d}\int_0^1
+ \lvert\mu_P(a,x)-m_P(a,x)\rvert\,da\,dP_X(x).
+\]
+Hence the last nonnegative integral is zero. By Fubini's theorem, there is a set \(E_1\subseteq[0,1]^d\) with \(P_X(E_1)=1\) such that, for every \(x\in E_1\),
+\[
+\mu_P(a,x)=m_P(a,x)
+\quad\text{for Lebesgue-almost every }a\in[0,1].
+\]
+By the continuity hypothesis, there is another set \(E_2\) with \(P_X(E_2)=1\) on which both functions of \(a\) are continuous. For \(x\in E_1\cap E_2\), the continuous function \(a\mapsto\mu_P(a,x)-m_P(a,x)\) vanishes Lebesgue-almost everywhere. If it were nonzero at any point, continuity would make it nonzero on a relative open interval of positive Lebesgue measure, a contradiction. Thus
+\[
+\mu_P(a,x)=m_P(a,x)
+\quad\text{for every }a\in[0,1]
+\quad\text{and for }P_X\text{-almost every }x.
+\]
+In particular, \(\mu_P(t_0,x)=m_P(t_0,x)\) for \(P_X\)-almost every \(x\). The designated density \(p_X\) represents \(P_X\), while \(m_P(t_0,\cdot)\) is a version of \(\mathbb E[Y(t_0)\mid X=\cdot]\). Therefore, using boundedness and the tower property,
+\[
+\theta_P(t_0)
+=\int_{[0,1]^d}\mu_P(t_0,x)p_X(x)\,dx
+=\int_{[0,1]^d}m_P(t_0,x)\,dP_X(x)
+=\mathbb E[Y(t_0)].
+\]
+The first quantity is independent of the admissible observed-data versions by \(\mathrm{prop:estimand\text{-}version\text{-}invariant}\), so the equality identifies the stated causal target rather than an arbitrary representative.
+
+It remains to justify the final necessity assertion. Consider an admissible instance with \(L\ge1\). Let \(X\) be uniform on \([0,1]^d\), let \(A\) be uniform on \([0,1]\) independently of \(X\), and let \(Y=0\). The observed-data law has designated versions \(p_X(x)=1\), \(\pi_P(a\mid x)=1\), and \(\mu_P(a,x)=0\), and these satisfy the defining boundedness, positivity, and Hölder conditions. Put \(\eta=M_Y/2>0\). Two causal completions of this same observed law are
+\[
+Y^{(0)}(a)=0\quad\text{for every }a,
+\qquad
+Y^{(1)}(a)=\eta\mathbf 1\{a=t_0\}
+\quad\text{for every }a.
+\]
+For each fixed \(a\), both potential outcomes are deterministic, and hence each is conditionally independent of \(A\) given \(X\). Moreover, \(P(A=t_0)=0\), so in both completions \(Y=Y^{(j)}(A)=0\) almost surely; consistency holds. Nevertheless,
+\[
+\mathbb E[Y^{(0)}(t_0)]=0,
+\qquad
+\mathbb E[Y^{(1)}(t_0)]=\eta.
+\]
+Thus consistency and conditional exchangeability alone admit the same observed law with two different fixed-dose causal means. In the second completion every version of \(\mathbb E[Y^{(1)}(a)\mid X=\cdot]\) equals \(0\) for \(a\ne t_0\) and equals \(\eta\) for \(a=t_0\), up to \(P_X\)-null sets, so no version can be continuous in \(a\) for \(P_X\)-almost every \(x\). This is exactly the singleton-dose ambiguity excluded by the compatible continuous-version condition.
