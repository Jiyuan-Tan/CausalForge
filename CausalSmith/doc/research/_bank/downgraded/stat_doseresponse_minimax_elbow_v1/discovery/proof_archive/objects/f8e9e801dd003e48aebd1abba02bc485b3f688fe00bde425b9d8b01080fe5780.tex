Let \(m_P\) be the compatible version in the statement. Its asserted agreement with \(\mu_P\) gives
\[
0=
\int_{[0,1]^d}\int_0^1
\lvert\mu_P(a,x)-m_P(a,x)\rvert
\pi_P(a\mid x)\,da\,dP_X(x).
\]
Uniform positivity implies
\[
0\ge
c\int_{[0,1]^d}\int_0^1
\lvert\mu_P(a,x)-m_P(a,x)\rvert\,da\,dP_X(x),
\]
so the last integral is zero. By Fubini's theorem, for \(P_X\)-almost every \(x\), the continuous function
\[
a\longmapsto\mu_P(a,x)-m_P(a,x)
\]
vanishes for Lebesgue-almost every \(a\in[0,1]\). A continuous function that vanishes almost everywhere vanishes everywhere. Hence
\[
\mu_P(t_0,x)=m_P(t_0,x)
=\mathbb E[Y(t_0)\mid X=x]
\]
for \(P_X\)-almost every \(x\). All quantities are integrable because they are bounded by \(M_Y\). The tower property and the fact that \(p_X\) is a density of \(P_X\) now give
\[
\mathbb E[Y(t_0)]
=\int m_P(t_0,x)\,dP_X(x)
=\int\mu_P(t_0,x)p_X(x)\,dx
=\theta_P(t_0).
\]
The last equality is version invariant by \(\mathrm{prop:estimand\text{-}version\text{-}invariant}\). The displayed compatibility condition is precisely the additional pointwise version bridge needed because \(A=t_0\) is a probability-zero event under a continuous treatment density.
