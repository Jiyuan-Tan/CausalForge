For all sufficiently large \(n\), Lemma~\texttt{lem:optimized-deficient-rate-bracket} proves
\[
C_{\mathrm{low}}n^{-2\alpha/(2\alpha+1)}
\le
\mathcal M_n(\alpha,\beta,s,d,M_Y,L,c,t_0)
\le
C_{\mathrm{up}}n^{-R_{\mathrm{ach}}},
\]
where \(R_{\mathrm{ach}}=\max\{R_{\mathrm{sep}},R_{\mathrm{hist}}\}\) is the explicit optimization value stated there. Hence any exact exponent, if it exists, must satisfy
\[
R_{\mathrm{ach}}
\le \rho(\alpha,\beta,s,d)
\le \frac{2\alpha}{2\alpha+1}.
\]
The achievable endpoint equals the oracle exponent exactly on \(\Omega\) and is strictly smaller in each residual region. The regressogram exponent is independent of \(\beta\) whenever \(\beta\wedge1\ge(\alpha\wedge1)/2\), and all three displayed achievable exponents are independent of the numerical value of \(\beta\) on \(\beta\ge1\); these are estimator-side invariances, not minimax equivalences. At \((\alpha,\beta,d,s)=(1,1,1,1/5)\), the proved achievable exponent is \(1/2\), whereas the population higher-order balance suggests \(8/13\) with \(k\asymp n^{10/13}=o(n)\), so rank singularity does not explain the surviving-band gap.
