Let \(\mathcal L_{\mathcal G}:C(\mathcal I)\to C(\mathcal I)\) be the deterministic piecewise-linear interpolation operator on \(\mathcal G_{N_0,K_T,K_D}\). For a population panel set
\[
 \widetilde S^0_{p,m}=\mathcal L_{\mathcal G}S^0_{p,m},
 \qquad
 \widetilde s_p=N_0^{-1}\sum_{m\in\mathcal D}\widetilde S^0_{p,m},
 \qquad
 \widetilde Y_m=(\widetilde S^0_{0,m}-\widetilde s_0,
                         \widetilde S^0_{1,m}-\widetilde s_1),
\]
and \(\widetilde\Gamma=N_0^{-1}\sum_{m\in\mathcal D}\widetilde Y_m\otimes\widetilde Y_m\). Apply the same selected positive-square-root factor map and pre-period least-squares map described below to \((\widetilde S^0_{p,m})\), with the same fallback rule, and denote the resulting total population comparison curve by \(\theta^{\mathrm{pop}}_{r,\mathcal G}\). For \(r=1\), set \(\theta^{\mathrm{pop}}_{1,\mathcal G}=\widetilde s_1\). This comparison curve is a proof object defined through the interpolated \(L^2\) factor map; it is not a data-dependent estimator and it does not redefine the causal target \(\theta\).

On the grid, compute every full-cell Kaplan--Meier curve \(\widehat S^{\mathrm{KM}}_{p,m}\), using the convention that an empty product is one, and extend it by \(\mathcal L_{\mathcal G}\). For \(r=1\), define \(\widehat\theta_1\) as the Kaplan--Meier curve obtained by pooling the \(N_0K_D\) donor-post records.

For \(r\ge2\), split each donor-period patient set deterministically into odd and even indices. If both folds are nonempty, compute the two fold-specific Kaplan--Meier curves, interpolate them by \(\mathcal L_{\mathcal G}\), center each fold across donors to obtain joint-period curves \(\widehat Y_m^{(1)}\) and \(\widehat Y_m^{(2)}\) in \(L^2(\{0,1\}\times\mathcal I)\), and form the self-adjoint finite-rank operator
\[
 \widehat\Gamma=\frac{1}{2N_0}\sum_{m\in\mathcal D}
 \left\{\widehat Y_m^{(1)}\otimes\widehat Y_m^{(2)}+
 \widehat Y_m^{(2)}\otimes\widehat Y_m^{(1)}\right\}.
\]
Order its eigenvalues \(\widehat\lambda_1\ge\widehat\lambda_2\ge\cdots\), use a deterministic lexicographic sign and basis rule, and define \(\widehat\mu_k=\sqrt{\max\{\widehat\lambda_k,0\}}\). Let \(\widehat u_k\) be the corresponding joint-period eigenfunctions and set \(\widehat b_{p,k}(t)=\widehat\mu_k\widehat u_{k,p}(t)\) for \(1\le k\le d\). Put \(\widehat s_p=N_0^{-1}\sum_{m\in\mathcal D}\widehat S^{\mathrm{KM}}_{p,m}\) and \(\widehat H_0=\int_{\mathcal I}\widehat b_0(t)\widehat b_0(t)^\top dt\). On the regular event that both folds are nonempty,
\[
 \widehat\lambda_d\ge\gamma_-^2/4,
 \qquad
 \widehat\lambda_d-\widehat\lambda_{d+1}\ge\gamma_-^2/4,
 \qquad
 \lambda_{\min}(\widehat H_0)\ge\kappa_-/4,
\]
define
\[
 \widehat z_\star=\widehat H_0^{-1}\int_{\mathcal I}\widehat b_0(t)
 \{\widehat S^{\mathrm{KM}}_{0,\star}(t)-\widehat s_0(t)\}\,dt,
 \qquad
 \widehat\theta_r=\widehat s_1+\widehat b_1^\top\widehat z_\star.
\]
Equivalently, this fitted curve is the coordinate-free selected-square-root map from the interpolated empirical panel to the post-period prediction; it is invariant to rotations inside a tied selected eigenspace. If a fold is empty or any displayed threshold fails, set \(\widehat b_0=\widehat b_1=0\), \(\widehat z_\star=0\), and define \(\widehat\theta_r\) to be the pooled donor-post Kaplan--Meier curve. Thus \((\widehat s_p,\widehat b_p,\widehat z_\star,\widehat\theta_r)\) and all derivatives used below are uniformly bounded measurable functions of every dataset.

On the regular event, differentiate this rotation-invariant interpolated-input map, including the selected spectral projector and positive square-root, with respect to every cellwise product-limit counting-process increment. On the fallback event, define the empirical derivative to be the ordinary pooled Kaplan--Meier derivative. Replace each patient contribution by \(\xi_{p,m,j}\) times that contribution, and let \(c_r^\xi\) be the conditional \(q_{N_0,K_T,K_D}\)-quantile of its grid supremum, where
\[
 q_{N_0,K_T,K_D}=1-\alpha+
 \min\left\{\frac{\alpha}{2},\frac{\varepsilon_{N_0,K_T,K_D}(\alpha)}{2}\right\}.
\]
Let \(\widetilde\theta_r\) be the pointwise projection of \(\widehat\theta_r\) onto \([0,1]\), with value one imposed at zero. With \(q=\min\{\beta+1,2\}\), \(c_{\mathrm{int}}=c_{\mathrm{int}}(L,\bar\tau,\beta)\) from \(\mathrm{prop:grid\mbox{-}interpolation}\), and
\[
 A_r=c_r^\xi+\mathbf 1\{r\ge2\}\eta_D(K_D)
     +\omega_r(N_0,K_T,K_D;\alpha)
     +c_{\mathrm{int}}h_{N_0,K_T,K_D}^{q},
\]
define the grid endpoints by
\[
 \widehat B_r^{\mathrm{lo}}(g)=\max\{0,\widetilde\theta_r(g)-A_r\},
 \qquad
 \widehat B_r^{\mathrm{up}}(g)=\min\{1,\widetilde\theta_r(g)+A_r\}.
\]
Interpolate both endpoints linearly and impose the common value one at zero. This total measurable construction defines \(\widehat B_r\) and its multiplier process for every dataset. The allowance \(\eta_D\) is the exact deterministic half-fold risk-exhaustion envelope, \(\omega_r\) is the finite-tail nonlinear-remainder and multiplier-transfer buffer, and the discrepancy between \(S^0\) and \(\widetilde S^0\) away from the grid enters only through the final interpolation term in \(A_r\).
