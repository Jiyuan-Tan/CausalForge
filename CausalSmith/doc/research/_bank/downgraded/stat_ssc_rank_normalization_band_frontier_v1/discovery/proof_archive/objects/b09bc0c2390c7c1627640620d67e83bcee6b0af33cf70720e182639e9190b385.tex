\textbf{Proof.}
Fix \(r\) and a sufficiently large evaluated triple.  The normalization-preserving converse implies for every admissible band
\[
 \sup_{P\in\mathfrak P_r}E_Pw(B)\ge c\rho_r.             \tag{1}
\]
Taking the infimum over the same per-triple honesty class gives \(W_r^*\ge c\rho_r\).  The attaining theorem supplies the single data-dependent witness \(\widehat B_r\in\mathcal H_r\) satisfying
\[
 \sup_{P\in\mathfrak P_r}E_Pw(\widehat B_r)\le C\bar\rho_r, \tag{2}
\]
so the minimax infimum is at most the right side of (2).  For \(r=1\), \(\bar\rho_1=\rho_1=(N_0K_D)^{-1/2}\), proving the sharp rank-one equivalence.  For \(r\ge2\) this gives exactly
\[
 c\{K_T^{-1/2}+(N_0K_D)^{-1/2}\}
 \le W_r^*
 \le C\{K_T^{-1/2}+(N_0K_D)^{-1/2}+\eta_D(K_D)\}.       \tag{3}
\]
If \(\eta_D(K_D)=O(\rho_r)\), the endpoints of (3) match.  Otherwise (3) is only the proved bracket.  Both input theorems are uniform on every three-dimensional tail and use the same evaluated-triple action class. \(\square\)
