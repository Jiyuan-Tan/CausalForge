Let \(\mathcal L_{\mathcal G}\) be piecewise-linear interpolation on the canonical grid. For the population comparison, define \(\widetilde S^0_{p,m}=\mathcal L_{\mathcal G}S^0_{p,m}\), \(\widetilde s_p=N_0^{-1}\sum_{m\in\mathcal D}\widetilde S^0_{p,m}\), \(\widetilde Y_m=(\widetilde S^0_{0,m}-\widetilde s_0,\widetilde S^0_{1,m}-\widetilde s_1)\), and \(\widetilde\Gamma=N_0^{-1}\sum_m\widetilde Y_m\otimes\widetilde Y_m\). Apply the selected positive-square-root and pre-period least-squares prediction map below to this panel and call the result \(\theta^{\mathrm{pop}}_{r,\mathcal G}\); for \(r=1\), put \(\theta^{\mathrm{pop}}_{1,\mathcal G}=\widetilde s_1\). This is a proof comparison and does not redefine \(\theta\).

Put \(h_0=s_-g_-\). For any cell or deterministic half-fold containing \(k\) patients, set
\[
 \ell_k=\max\{1,kh_0/8\},\qquad
 Y_k^\dagger(u)=\max\{Y_k(u),\ell_k\}.
\]
Order tied observed failures lexicographically by failure time and patient index, updating the risk count after each ordered failure, and define the stabilized product-limit step curve by
\[
 \widehat S_k^\dagger(t)=
 \prod_{u\le t}\left\{1-\frac{dN_k(u)}{Y_k^\dagger(u)}\right\}.
\]
Each ordered increment has \(dN_k(u)\in\{0,1\}\), so the construction is measurable and takes values in \([0,1]\) on every dataset. Interpolate it by \(\mathcal L_{\mathcal G}\). For every \(r\ge2\), use these stabilized curves for the target-pre full cell, every donor full cell, and both odd--even donor half-folds. For \(r=1\), do not stabilize: pool all \(N_0K_D\) donor-post records first, form the ordinary aggregate-risk product-limit curve with its empty-risk convention, and interpolate it continuously.

For \(r\ge2\), center the two sets of stabilized half-fold donor curves across donors to obtain \(\widehat Y_m^{(1)}\) and \(\widehat Y_m^{(2)}\), and form
\[
 \widehat\Gamma=\frac{1}{2N_0}\sum_{m\in\mathcal D}
 \{\widehat Y_m^{(1)}\otimes\widehat Y_m^{(2)}+
   \widehat Y_m^{(2)}\otimes\widehat Y_m^{(1)}\}.
\]
Select its largest \(d\) eigenvalues with deterministic lexicographic basis and sign rules, put \(\widehat\mu_k=\sqrt{\max\{\widehat\lambda_k,0\}}\), and set \(\widehat b_{p,k}=\widehat\mu_k\widehat u_{k,p}\). Let \(\widehat s_p\) be the donor average of the stabilized full-cell curves, and let \(\widehat H_0=\int_{\mathcal I}\widehat b_0\widehat b_0^\top\). On the aggregate regular event
\[
 \widehat\lambda_d\ge\gamma_-^2/4,\qquad
 \widehat\lambda_d-\widehat\lambda_{d+1}\ge\gamma_-^2/4,
 \qquad \lambda_{\min}(\widehat H_0)\ge\kappa_-/4,
\]
define
\[
 \widehat z_\star=\widehat H_0^{-1}\int_{\mathcal I}\widehat b_0(t)
 \{\widehat S_{0,\star}^\dagger(t)-\widehat s_0(t)\}\,dt,
 \qquad
 \widehat\theta_r=\widehat s_1+\widehat b_1^\top\widehat z_\star.
\]
This is equivalently the rotation-invariant selected-projector, positive-square-root, and inverse-pre-Gram prediction map. If a fold is empty or an aggregate threshold fails, set the factor and loading estimates to zero and let \(\widehat\theta_r\) be the continuously interpolated ordinary pooled donor-post product-limit curve. Thus every branch is total, measurable, and continuous.

On the regular branch, differentiate the coordinate-free prediction map and the stabilized product-limit inputs. The observed contribution of patient \(j\) in a stabilized \(k\)-patient input uses the explicit weight
\[
 -\widehat S_k^\dagger(t-)
 \int_0^t\{Y_k^\dagger(u)\}^{-1}\,dN_{k,j}(u).
\]
On the fallback and rank-one branches use the ordinary pooled aggregate-risk derivative. Attach independent \(N(0,1)\) multipliers to the patient contributions and denote the resulting interpolated grid process by \(\widehat Z_r^\xi\). Put
\[
 q_{N_0,K_T,K_D}=1-\alpha+
 \min\left\{\frac\alpha2,
 \frac{\varepsilon_{N_0,K_T,K_D}(\alpha)}2\right\},
\]
and define its left-continuous generalized-inverse conditional quantile by
\[
 \widetilde c_r^\xi=
 \inf\left\{x\ge0:
 P_\xi\left(\max_{g\in\mathcal G}|\widehat Z_r^\xi(g)|\le x
 \mid O\right)\ge q_{N_0,K_T,K_D}\right\}.
\]
Let \(C_Z\) be a fixed model-class constant dominating the uniform second-moment bounds for the oracle and empirical patient-martingale processes, put
\[
 d_r(\alpha)=\left(\frac{2C_Z}{\alpha}\right)^{1/2}\rho_r,
 \qquad c_r^\xi=\max\{\widetilde c_r^\xi,d_r(\alpha)\},
\]
and call this the guarded multiplier critical radius.

Project \(\widehat\theta_r\) pointwise onto \([0,1]\), impose value one at zero, and call the result \(\widetilde\theta_r\). With \(q=\min\{\beta+1,2\}\), define
\[
 A_r=c_r^\xi+\mathbf1\{r\ge2\}\eta_D(K_D)
 +\omega_r(N_0,K_T,K_D;\alpha)+c_{\mathrm{int}}h_{N_0,K_T,K_D}^{q}.
\]
At each grid knot set \(\widehat B_r^{\mathrm{lo}}=\max\{0,\widetilde\theta_r-A_r\}\) and \(\widehat B_r^{\mathrm{up}}=\min\{1,\widetilde\theta_r+A_r\}\), interpolate both endpoints linearly between adjacent knots, and impose their common value one at zero. This defines the guarded martingale-multiplier functional-PCR band on every dataset.
