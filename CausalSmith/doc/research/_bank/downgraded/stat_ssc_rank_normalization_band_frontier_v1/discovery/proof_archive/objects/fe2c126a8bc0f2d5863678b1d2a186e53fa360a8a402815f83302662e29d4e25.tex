Let \(S(t)=\exp\{-\int_0^t\lambda(u)\,du\}\).  The bound \(\|\lambda\|_{C^\beta}\le L\) implies a uniform \(C^{\beta+1}\) bound for \(S\).  The standard remainder formula for linear interpolation, applied in the Hölder scale, then gives
\[
 \|S-I_hS\|_\infty\le C(L,\bar\tau)h^{\min\{\beta+1,2\}}.
\]
If \(\widehat\theta\) is linearly interpolated from its grid values, then on every interval between adjacent grid points,
\[
 |\widehat\theta(t)-\theta(t)|
 \le \max_{g\in\mathcal G}|\widehat\theta(g)-\theta(g)|
      +|I_h\theta(t)-\theta(t)|.
\]
Taking suprema proves the corrected interpolation inequality.  The frozen exponent \(h^\beta\) is valid only when \(\beta\le2\); for \(\beta>2\), a generic twice differentiable survival curve has linear-interpolation error of exact order \(h^2\), which is not \(O(h^\beta)\).
