\textbf{Proof.}
Put \(n_D=N_0K_D\). The converse gives \(W_1^*\ge c_1n_D^{-1/2}\) and, for fixed \(r\ge2\), \(W_r^*\ge c_r\{K_T^{-1/2}+n_D^{-1/2}\}=c_r\rho_r\), after taking the infimum over the same per-triple admissible class. The attaining theorem supplies one explicit measurable band with
\[
 \widehat B_r\in\mathcal H_r(N_0,K_T,K_D;\alpha),
 \qquad \sup_{P\in\mathfrak P_r}E_Pw(\widehat B_r)\le C_r\bar\rho_r. \tag{1}
\]
Using it in the minimax infimum gives \(W_r^*\le C_r\bar\rho_r\). At rank one, \(\bar\rho_1=\rho_1=n_D^{-1/2}\), so \(W_1^*\asymp(N_0K_D)^{-1/2}\). At fixed \(r\ge2\), the unrestricted conclusion is
\[
 c_r\{K_T^{-1/2}+n_D^{-1/2}\}
 \le W_r^*\le C_r\{K_T^{-1/2}+n_D^{-1/2}+\eta_D(K_D)\}.   \tag{2}
\]
If \(\eta_D(K_D)=O(\rho_r)\), the two sides have the same order. Without that condition, (2) is only a bracket. Both input theorems are uniform on three-dimensional tails and use the evaluated-triple coverage constraint. \(\square\)
