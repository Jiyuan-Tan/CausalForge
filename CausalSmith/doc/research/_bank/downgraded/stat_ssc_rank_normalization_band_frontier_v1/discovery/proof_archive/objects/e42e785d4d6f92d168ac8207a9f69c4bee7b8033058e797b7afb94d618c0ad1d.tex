\textbf{Proof.}
Fix \(P\in\mathfrak P_1(N_0,K_T,K_D)\).  Since \(d=r-1\), exact rank one gives \(d=0\).  Equivalently, \(\mathcal C_D\) has rank zero by \(\mathrm{ass:exact\mbox{-}centered\mbox{-}rank}\).  Under the zero-dimensional convention in \(\mathrm{def:canonical\mbox{-}factorization}\), the inner product \(b_p(t)^\top z_m\) is an empty sum and hence is zero.  Substitution into \(\mathrm{ass:normalized\mbox{-}factor\mbox{-}model}\) gives, for every \(p,m,t\),
\[
 S^0_{p,m}(t)=s_p(t)+b_p(t)^\top z_m=s_p(t).
\]
The target definition then yields
\[
 \theta(t)=S^0_{1,\star}(t)=s_1(t).
\]

Let \(\{P_\eta:|\eta|<\eta_0\}\) be a regular submodel covered by the claim, and write \(q_{0,\star,\eta}\) for the density of one target-pre record with respect to a common dominating measure.  The target-pre marginal is fixed along this path, so \(q_{0,\star,\eta}=q_{0,\star,0}\).  Its score is therefore
\[
 \left.\partial_\eta\log q_{0,\star,\eta}(O_{0,\star,j})\right|_{\eta=0}=0.
\]
Patient independence makes the target-pre sample score the sum of these zero contributions.  This proves the stated ancillarity for precisely the paths quantified in the corrected claim.

Finally fix \(r\ge2\) and a loading path \(z_{\star,\eta}=z_\star+\eta v\) that remains in the model.  The donor loadings and factor curves are fixed, so the primitive donor operator, its rank, and its singular values are fixed.  Endpoint normalization is preserved because \(b_1(0)=0\) in the canonical factorization.  Differentiating the target formula gives
\[
 \left.\partial_\eta\theta_\eta(t)\right|_{\eta=0}
 =\left.\partial_\eta\{s_1(t)+b_1(t)^\top(z_\star+\eta v)\}\right|_{\eta=0}
 =b_1(t)^\top v.
\]
This derivative is a nonzero element of \(C(\mathcal I)\) if and only if \(b_1^\top v\not\equiv0\). \(\square\)
