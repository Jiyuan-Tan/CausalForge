For any fixed positive contrast separation, a universal threshold tending to zero reduces rank choice to testing whether the centered contrast operator is zero. Uniformity over all unknown positive lower bounds with one common finite threshold is different: alternatives whose singular value is of the testing order are contiguous to rank one, so no uniformly consistent selector exists there.
