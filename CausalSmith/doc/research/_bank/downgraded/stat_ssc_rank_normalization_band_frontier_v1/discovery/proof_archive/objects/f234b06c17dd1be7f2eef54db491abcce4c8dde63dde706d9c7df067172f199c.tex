Fix \(d=r-1\).  For every integer \(N_0\ge2d+1\) and \(1\le k\le d\), define the explicitly centered donor column
\[
 q_{k,m}=\{m-(N_0+1)/2\}^k-
 N_0^{-1}\sum_{\ell=1}^{N_0}\{\ell-(N_0+1)/2\}^k,
 \qquad 1\le m\le N_0.
\]
Apply deterministic empirical Gram--Schmidt to \(q_1,\ldots,q_d\) in the inner product \(N_0^{-1}\sum_m xy\), orienting each column to have positive leading polynomial coefficient, and denote the resulting row vectors by \(z_m^{(N_0,d)}\).  Thus every column is mean zero and \(N_0^{-1}\sum_m z_m^{(N_0,d)}z_m^{(N_0,d)\top}=I_d\); for \(d=1\), \(z_{m,1}^{(N_0,1)}=\{m-(N_0+1)/2\}/\sqrt{(N_0^2-1)/12}\).

For \(d\ge1\), apply deterministic \(L^2(\mathcal I)\) Gram--Schmidt to \(\psi_\circ,t\psi_\circ,\ldots,t^{d-1}\psi_\circ\), orient the first function as \(\varphi_{1,d}=\psi_\circ/\|\psi_\circ\|_2\), write \(\Phi_d=(\varphi_{1,d},\ldots,\varphi_{d,d})^\top\), and set
\[
 A_{p,d}(t)=a_{\circ,p}\|\psi_\circ\|_2\Phi_d(t).
\]
For \(u\in\{-1,+1\}\), take \(s_p(t)=e^{-\lambda_\circ t}\), \(b_p=A_{p,d}\), donor loadings \(z_m=z_m^{(N_0,d)}\), and target loading \(z_\star^{(u)}=u h_\circ K_T^{-1/2}e_1\).  Put
\[
 S_{p,m}^{(r,u)}(t)=s_p(t)+A_{p,d}(t)^\top z_m,
 \qquad
 S_{p,\star}^{(r,u)}(t)=s_p(t)+A_{p,d}(t)^\top z_\star^{(u)}
\]
on \(\mathcal I\), continue every curve after \(\bar\tau\) by its value at \(\bar\tau\) times \(e^{-\lambda_\circ(t-\bar\tau)}\), take \(C_{p,m,j}=\infty\), and let \(P_{r,u}\) be the induced independent observed-data law.  For \(r=2\), define \(P_u=P_{2,u}\).  When \(d=0\), all score arrays and factor terms are empty and the same prescription defines the homogeneous backbone.  This construction only names the laws; centering, empirical Gram, class membership, rank, spectrum, separation, and divergence are properties to be proved.
