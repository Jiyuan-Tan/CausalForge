Let \(\mathcal L_{\mathcal G}\) be piecewise-linear interpolation on the canonical grid. For the population comparison, define
\[
 \widetilde S^0_{p,m}=\mathcal L_{\mathcal G}S^0_{p,m},\qquad
 \widetilde s_p=N_0^{-1}\sum_{m\in\mathcal D}\widetilde S^0_{p,m},
\]
\[
 \widetilde Y_m=(\widetilde S^0_{0,m}-\widetilde s_0,
                  \widetilde S^0_{1,m}-\widetilde s_1),\qquad
 \widetilde\Gamma=N_0^{-1}\sum_{m\in\mathcal D}
 \widetilde Y_m\otimes\widetilde Y_m.
\]
Apply the selected positive-square-root and pre-period least-squares prediction map below to this panel and call the result \(\theta^{\mathrm{pop}}_{r,\mathcal G}\); for \(r=1\), put \(\theta^{\mathrm{pop}}_{1,\mathcal G}=\widetilde s_1\). This is a proof comparison and does not redefine \(\theta\).

Put \(h_0=s_-g_-\). For any cell or deterministic half-fold containing \(k\) patients, set
\[
 \ell_k=\max\{1,kh_0/8\},\qquad
 Y_k^\dagger(u)=\max\{Y_k(u),\ell_k\}.
\]
Order tied observed failures lexicographically by failure time and patient index, updating the risk count after each ordered failure, and define
\[
 \widehat S_k^\dagger(t)=
 \prod_{u\le t}\left\{1-\frac{dN_k(u)}{Y_k^\dagger(u)}\right\}.
\]
Every ordered increment is zero or one, so this measurable curve lies in \([0,1]\) on every dataset. Interpolate it by \(\mathcal L_{\mathcal G}\). For every \(r\ge2\), use these stabilized curves for the target-pre full cell, every donor full cell, and both odd--even donor half-folds. For \(r=1\), do not stabilize: pool all \(N_0K_D\) donor-post records first, form the ordinary aggregate-risk product-limit curve with its empty-risk convention, and interpolate it continuously.

For \(r\ge2\), center the two sets of stabilized half-fold donor curves across donors to obtain \(\widehat Y_m^{(1)}\) and \(\widehat Y_m^{(2)}\), and form
\[
 \widehat\Gamma=\frac{1}{2N_0}\sum_{m\in\mathcal D}
 \{\widehat Y_m^{(1)}\otimes\widehat Y_m^{(2)}+
   \widehat Y_m^{(2)}\otimes\widehat Y_m^{(1)}\}.
\]
Select its largest \(d\) eigenvalues with deterministic lexicographic basis and sign rules, put \(\widehat\mu_k=\sqrt{\max\{\widehat\lambda_k,0\}}\), and set \(\widehat b_{p,k}=\widehat\mu_k\widehat u_{k,p}\). Let \(\widehat s_p\) be the donor average of the stabilized full-cell curves, and let \(\widehat H_0=\int_{\mathcal I}\widehat b_0\widehat b_0^\top\). On the aggregate regular event
\[
 \widehat\lambda_d\ge\gamma_-^2/4,\qquad
 \widehat\lambda_d-\widehat\lambda_{d+1}\ge\gamma_-^2/4,
 \qquad \lambda_{\min}(\widehat H_0)\ge\kappa_-/4,
\]
define
\[
 \widehat z_\star=\widehat H_0^{-1}\int_{\mathcal I}\widehat b_0(t)
 \{\widehat S_{0,\star}^\dagger(t)-\widehat s_0(t)\}\,dt,
 \qquad
 \widehat\theta_r=\widehat s_1+\widehat b_1^\top\widehat z_\star.
\]
This is the rotation-invariant selected-projector, positive-square-root, and inverse-pre-Gram prediction map. If a fold is empty or an aggregate threshold fails, set the factor and loading estimates to zero and let \(\widehat\theta_r\) be the continuously interpolated ordinary pooled donor-post product-limit curve. Thus every branch is total, measurable, and continuous.

On the regular branch, differentiate the coordinate-free prediction map and the stabilized product-limit inputs. The observed contribution of patient \(j\) in a stabilized \(k\)-patient input uses the weight
\[
 -\widehat S_k^\dagger(t-)
 \int_0^t\{Y_k^\dagger(u)\}^{-1}\,dN_{k,j}(u).
\]
On the fallback and rank-one branches use the ordinary pooled aggregate-risk derivative. Attach independent standard Gaussian multipliers to the patient contributions and denote the resulting interpolated process by \(\widehat Z_r^\xi\). Define its conditional covariance by
\[
 \widehat\Sigma_r(g,g')
 =E_\xi\{\widehat Z_r^\xi(g)\widehat Z_r^\xi(g')\mid O\}.
\]

Put \(n_D=N_0K_D\), \(p_{\mathcal G}=2|\mathcal G_{N_0,K_T,K_D}|\), and
\[
 n_{\mathrm{eff},r}=
 \begin{cases}
 n_D,&r=1,\\
 \min\{K_T,n_D\},&r\ge2.
 \end{cases}
\]
With \(c_0=s_-g_-/3\), define
\[
 a_{r,n}=n_D^{-1/2}+\mathbf1\{r\ge2\}
 \left\{K_T^{-1/2}+K_D^{-1/2}+\eta_D(K_D)
 +e^{-c_0K_T/2}+e^{-c_0n_D/2}\right\}.
\]
Let
\[
 k_{r,n}=\max\{2,\lceil n_{\mathrm{eff},r}^{1/9}\rceil\},
 \qquad p_{\mathrm c,r,n}=2(k_{r,n}+1),
\]
and, for a sufficiently large fixed \(C_U<\infty\) depending only on the fixed model constants and \(r\), put
\[
 U_{r,n}=C_U p_{\mathrm c,r,n}^{5/2}n_{\mathrm{eff},r}^{-1/2},
 \qquad
 \zeta_{r,n}=U_{r,n}^{1/4}\{1+|\log U_{r,n}|\}.
\]
For a sufficiently large fixed \(C_\chi<\infty\), depending only on the same constants and \(r\), define
\[
 \chi_{r,n}=C_\chi\left[
 \zeta_{r,n}+a_{r,n}^{1/48}\{1+|\log a_{r,n}|\}\right],
 \qquad
 \tau_{r,n}=\rho_r(N_0,K_T,K_D)\chi_{r,n},
\]
and
\[
 \delta_{r,n}(\alpha)=
 \min\left\{\frac\alpha2,
 \frac{\varepsilon_{N_0,K_T,K_D}(\alpha)}2\right\}.
\]
Set \(q_{N_0,K_T,K_D}=1-\alpha+\delta_{r,n}(\alpha)\), and define the left-continuous generalized-inverse conditional quantile by
\[
 \widetilde c_r^\xi=
 \inf\left\{x\ge0:
 P_\xi\left(\max_{g\in\mathcal G}|\widehat Z_r^\xi(g)|\le x
 \mid O\right)\ge q_{N_0,K_T,K_D}\right\}.
\]
Define the stochastic critical radius by
\[
 c_r^\xi=\widetilde c_r^\xi+\tau_{r,n}.
\]
Thus the conditional random quantile is accompanied by an explicit degeneracy-robust additive comparison slack. The first component of \(\chi_{r,n}\) is the correctly dimensioned coarse-net Yurinskii and modulus allowance; the second covers empirical covariance, entropy, and fallback transfer. No coordinate-variance lower bound or deterministic moment guard is used.

Project \(\widehat\theta_r\) pointwise onto \([0,1]\), impose value one at zero, and call the result \(\widetilde\theta_r\). With \(q=\min\{\beta+1,2\}\), define
\[
 A_r=\widetilde c_r^\xi+\tau_{r,n}
 +\mathbf1\{r\ge2\}\eta_D(K_D)
 +\omega_r(N_0,K_T,K_D;\alpha)
 +c_{\mathrm{int}}h_{N_0,K_T,K_D}^{q}.
\]
At each grid knot set
\[
 \widehat B_r^{\mathrm{lo}}=
 \max\{0,\widetilde\theta_r-A_r\},\qquad
 \widehat B_r^{\mathrm{up}}=
 \min\{1,\widetilde\theta_r+A_r\},
\]
interpolate both endpoints linearly between adjacent knots, and impose their common value one at zero. This defines the random-quantile martingale-multiplier functional-PCR band on every dataset.
