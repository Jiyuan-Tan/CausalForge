For every fixed \(0<\epsilon<1/2\), the answer to the logarithmic-upper question is negative.  There do not exist finite \(C_\epsilon\), positive \(\rho_\epsilon\), and a collection of measurable estimators \(\widehat V_{n,d}\) such that
\[
 \sup_{P\in\mathcal P_{d,\epsilon}}
 E_P\!\left[
  \left\{\widehat V_{n,d}(O_1,\ldots,O_n)-V^\star(P)\right\}^2
 \right]
 \le C_\epsilon\left\{\frac1n+\frac d{n\log(en)}\right\}
\]
for every \(2\le d\le\rho_\epsilon n\log(en)\).  Indeed, for \(d_n=\max\{2,\lfloor\log(en)\rfloor\}\),
\[
 \mathfrak R_{n,d_n,\epsilon}
 \ge c_\epsilon\frac{\sqrt{\log(en)}}n
\]
for all sufficiently large \(n\).  Hence no computable four-cell overlap-cone certificate can imply the proposed bound.  Moreover, along sequences in the stated range, \(\mathfrak R_{n,d,\epsilon}=O(n^{-1})\) holds if and only if \(d=O(1)\).
