Along every sequence with \(d/\log n\to\infty\) and \(d/(n\log n)\to0\), the elementary minimax bracket gives
\[
 \frac{n\log n}{d}\,\mathfrak R_{n,d,\epsilon}
 \ge c_\epsilon\left\{\frac{\log n}{d}+\frac{\log n}{\log(en)}\right\},
\]
so
\[
 \liminf_{n\to\infty}\frac{n\log n}{d}\,\mathfrak R_{n,d,\epsilon}\ge c_\epsilon>0.
\]
The same bracket yields only
\[
 \frac{n\log n}{d}\,\mathfrak R_{n,d,\epsilon}
 \le \min\left\{\frac{n\log n}{d},\,C_\epsilon\log n\right\},
\]
whose two entries both diverge under the stated regime. Hence every finite subsequential limit, if one exists, is strictly positive, but the current core proves neither a finite normalized limsup nor convergence.
