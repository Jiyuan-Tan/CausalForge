\textbf{Proof.}
Fix class \(j\).  For each block choose \(k_\ell\in\arg\min_{1\le k\le3}d_{j\ell k}\), put unit direction mass on \(k_\ell\), and use independent symmetric signs.  Positivity of the loadings ensures that the response class is nonzero, while zero mass on the unused directions is allowed by \(\Pi_n\).  The diagonal risk formula in \(\mathrm{thm:block\text{-}specific\text{-}finite\text{-}class\text{-}frontier}\) gives
\[
R_j^{\mathrm{blk}}
=\frac4{n^2}\max_{1\le\ell\le q}d_{j\ell k_\ell}
=\frac4{n^2}\max_{1\le\ell\le q}\min_{1\le k\le3}d_{j\ell k}
=\frac{4\bar r_j}{n^2}.
\tag{1}
\]
The same theorem identifies the last quantity with \((r_j^{\mathrm{blk}})^\star\), so the product law attains the class oracle.

If \(b_j>\bar r_j\), then
\[
\Delta_j^{\mathrm{blk}}
=\frac{4(b_j-\bar r_j)}{n^2}>0.
\tag{2}
\]
At the oracle law the one-class retained fraction equals
\[
g_j^{\mathrm{blk}}
=\frac{B_j^{\mathrm{blk}}-(r_j^{\mathrm{blk}})^\star}
{B_j^{\mathrm{blk}}-(r_j^{\mathrm{blk}})^\star}=1.
\tag{3}
\]
No design can exceed one because \((r_j^{\mathrm{blk}})^\star\) is the minimum possible risk.  Thus the one-class value is one, and any lower finite-menu value is due to simultaneous commitment across classes.  \(\square\)
