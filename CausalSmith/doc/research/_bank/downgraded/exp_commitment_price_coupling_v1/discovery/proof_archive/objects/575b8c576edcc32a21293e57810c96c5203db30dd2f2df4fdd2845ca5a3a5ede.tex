For every instance of the heterogeneous even-block construction \(\mathcal H_{\mathrm{het}}\) in \(\mathrm{def:heterogeneous-block-local-sdp}\), global blinding implies
\[
\Pr_\pi\{Z_{[\ell]}=a_{\ell r}\}
=\Pr_\pi\{Z_{[\ell]}=-a_{\ell r}\}
=\frac12p_{\ell r}(\pi),
\qquad
p_\ell(\pi)\in\Delta_{m_\ell}.
\]
The independent-block, independent-symmetric-sign law \(\pi_p\) with these same local masses belongs to \(\Pi_{\mathrm{het}}\) and satisfies
\[
[Q_{\pi_p}]_{\ell\ell}=[Q_\pi]_{\ell\ell}=\Sigma_\ell(p_\ell),
\qquad
[Q_{\pi_p}]_{\ell s}=0\quad(\ell\ne s).
\]
For every class \(j\),
\[
R_j(\pi)
=\frac1{N^2}\lambda_{\max}\{G_j^{1/2}Q_\pi G_j^{1/2}\}
\ge\frac1{N^2}\max_{1\le\ell\le L}
\lambda_{\max}\{L_{j\ell}(p_\ell)\},
\]
whereas
\[
R_j(\pi_p)
=\frac1{N^2}\max_{1\le\ell\le L}
\lambda_{\max}\{L_{j\ell}(p_\ell)\}
\le R_j(\pi).
\]
Thus the same productization Pareto-dominates \(\pi\) simultaneously for every member of the finite menu, with arbitrary local ranks and without any commutativity requirement among the local class kernels.

The causal target remains distinct from this design criterion.  For any fixed potential-outcome array \(\{Y_{\ell u}(0),Y_{\ell u}(1):1\le\ell\le L,1\le u\le b_\ell\}\), define
\[
\tau_N^{\mathrm{het}}
=\frac1N\sum_{\ell=1}^L\sum_{u=1}^{b_\ell}
\{Y_{\ell u}(1)-Y_{\ell u}(0)\},
\]
\[
Y_{\ell u}^{\mathrm{obs}}
=\frac{1+Z_{\ell u}}2Y_{\ell u}(1)
+\frac{1-Z_{\ell u}}2Y_{\ell u}(0),
\qquad
\widehat\tau_{\mathrm{het}}
=\frac2N\sum_{\ell=1}^L\sum_{u=1}^{b_\ell}Z_{\ell u}Y_{\ell u}^{\mathrm{obs}}.
\]
Let \(\mu_{\mathrm{het}}\) be the centered vector formed from \(Y(1)+Y(0)\).  Conditional on this fixed array, assignment under \(\pi\) is the only randomness, and
\[
\widehat\tau_{\mathrm{het}}-\tau_N^{\mathrm{het}}
=N^{-1}Z^\top\mu_{\mathrm{het}},
\qquad
\mathbb E_\pi\widehat\tau_{\mathrm{het}}=\tau_N^{\mathrm{het}}.
\]
If \(\mu_{\mathrm{het}}\in\mathcal M_j\), then
\[
\operatorname{Var}_\pi(\widehat\tau_{\mathrm{het}})
\le R_j(\pi).
\]

The class baseline and oracle risks are exactly
\[
R_j(\pi_0^{\mathrm{het}})=\beta_j,
\qquad
\min_{\pi\in\Pi_{\mathrm{het}}}R_j(\pi)=\rho_j
=\frac1{N^2}\max_{1\le\ell\le L}
\min_{p_\ell\in\Delta_{m_\ell}}
\lambda_{\max}\{L_{j\ell}(p_\ell)\}.
\]
Each local oracle value is the optimum of the explicit semidefinite program
\[
\min_{p_\ell\in\Delta_{m_\ell},\,u\in\mathbb R}
\{u:L_{j\ell}(p_\ell)\preceq uI_{b_\ell-1}\}.
\]
Assume the necessary gain-positivity condition \(\delta_j>0\) for every \(1\le j\le J\).  Then the exact finite-sample commitment value is
\[
\boxed{
\lambda_{\mathrm{het}}^\star
=\max_{t,\,(p_{\ell r})}
\left\{t:
p_{\ell r}\ge0,\quad
\sum_{r=1}^{m_\ell}p_{\ell r}=1,\quad
L_{j\ell}(p_\ell)
\preceq N^2(\beta_j-\delta_jt)I_{b_\ell-1}
\ \text{for all }j,\ell
\right\}.}
\]
Every optimizer yields an attaining independent-block, independent-symmetric-sign design.  Zero local masses are permitted; no lower overlap bound on assignment directions is imposed.  The program has \(1+\sum_{\ell=1}^Lm_\ell\) scalar variables, \(L\) simplex equalities, and \(JL\) local linear matrix inequalities of order \(b_\ell-1\).  Its displayed coefficient array has size
\[
O\!\left(J\sum_{\ell=1}^Lm_\ell(b_\ell-1)^2\right),
\]
so its formulation is polynomial in the explicitly enumerated local support sizes and block dimensions, without enumerating the \(\prod_\ell(2m_\ell)\) global assignments.  If \(\max_\ell b_\ell\le B\) for a fixed even \(B\), then \(m_\ell\le\binom{B}{B/2}/2\), the formulation has \(O(L)\) variables and \(JL\) bounded-order linear matrix inequalities, and hence has polynomial description size in \(J\) and \(L\).

When \(b_\ell=4\), \(\mathcal A_\ell=\{\pm v_1,\pm v_2,\pm v_3\}\), and \(H_\ell=[h_1\ h_2\ h_3]\) for every block, the result reduces exactly to the matched-quadruple order-three program.  Rank-one local kernels then give the established scalar linear program, and the homogeneous two-class menu gives the established piecewise closed form.  The productization conclusion requires \(G_j=\bigoplus_\ell G_{j\ell}\); it makes no claim for a kernel coupling distinct blocks.
