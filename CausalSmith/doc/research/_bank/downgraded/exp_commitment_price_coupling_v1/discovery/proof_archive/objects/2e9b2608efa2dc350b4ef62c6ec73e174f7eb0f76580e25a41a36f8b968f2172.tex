For any finite collection of heterogeneous even-sized blocks with explicitly listed nonempty centrally symmetric balanced local assignment supports, and any finite menu of nonzero direct-sum centered positive-semidefinite kernels, if every baseline-to-oracle gain denominator is positive, then \(\lambda_{\mathrm{het}}^\star\) is the optimum of the explicit local semidefinite program in \(\mathrm{thm:heterogeneous-block-psd-finite-class-frontier}\).  The program has \(1+\sum_\ell m_\ell\) scalar variables and one local LMI of order at most \(b_\ell-1\) per class--block pair, and the independent-block, independent-symmetric-sign law from any optimizer attains it.  Its description size is polynomial in the explicitly enumerated local support sizes and block dimensions; when the largest block size is fixed, it has \(O(L)\) variables and \(JL\) bounded-order LMIs.  The matched-quadruple theorem, rank-one LP, and homogeneous two-class piecewise formula are exact corollaries.  Arbitrary kernels coupling distinct blocks remain computable only through the separate exponential-column mass-simplex SDP and are not covered by productization.
