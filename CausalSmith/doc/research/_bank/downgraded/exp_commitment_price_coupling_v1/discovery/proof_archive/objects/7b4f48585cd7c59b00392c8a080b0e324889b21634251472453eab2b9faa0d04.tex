\textbf{Proof.}
Fix a class \(j\). For every block \(\ell\), choose any index
\[
k_\ell\in\arg\min_{1\le k\le3}d_{j\ell k}
\]
and set \(p_{\ell k_\ell}=1\), with the other two direction probabilities zero. This is a valid point of every block simplex; the product law in \(\mathrm{def:block\text{-}product\text{-}design}\) adds independent symmetric signs and therefore belongs to \(\Pi_n\). The risk formula in \(\mathrm{thm:block\text{-}specific\text{-}finite\text{-}class\text{-}frontier}\) gives
\[
R_j^{\mathrm{blk}}
=\frac4{n^2}\max_{1\le\ell\le q}
\sum_{k=1}^3d_{j\ell k}p_{\ell k}
=\frac4{n^2}\max_{1\le\ell\le q}
\min_{1\le k\le3}d_{j\ell k}
=\frac{4\bar r_j}{n^2}
=(r_j^{\mathrm{blk}})^\star.
\]
If \(b_j>\bar r_j\), the gain denominator is positive and this design has
\[
g_j^{\mathrm{blk}}
=\frac{B_j^{\mathrm{blk}}-(r_j^{\mathrm{blk}})^\star}
{B_j^{\mathrm{blk}}-(r_j^{\mathrm{blk}})^\star}=1.
\]
Conversely, oracle minimality implies \(R_j^{\mathrm{blk}}(\pi)\ge(r_j^{\mathrm{blk}})^\star\) for every design, so \(g_j^{\mathrm{blk}}(\pi)\le1\). The single-class commitment value is therefore exactly one, and any loss below one in the finite-class problem comes from simultaneously protecting incompatible classes. \(\square\)
