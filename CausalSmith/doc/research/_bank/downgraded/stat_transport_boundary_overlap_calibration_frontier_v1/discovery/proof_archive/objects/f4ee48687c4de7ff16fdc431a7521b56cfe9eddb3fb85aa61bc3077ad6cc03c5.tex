For this certificate use the following H\"older convention. Put \(p=\lceil s\rceil-1\) and \(\beta=s-p\in(0,1]\). For \(L>0\),
\[
\mathcal H^s(L)=\left\{v\in C^p([0,1]):
\max_{0\le r\le p}\|v^{(r)}\|_\infty\le L,
\quad
[v^{(p)}]_{\beta}:=\sup_{x\ne y}\frac{|v^{(p)}(x)-v^{(p)}(y)|}{|x-y|^\beta}\le L
\right\}.
\]
For integers \(n,m\ge2\) and \(h\in(0,1)\), let \(z_1<\cdots<z_N\) be the distinct sites among \(X_1,\ldots,X_n,X_1^T,\ldots,X_m^T\), and set
\[
c_\ell=\sum_{i:X_i=z_\ell}\Gamma_i(h,J_{\mu,n},J_{r,n})-
\frac1m\#\{j:X_j^T=z_\ell\}.
\]
Retain the abstract design discrepancy
\[
B_X(h,J_{\mu,n},J_{r,n})=
\sup_{\substack{v\in\mathcal H^s(2M)\\ \|v\|_\infty\le1}}
\left|\sum_{\ell=1}^Nc_\ell v(z_\ell)\right|.
\]
For each \(\sigma\in\{-1,1\}\), let \(V_\sigma\) be the optimal value of the finite linear program
\[
\operatorname{maximize}_{(u_{\ell,r})}\quad
\sigma\sum_{\ell=1}^Nc_\ell u_{\ell,0}
\]
over \(N(p+1)\) real variables \(u_{\ell,r}\), \(1\le\ell\le N\), \(0\le r\le p\), subject to
\[
|u_{\ell,0}|\le1,
\qquad
|u_{\ell,r}|\le2M\quad(1\le r\le p),
\]
and, for every \(1\le\ell,k\le N\) and \(0\le r\le p\),
\[
\left|u_{\ell,r}-\sum_{q=r}^p
u_{k,q}\frac{(z_\ell-z_k)^{q-r}}{(q-r)!}\right|
\le
2M\frac{\Gamma(\beta+1)}{\Gamma(s-r+1)}|z_\ell-z_k|^{s-r}.
\]
Each absolute-value restriction means its two one-sided linear inequalities. Define the certified jet-LP radius
\[
\overline B_X(h,J_{\mu,n},J_{r,n})=\max\{V_{-1},V_1\}.
\]
The two programs have \(N(p+1)\) variables and \(O\{N^2(p+1)\}\) linear inequalities, which is \(O(N^2p)\) for \(p\ge1\). Every admissible H\"older trace is feasible, so
\[
B_X(h,J_{\mu,n},J_{r,n})\le\overline B_X(h,J_{\mu,n},J_{r,n}).
\]
For \(0<s\le1\) the reduction is exact by H\"older--McShane extension. For \(s>1\) it is a certified conservative jet relaxation, not an asserted exact finite Whitney characterization. Both optimal values are finite because of the box constraints. No stochastic-order or frontier-order claim is part of this definition.
