Under the convention and notation of \(\mathrm{def:bias\text{-}envelope}\), every trace \(u_{\ell,r}=v^{(r)}(z_\ell)\) generated by \(v\in\mathcal H^s(2M)\) with \(\|v\|_\infty\le1\) is feasible for both signed jet linear programs. Consequently,
\[
B_X(h,J_{\mu,n},J_{r,n})\le\overline B_X(h,J_{\mu,n},J_{r,n}).
\]
The programs have \(N(p+1)\) variables and \(O\{N^2(p+1)\}\) linear inequalities. If \(0<s\le1\), every feasible zeroth-order jet has an admissible H\"older--McShane extension, so equality holds. For \(s>1\), only the displayed certified upper bound is claimed.
