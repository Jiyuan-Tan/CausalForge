For the H\"older convention and finite jet programs in \(\mathrm{def:bias\text{-}envelope}\),
\[
B_X(h,J_{\mu,n},J_{r,n})\le\overline B_X(h,J_{\mu,n},J_{r,n}).
\]
Each sign program has \(N(p+1)\) variables and \(O(N^2(p+1))\) linear inequalities. If \(0<s\le1\), equality holds. If \(s>1\), the displayed program remains a finite certified upper bound but is not claimed to be an exact Whitney extension characterization.
