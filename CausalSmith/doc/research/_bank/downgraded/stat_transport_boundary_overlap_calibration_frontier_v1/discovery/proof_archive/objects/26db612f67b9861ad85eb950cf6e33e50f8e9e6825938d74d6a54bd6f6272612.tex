\textbf{Proof.}
By \(\mathrm{lem:source\text{-}only\text{-}frontier\text{-}lower}\),
\[
\mathfrak R_{n,m}(a,s,t)\ge c_0\rho_n(a,s).
\]
The sample-balance assumption gives constants \(0<c_\kappa<C_\kappa<\infty\) such that
\[
c_\kappa n\le m\le C_\kappa n
\]
eventually, and hence \(m^{-1/2}\le c_\kappa^{-1/2}n^{-1/2}\). If \(a<1\), then \(\rho_n(a,s)=n^{-1/2}\). If \(a=1\), then \(\rho_n(a,s)=\sqrt{\log n/n}\ge n^{-1/2}\) eventually. If \(a>1\), then
\[
\frac{s+1}{2s+a+1}<\frac12,
\]
so again \(\rho_n(a,s)\ge n^{-1/2}\). Therefore
\[
m^{-1/2}+\rho_n(a,s)\le C\rho_n(a,s)
\le C'\mathfrak R_{n,m}(a,s,t),
\]
which proves the displayed one-sided phase diagram without a strict target-density-slack condition. The oracle-envelope assertion is exactly \(\mathrm{lem:oracle\text{-}truncation\text{-}envelope}\). No step in this proof supplies a measurable upper-bound witness. \(\square\)
