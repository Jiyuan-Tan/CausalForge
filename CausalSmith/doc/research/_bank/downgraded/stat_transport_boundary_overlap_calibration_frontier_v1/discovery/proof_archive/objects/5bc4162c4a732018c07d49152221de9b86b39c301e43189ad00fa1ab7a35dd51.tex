For each fold \(k\), bandwidth \(h\in(0,1)\), and regression knot-interval count \(J_{\mu,n}\), put \(d_{\mu,n}=J_{\mu,n}+q\) and define the observable interior ridge Gram matrix
\[
\widehat H_{k,h,J_{\mu,n}}
=\frac1{|\mathcal T^S_k|}\sum_{u\in\mathcal T^S_k}\mathbf 1\{X_u\ge h\}
\mathbf b_{h,J_{\mu,n}}(X_u)\mathbf b_{h,J_{\mu,n}}(X_u)^\top+n^{-2}I_{d_{\mu,n}}
\in\mathbb R^{d_{\mu,n}\times d_{\mu,n}}.
\]
For each source index \(q_0\in\{1,\ldots,n\}\), set
\[
L_{q_0,k,h,J_{\mu,n}}(x)=\frac{\mathbf 1\{q_0\in\mathcal T^S_k\}}{|\mathcal T^S_k|}
\begin{cases}
\mathbf 1\{X_{q_0}\le2h\}\mathbf R_h(x)^\top\widehat G_{k,h}^{-1}\mathbf R_h(X_{q_0}),&0\le x<h,\\
\mathbf 1\{X_{q_0}\ge h\}\mathbf b_{h,J_{\mu,n}}(x)^\top\widehat H_{k,h,J_{\mu,n}}^{-1}\mathbf b_{h,J_{\mu,n}}(X_{q_0}),&h\le x\le1.
\end{cases}
\]
For integers \(n,m\ge2\), every training complement in this display is nonempty. Finally define the observable coefficient of \(Z_{q_0}\) by
\[
\begin{aligned}
\Gamma_{q_0}(h,J_{\mu,n},J_{r,n})={}&
\frac1m\sum_{j=1}^mL_{q_0,k_T(j),h,J_{\mu,n}}(X_j^T)
+\frac1n\widehat r^{\mathrm{RICOT},(-k_S(q_0))}_{h,J_{r,n}}(X_{q_0})\mathbf 1\{X_{q_0}\ge h\}\\
&-\frac1n\sum_{i=1}^n
\widehat r^{\mathrm{RICOT},(-k_S(i))}_{h,J_{r,n}}(X_i)\mathbf 1\{X_i\ge h\}
L_{q_0,k_S(i),h,J_{\mu,n}}(X_i).
\end{aligned}
\]
The regression matrices have dimension \(d_{\mu,n}=J_{\mu,n}+q\). The weight construction uses \(d_{r,n}=J_{r,n}+q\) standard B-splines and \(d_{r,n}-1\) nonconstant calibration coordinates. All matrices are invertible because of the positive ridges, and every displayed quantity is a measurable function of the observed source and target covariates. This construction only names the coefficients; the exact estimator identity is proved in \(\mathrm{thm:ricot\text{-}attainment}\).
