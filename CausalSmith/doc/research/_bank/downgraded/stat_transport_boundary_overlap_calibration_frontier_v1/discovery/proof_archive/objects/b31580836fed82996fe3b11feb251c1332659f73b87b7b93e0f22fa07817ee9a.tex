For \(h\in(0,1/2]\) and \(J\in\mathbb N\), define the source boundary and preconditioned interior moments
\[
\widehat G_B(h)=\frac1n\sum_{i=1}^n\mathbf 1\{X_i<2h\}\mathbf R_h(X_i)\mathbf R_h(X_i)^\top,
\quad
\widehat s_B(h)=\frac1n\sum_{i=1}^n\mathbf 1\{X_i<2h\}\mathbf R_h(X_i)Z_i,
\]
\[
\widehat G_I(h,J)=\frac1n\sum_{i=1}^n\mathbf 1\{X_i\ge h\}X_i^{-a}\mathbf b_{h,J}(X_i)\mathbf b_{h,J}(X_i)^\top,
\quad
\widehat s_I(h,J)=\frac1n\sum_{i=1}^n\mathbf 1\{X_i\ge h\}X_i^{-a}\mathbf b_{h,J}(X_i)Z_i.
\]
Put
\[
H_{a,p}=\int_0^2u^a\mathbf R_1(u)\mathbf R_1(u)^\top\,du,
\quad
L_{h,J}=\int_h^1\mathbf b_{h,J}(x)\mathbf b_{h,J}(x)^\top\,dx.
\]
The observable Gram branch \(\mathcal E^G_{n}(h,J)\) is the event
\[
\lambda_{\min}\{\widehat G_B(h)\}\ge\frac{c_{S,-}}2h^{a+1}\lambda_{\min}(H_{a,p}),
\qquad
\lambda_{\min}\{\widehat G_I(h,J)\}\ge\frac{c_{S,-}}2\lambda_{\min}(L_{h,J}).
\]
On \(\mathcal E^G_n(h,J)\), set
\[
\widehat\alpha_h=\widehat G_B(h)^{-1}\widehat s_B(h),
\qquad
\widehat\beta_{h,J}=\widehat G_I(h,J)^{-1}\widehat s_I(h,J),
\]
and otherwise set both coefficient vectors equal to zero.  Define the pure source outcome-regression fit
\[
\widehat\mu_{h,J}(x)=
\begin{cases}
\mathbf R_h(x)^\top\widehat\alpha_h,&0\le x<h,\\
\mathbf b_{h,J}(x)^\top\widehat\beta_{h,J},&h\le x\le1.
\end{cases}
\]
All inverses are therefore taken only on an observable positive-eigenvalue branch.  The deterministic dimension is
\[
J_n=\left\lceil\rho_n(a,s)^{-1/(s+t)}\right\rceil,
\]
where the ordinary ceiling convention resolves an integer tie by returning that integer.
