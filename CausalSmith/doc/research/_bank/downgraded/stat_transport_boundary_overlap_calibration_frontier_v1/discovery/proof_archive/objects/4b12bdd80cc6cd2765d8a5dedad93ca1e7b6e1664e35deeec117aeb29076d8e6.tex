Using only the displayed bias, multiplier-envelope, and standard-error statistics, define, when \(\widehat{\mathrm{se}}_{h,J_{\mu,n},J_{r,n}}>0\),
\[
\mathcal I_{h,J_{\mu,n},J_{r,n}}=\left[\widehat\tau^{\mathrm{sp}}_{h,J_{\mu,n},J_{r,n}}\pm\operatorname{cv}_{1-\gamma/2}\!\left(\frac{\widehat B_{h,J_{\mu,n},J_{r,n}}+\widehat E_{h,J_{\mu,n},J_{r,n}}}{\widehat{\mathrm{se}}_{h,J_{\mu,n},J_{r,n}}}\right)\widehat{\mathrm{se}}_{h,J_{\mu,n},J_{r,n}}\right].
\]
If \(\widehat{\mathrm{se}}_{h,J_{\mu,n},J_{r,n}}=0\), define
\[
\mathcal I_{h,J_{\mu,n},J_{r,n}}=\left[\widehat\tau^{\mathrm{sp}}_{h,J_{\mu,n},J_{r,n}}-(\widehat B_{h,J_{\mu,n},J_{r,n}}+\widehat E_{h,J_{\mu,n},J_{r,n}}),\ \widehat\tau^{\mathrm{sp}}_{h,J_{\mu,n},J_{r,n}}+(\widehat B_{h,J_{\mu,n},J_{r,n}}+\widehat E_{h,J_{\mu,n},J_{r,n}})\right].
\]
This is the finite continuous extension of the bias-aware radius and is a singleton if both envelopes vanish.
