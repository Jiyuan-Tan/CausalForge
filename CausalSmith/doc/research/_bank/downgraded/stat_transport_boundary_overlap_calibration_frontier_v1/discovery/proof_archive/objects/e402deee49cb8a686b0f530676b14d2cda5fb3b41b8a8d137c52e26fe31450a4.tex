On \(\mathcal E_{n,m}(h)\cap\{\widehat{\mathrm{se}}_{h,J_{\mu,n},J_{r,n}}>0\}\), define
\[
 \mathcal I_{h,J_{\mu,n},J_{r,n}}
 =\left[
 \widehat\tau^{\mathrm{sp}}_{h,J_{\mu,n},J_{r,n}}
 \pm
 \left\{\widehat B_{h,J_{\mu,n},J_{r,n}}
 +\operatorname{cv}_{1-\gamma/2}(0)
 \widehat{\mathrm{se}}_{h,J_{\mu,n},J_{r,n}}\right\}
 \right].
\]
On the observable complementary event, including a zero standard error, set
\[
 \mathcal I_{h,J_{\mu,n},J_{r,n}}=[-1,1].
\]
Thus the rare-event branch always contains the parameter space and the good branch uses only the estimator, the analytic fixed-class bias envelope, the complete sandwich standard error, and the zero-bias value of the declared critical-value map.  The additive envelope is intentionally robust to dependence between the bounded remainder and the linear term.
