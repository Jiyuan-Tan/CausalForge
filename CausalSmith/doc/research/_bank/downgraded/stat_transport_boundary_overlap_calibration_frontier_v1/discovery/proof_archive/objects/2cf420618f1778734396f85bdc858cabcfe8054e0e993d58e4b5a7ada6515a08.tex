\textbf{Proof.}
By \(\mathrm{lem:source\text{-}only\text{-}frontier\text{-}lower}\), there is a constant \(c_0>0\), independent of \(n\) and \(m\), such that for all sufficiently large \(n\),
\[
\mathfrak R_{n,m}(a,s,t)\ge c_0\rho_n(a,s).
\]
This application is valid under the stated restrictions \(M\ge a+1\), \(t>1/2\), and
\[
\frac{s}{2s+1}+\frac{t}{2t+1}>\frac12.
\]
The lower-bound construction in that lemma uses the target density \(f_T=1\). The declared ranges \(c_{T,-}\le 1\le c_{T,+}\) therefore show that the construction belongs to the class even when either target-density bound is attained. Hence no strict slack in the target-density inequalities is required.

By \(\mathrm{ass:sample\text{-}balance}\), \(m/n\to\kappa\in(0,\infty)\). Thus there are constants \(c_\kappa,C_\kappa>0\) and an integer \(n_0\) such that
\[
c_\kappa n\le m\le C_\kappa n
\]
whenever \(n\ge n_0\). In particular,
\[
m^{-1/2}\le c_\kappa^{-1/2}n^{-1/2}.
\]
We compare \(n^{-1/2}\) with the three branches of \(\rho_n(a,s)\). If \(a<1\), then \(\rho_n(a,s)=n^{-1/2}\). If \(a=1\), then for all sufficiently large \(n\),
\[
\rho_n(1,s)=\sqrt{\frac{\log n}{n}}\ge n^{-1/2}.
\]
If \(a>1\), then \(s>0\) and \(a>1\) imply
\[
\frac{s+1}{2s+a+1}<\frac12,
\]
so
\[
\rho_n(a,s)=n^{-(s+1)/(2s+a+1)}\ge n^{-1/2}.
\]
Consequently, in every regime there is a finite constant \(C_1\), depending only on the fixed parameters and \(\kappa\), such that eventually
\[
m^{-1/2}+\rho_n(a,s)\le C_1\rho_n(a,s).
\]
Combining the last display with the source-only lower bound yields
\[
\mathfrak R_{n,m}(a,s,t)
\ge \frac{c_0}{C_1}\{m^{-1/2}+\rho_n(a,s)\}.
\]
Expanding the definition of \(\rho_n(a,s)\) gives the first displayed lower bound in the theorem, with \(c=c_0/C_1>0\).

Finally, \(\mathrm{lem:oracle\text{-}truncation\text{-}envelope}\) gives, uniformly over \(\mathbb P_{n,m}\in\mathcal M_{n,m}(a,s,t)\),
\[
m^{-1/2}+h_n^{s+1}+n^{-1/2}
\left\|r\mathbf 1\{X\ge h_n\}\right\|_{L^2(P_S)}
\asymp m^{-1/2}+\rho_n(a,s).
\]
This is an order identity for the deterministic boundary approximation term and the exact truncated source representer. Neither term defines a measurable data-driven estimator, so this identity supplies only the stated oracle benchmark and does not establish a minimax upper bound. \(\square\)
