Using the deterministic fold maps and the direct-series training-complement fits, define
\[
\widehat\tau^{\mathrm{sp}}_{h,J_{\mu,n},J_{r,n}}
=\frac1m\sum_{j=1}^m\widehat\mu^{(-k_T(j))}_{h,J_{\mu,n}}(X_j^T)
+\frac1n\sum_{i=1}^n\mathbf 1\{X_i\ge h\}\widehat r^{\mathrm{DS},(-k_S(i))}_{h,J_{r,n}}(X_i)
\left\{Z_i-\widehat\mu^{(-k_S(i))}_{h,J_{\mu,n}}(X_i)\right\}.
\]
Every evaluation is held out from the fit used there.  The target plug-in includes the boundary local-polynomial extrapolation, while the correction term is confined to \([h,1]\).  The estimator is an explicit measurable map of \(\mathcal D_{n,m}\).
