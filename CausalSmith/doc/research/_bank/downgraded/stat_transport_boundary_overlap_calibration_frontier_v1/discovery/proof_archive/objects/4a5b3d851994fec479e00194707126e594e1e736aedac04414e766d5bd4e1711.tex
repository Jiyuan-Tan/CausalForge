\textbf{Proof.}
Let
\[
\mathsf D_{n,m}
=\bigl(\mathcal X\times\{0,1\}\times[0,1]\bigr)^n\times\mathcal X^m
\]
carry its product Borel \(\sigma\)-field. An interval-valued statistic must, at a minimum, be a single-valued measurable map
\[
T_{n,m}:\mathsf D_{n,m}\longrightarrow
\bigl\{[\ell,u]:\ell,u\in\mathbb R,\ \ell\le u\bigr\}.
\]
Equivalently, it must specify measurable endpoint functions \(L_{n,m}\) and \(U_{n,m}\) satisfying
\[
T_{n,m}(d)=[L_{n,m}(d),U_{n,m}(d)]
\quad\text{and}\quad
L_{n,m}(d)\le U_{n,m}(d)
\]
for every realized data array \(d\in\mathsf D_{n,m}\).

By \(\mathrm{def:adaptive\text{-}handle}\), the candidate family is
\[
\left\{\mathcal I_{h,J_{\mu,n},J_{r,n}}:
h\text{ is an admissible dyadic boundary bandwidth}\right\}.
\]
The construction instructs the user to form adjacent-scale boundary local-polynomial differences, to estimate \(a\) from empirical masses of dyadic boundary shells, and to combine these quantities with interior Riesz-calibration residuals. It gives no formula for a measurable estimator of \(a\) or of the boundary regularity, no numerical threshold for an adjacent-scale comparison, no rule mapping the resulting diagnostics to one admissible dyadic \(h\), and no convention for choosing among multiple admissible candidates.

Consequently, the construction specifies neither endpoint functions \(L_{n,m},U_{n,m}\) nor an equivalent measurable bandwidth selector
\[
\widehat h_{n,m}:\mathsf D_{n,m}\longrightarrow
\{h:h\text{ is an admissible dyadic boundary bandwidth}\}
\]
such that
\[
T_{n,m}(d)
=\mathcal I_{\widehat h_{n,m}(d),J_{\mu,n},J_{r,n}}(d).
\]
Equivalently, it does not specify a measurable selected triple
\[
\bigl(\widehat h_{n,m},J_{\mu,n},J_{r,n}\bigr).
\]

This is a definitional obstruction, not a stochastic remainder. Assumption \(\mathrm{ass:boundary\text{-}self\text{-}similarity}\) restricts a member law; it does not itself select a bandwidth for a realized data array. The written handle is compatible with distinct completions that choose different dyadic bandwidths whenever several candidates satisfy an unspecified comparison, and the handle selects none of those completions. Hence it does not define a single interval-valued statistic.

Because the handle defines no random interval \(T_{n,m}\), neither
\[
\mathbb P_{n,m}\!\left\{\tau\in T_{n,m}(\mathcal D_{n,m})\right\}
\]
nor
\[
\mathbb E_{\mathbb P_{n,m}}\!\left[
U_{n,m}(\mathcal D_{n,m})-L_{n,m}(\mathcal D_{n,m})
\right]
\]
is an evaluable quantity attached to \(\mathrm{def:adaptive\text{-}handle}\). The frozen handle therefore yields neither an adaptive coverage guarantee nor an adaptive expected-length guarantee. A positive result first requires explicit measurable diagnostics, numerical thresholds, a single-valued dyadic-bandwidth selection rule, and deterministic tie breaking. This proves the theorem. \(\square\)
