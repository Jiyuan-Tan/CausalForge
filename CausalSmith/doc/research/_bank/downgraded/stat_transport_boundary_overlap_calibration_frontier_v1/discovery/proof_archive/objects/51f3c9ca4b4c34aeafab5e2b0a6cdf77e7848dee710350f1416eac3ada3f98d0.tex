Conditionally on \(\mathcal D_{n,m}\), let \(\mathbb P^*\) make \(\{\zeta_i^S:i=1,\ldots,n\}\) and \(\{\zeta_j^T:j=1,\ldots,m\}\) mutually independent standard-normal variables. For \(v\in\mathcal H^s(1)\), define the fold-centered calibration process \[\begin{aligned}\mathbb G^{\mathrm{cal},*}_{h,J}(v)={}&\frac1m\sum_{k=1}^{K_0}\sum_{j\in\mathcal V^T_k}\zeta_j^T\left[v(X_j^T)\mathbf 1\{X_j^T\ge h\}-\frac1{N_k^T}\sum_{\ell\in\mathcal V^T_k}v(X_\ell^T)\mathbf 1\{X_\ell^T\ge h\}\right]\\&-\frac1n\sum_{k=1}^{K_0}\sum_{i\in\mathcal V^S_k}\zeta_i^S\left[\widehat r^{\mathrm{RICOT},(-k)}_{h,J}(X_i)v(X_i)\mathbf 1\{X_i\ge h\}-\frac1{N_k^S}\sum_{\ell\in\mathcal V^S_k}\widehat r^{\mathrm{RICOT},(-k)}_{h,J}(X_\ell)v(X_\ell)\mathbf 1\{X_\ell\ge h\}\right].\end{aligned}\] Define the boundary contribution, using the exact local-polynomial linear summand from \(\mathrm{def:foldwise\text{-}inference\text{-}statistics}\), by \[\mathbb G^{\mathrm{bd},*}_{h,J}=\frac1n\sum_{k=1}^{K_0}\sum_{i\in\mathcal V^S_k}\zeta_i^S\left[\widehat U^B_{i,h,J}-\frac1{N_k^S}\sum_{\ell\in\mathcal V^S_k}\widehat U^B_{\ell,h,J}\right].\] The computable random envelope is \[\widehat E_{h,J}=\inf\left\{e\ge0:\mathbb P^*\left(\sup_{v\in\mathcal H^s(1)}\left|2M\mathbb G^{\mathrm{cal},*}_{h,J}(v)+\mathbb G^{\mathrm{bd},*}_{h,J}\right|\le e\,\middle|\,\mathcal D_{n,m}\right)\ge1-\gamma/2\right\}.\] Empty-fold averages are zero; with the deterministic modulo allocation they are absent once \(n,m\ge K_0\). The same source multipliers appear in both source pieces, so their covariance is retained, while all target multipliers are independent of all source multipliers.
