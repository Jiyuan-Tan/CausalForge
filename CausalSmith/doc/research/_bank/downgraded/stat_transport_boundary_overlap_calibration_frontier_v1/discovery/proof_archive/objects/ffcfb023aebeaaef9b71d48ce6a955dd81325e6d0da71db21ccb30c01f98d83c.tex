For \(i\in\mathcal T^S_1\), let \(L_{i,h}(x)\) be the coefficient of \(Z_i\) in the linear fit \(\widehat\mu_{h,J_{\mu,n}}(x)\):
\[
 L_{i,h}(x)=\frac1{|\mathcal T^S_1|}
 \begin{cases}
 \mathbf 1\{X_i\le2h\}\mathbf R_h(x)^\top
 (\widehat G^{\mathrm{bd}}_h+\lambda_nI)^{-1}\mathbf R_h(X_i),&x<h,\\
 \mathbf 1\{X_i\ge h\}X_i^{-a}\mathbf b_{h,J_{\mu,n}}(x)^\top
 (\widehat G^{\mu}_{h,J_{\mu,n}}+\lambda_nI)^{-1}
 \mathbf b_{h,J_{\mu,n}}(X_i),&x\ge h.
 \end{cases}
\]
Set \(L_{i,h}=0\) for \(i\notin\mathcal T^S_1\).  On \(\mathcal E_{n,m}(h)\), define the complete realized source coefficient
\[
 \Gamma_{i,h}=\begin{cases}
 (N^S_1)^{-1}\mathbf 1\{X_i\ge h\}\widehat r^{\mathrm{DS}}_{h,J_{r,n}}(X_i),&i\in\mathcal V^S_1,\\
 (N^T_1)^{-1}\displaystyle\sum_{j\in\mathcal V^T_1}L_{i,h}(X_j^T)
 -(N^S_1)^{-1}\displaystyle\sum_{\ell\in\mathcal V^S_1}
 \mathbf 1\{X_\ell\ge h\}\widehat r^{\mathrm{DS}}_{h,J_{r,n}}(X_\ell)L_{i,h}(X_\ell),&i\in\mathcal T^S_1.
 \end{cases}
\]
On the complementary event set every \(\Gamma_{i,h}=0\).  Direct substitution gives the exact identity \(\widehat\tau^{\mathrm{sp}}_{h,J_{\mu,n},J_{r,n}}=\sum_{i=1}^n\Gamma_{i,h}Z_i\) on the good branch.  Define
\[
 \widehat\epsilon_i=Z_i-\widehat\mu^{(-i)}_{h,J_{\mu,n}}(X_i),
 \qquad
 \overline\mu_T=(N^T_1)^{-1}\sum_{j\in\mathcal V^T_1}
 \widehat\mu_{h,J_{\mu,n}}(X_j^T),
\]
and
\[
 \widehat{\mathrm{se}}_{h,J_{\mu,n},J_{r,n}}^2
 =\sum_{i=1}^n\Gamma_{i,h}^2\widehat\epsilon_i^2
 +\frac1{N^T_1(N^T_1-1)}\sum_{j\in\mathcal V^T_1}
 \{\widehat\mu_{h,J_{\mu,n}}(X_j^T)-\overline\mu_T\}^2,
\]
with the second term set to zero if \(N^T_1\le1\).  Since \(\Gamma_{i,h}\) is the coefficient of the entire source pseudo-outcome, the first sum contains all covariance among the direct residual correction, interior regression, and boundary regression pieces without an omitted cross term.
