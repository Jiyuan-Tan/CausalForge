On \(\mathcal E^G_n(h,J)\), define the target loading vectors
\[
\widehat l_B(h)=\frac1m\sum_{j=1}^m\mathbf 1\{X_j^T<h\}\mathbf R_h(X_j^T),
\qquad
\widehat l_I(h,J)=\frac1m\sum_{j=1}^m\mathbf 1\{X_j^T\ge h\}\mathbf b_{h,J}(X_j^T),
\]
and, for \(i=1,\ldots,n\),
\[
\Gamma_i(h,J)=\frac1n\left[
\mathbf 1\{X_i<2h\}\widehat l_B(h)^\top\widehat G_B(h)^{-1}\mathbf R_h(X_i)
+\mathbf 1\{X_i\ge h\}X_i^{-a}\widehat l_I(h,J)^\top\widehat G_I(h,J)^{-1}\mathbf b_{h,J}(X_i)
\right].
\]
Set all loadings and coefficients to zero off \(\mathcal E^G_n(h,J)\).  Define
\[
V_a(h)=1+\log(1/h)\mathbf 1\{a=1\}+h^{1-a}\mathbf 1\{a>1\}.
\]
For the fixed explicit certificate constant \(C_\Gamma\) in the symbol table, the observable good branch is
\[
\mathcal E_{n,m}(h,J)=\mathcal E^G_n(h,J)\cap
\left\{\sum_{i=1}^n\Gamma_i(h,J)^2\le \frac{C_\Gamma V_a(h)}n,\quad
\sum_{i=1}^n|\Gamma_i(h,J)|\le C_\Gamma,\quad
\frac{\max_i\Gamma_i(h,J)^2}{\sum_i\Gamma_i(h,J)^2}\le\frac1{\log(en)}\right\},
\]
where the displayed ratio is defined to be zero when its denominator is zero.  Every condition is a measurable function of the observed covariates, and no outcome, density estimate, density-ratio estimate, transport plan, dual variable, or calibration residual enters this branch.
