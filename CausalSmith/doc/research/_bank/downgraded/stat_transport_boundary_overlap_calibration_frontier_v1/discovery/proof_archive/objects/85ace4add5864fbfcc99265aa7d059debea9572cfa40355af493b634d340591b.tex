Using the fold maps \(k_S\) and \(k_T\) and the unique training-complement fits from \(\mathrm{def:regression\text{-}fit}\) and \(\mathrm{def:ricot\text{-}weights}\), define \[\widehat\tau^{\mathrm{sp}}_{h,J}=\frac1m\sum_{j=1}^m\widehat\mu_h^{(-k_T(j))}(X_j^T)+\frac1n\sum_{i=1}^n\widehat r^{\mathrm{RICOT},(-k_S(i))}_{h,J}(X_i)\mathbf 1\{X_i\ge h\}\{Z_i-\widehat\mu_h^{(-k_S(i))}(X_i)\}.\] Thus each displayed evaluation uses a fit trained without that observation's deterministic fold. The dual extension is evaluated as a function at held-out \(X_i\), so the residual correction is not an empirical-support lookup. If an interior training measure is empty, its weight contribution is zero by \(\mathrm{def:ricot\text{-}weights}\).
