The sibling-owned \(\mathrm{prop:calibrated\text{-}direct\text{-}rate\text{-}bracket}\) proves, for all sufficiently large \(n\),
\[
c_{\mathrm{lb}}n^{-2\gamma/(2\gamma+d)}
\le\mathfrak R_n(1,\gamma;\kappa)
\le C_{\mathrm{ub}}n^{-2\min\{\beta,\gamma\}/\{2\min\{\beta,\gamma\}+d\}}.
\]
In particular, if \(\beta\ge\gamma\), the high-smoothness branch necessarily applies and the question is completely answered there:
\[
\mathfrak R_n(1,\gamma;\kappa)\asymp(r_n^*)^2.
\]
If \(\beta<\gamma\), the same result supplies the honest bracket with upper endpoint \(C_{\mathrm{ub}}n^{-2\beta/(2\beta+d)}\), but exactness remains unresolved.
