For all sufficiently large \(n\), the established direct bracket is
\[
c n^{-2\gamma/(2\gamma+d)}
\le \mathfrak R_n(1,\gamma;\kappa)
\le C n^{-2\min\{\beta,\gamma\}/\{2\min\{\beta,\gamma\}+d\}}.
\]
When \(\beta\ge\gamma\), this condition forces the high-smoothness branch of \(r_n^*\), the endpoints coincide, and \(\mathfrak R_n(1,\gamma;\kappa)\asymp(r_n^*)^2\). When \(\beta<\gamma\), the displayed bracket is the strongest result currently proved for the calibrated uniform-design class.
