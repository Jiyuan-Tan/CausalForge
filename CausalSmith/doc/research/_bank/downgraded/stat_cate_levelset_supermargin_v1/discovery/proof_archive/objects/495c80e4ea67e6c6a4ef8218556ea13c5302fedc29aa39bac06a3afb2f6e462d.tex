The sibling-owned proposition \(\mathrm{prop:calibrated\text{-}direct\text{-}rate\text{-}bracket\) proves, for all sufficiently large \(n\), \[c_{\mathrm{lb}}n^{-2\gamma/(2\gamma+d)}\le\mathfrak R_n(1,\gamma;\kappa)\le C_{\mathrm{ub}}n^{-2\min\{\beta,\gamma\}/\{2\min\{\beta,\gamma\}+d\}}.\] Because \(\beta\) is frozen in \(\kappa\), this completely answers the subregime \(\beta\ge\gamma\): that subregime is necessarily in the high-smoothness branch and \(\mathfrak R_n(1,\gamma;\kappa)\asymp(r_n^*)^2\). For \(\beta<\gamma\), the same proposition supplies the honest bracket \[c_{\mathrm{lb}}n^{-2\gamma/(2\gamma+d)}\le\mathfrak R_n(1,\gamma;\kappa)\le C_{\mathrm{ub}}n^{-2\beta/(2\beta+d)},\] but it does not resolve the OEQ.
