Fix a calibrated \(\kappa\) and \(\gamma>d\). By \(\mathrm{def:transverse-model}\), \(\mathcal M_{\mathrm{tr}}(\gamma;\kappa)=\mathcal M(1,\gamma;\kappa)\). The class is nonempty by \(\mathrm{thm:calibrated-witness}\), and \(\mathrm{thm:identified-version}\) shows that its causal upper set and weighted loss are observed-law objects modulo null sets.

The construction in \(\mathrm{def:boundary-adapted-estimator}\) is one law-independent measurable estimator. The uniform-design, local-Gram, spline-approximation, and estimator-construction lemmas verify uniformly over the calibrated class all hypotheses of \(\mathrm{lem:bkk-level-set-upper-cited}\). Applying that cited theorem with \(\xi=1\) gives, in each branch of \(r_n^*\),
\[
\sup_{P\in\mathcal M_{\mathrm{tr}}(\gamma;\kappa)}
\mathbb E_P\!\left[d_H(\widehat G_n^{\mathrm{LP}},G_P;P)\right]
\le C_1(r_n^*)^2
\]
for all sufficiently large \(n\), where \(C_1\) depends only on the fixed calibrated constants and smoothness indices. Taking the infimum over all measurable set estimators and using \(\mathrm{def:minimax-risk}\) yields
\[
\mathfrak R_n(1,\gamma;\kappa)\le C_1(r_n^*)^2.
\]
The first display proves that \(\widehat G_n^{\mathrm{LP}}\) attains this upper inequality in both branches. No converse is used or claimed.
