Fix \((C,D)\in\mathfrak F_{\mathrm{hard}}^\circ(5,\eta)\), fix an admissible \(\epsilon\), and fix \(P\in\mathcal H_{5,C,D,\eta,\epsilon}\). By \(\text{def:explicit-hard-family}\),
\[
k=\left\lfloor\frac{5-1}{2}\right\rfloor=2.
\]
Because \(d=5\) is odd, the public feature space has the orthonormal basis
\[
e_0,u_1,w_1,u_2,w_2,
\]
and there is no auxiliary vector \(z\). For each \(j\in\{1,2\}\), the same definition fixes the two informative action features at \(x_j\) as
\[
\phi(x_j,+)=\frac{u_j+w_j}{\sqrt2},
\qquad
\phi(x_j,-)=\frac{u_j-w_j}{\sqrt2}.
\]
Orthonormality gives
\[
\begin{aligned}
\langle u_j,\phi(x_j,+)\rangle&=2^{-1/2},&
\langle w_j,\phi(x_j,+)\rangle&=2^{-1/2},\\
\langle u_j,\phi(x_j,-)\rangle&=2^{-1/2},&
\langle w_j,\phi(x_j,-)\rangle&=-2^{-1/2}.
\end{aligned}
\]
All four coefficients are nonzero. Hence each of the two action features uses both latent directions \(u_j\) and \(w_j\), and the two actions use the same pair of latent directions. Moreover, neither vector is one of the displayed coordinate-basis vectors: each has two nonzero coordinates in that basis, whereas a coordinate-basis vector has exactly one.

The construction also cannot be the canonical tabular specialization. Indeed, it contains the three distinct contexts \(x_C,x_1,x_2\) and the action set \(\{+,-,0\}\), so \(|S|\ge 9>5=d\); canonical tabular features would instead require \(d=|S|\) and one distinct vector \(e_{(x,a)}\in\mathbb R^{|S|}\) for every cell. Finally, the feature map is part of the fixed public experiment and is identical for every sign index \(v\) and every resulting Bernoulli law in \(\mathcal H_{5,C,D,\eta,\epsilon}\). Therefore the preceding shared-feature and non-tabular conclusions hold for every member of that family.
