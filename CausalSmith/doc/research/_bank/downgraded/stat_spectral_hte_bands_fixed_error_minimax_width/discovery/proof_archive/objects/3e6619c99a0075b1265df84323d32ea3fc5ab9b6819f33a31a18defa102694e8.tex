For fixed \(P\), \(g\in\mathcal G\), and bounded \(g'\), the infimum over \(d\in\mathcal D_{\gamma_D,L_D}\) in \(d_P(g,g')\) is attained.  If
\[
 d_P^{\mathrm{dir}}(g,g')=operatorname*{ess\,sup}_{v\in[0,1]}
 E_P[|g'(X,V)-g(X,V)|\mid V=v],
\]
\[
 \Gamma_{\mathrm{dir}}(P,\varepsilon_0)
 =\{g\in\mathcal G:d_P^{\mathrm{dir}}(g,g_0)\le\varepsilon_0\},
 \qquad
 a_{\mathcal G}^{\mathrm{dir}}(P)=\inf_{g\in\mathcal G}d_P^{\mathrm{dir}}(g,g_0),
\]
then \(\Gamma_{\mathrm{dir}}(P,\varepsilon_0)\subseteq\Gamma(P,\varepsilon_0)\) and \(a_{\mathcal G}(P)\le a_{\mathcal G}^{\mathrm{dir}}(P)\).  If \(a_{\mathcal G}(P)\le\varepsilon_{\mathrm{app}}<\varepsilon_0\), then \(\Gamma(P,\varepsilon_0)\ne\varnothing\).  Moreover, if \(g_0=0\), \(\varepsilon_0<a\le C_g\), and \(\mathcal G\) contains the constant code \(g_a(x,v)=-a\), then \(g_a\in\Gamma(P,\varepsilon_0)\setminus\Gamma_{\mathrm{dir}}(P,\varepsilon_0)\).
