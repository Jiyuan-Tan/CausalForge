Let
\[
 \Gamma_{\mathrm{dir}}(P,\varepsilon_0)
 =\{g\in\mathcal G:d_P(g,g_0)\le\varepsilon_0\},
 \qquad
 a_{\mathrm{dir}}(P)=\inf_{g\in\mathcal G}d_P(g,g_0).
\]
Then \(\Gamma_{\mathrm{dir}}(P,\varepsilon_0)\subseteq\Gamma(P,\varepsilon_0)\) and \(a_{\mathcal G}(P)\le a_{\mathrm{dir}}(P)\). Moreover, the inclusion can be strict: if \(g_0=0\), \(\varepsilon_0<a\le C_g\), and \(\mathcal G\) contains the constant code \(g_a(x,v)=-a\), then \(g_a\in\Gamma(P,\varepsilon_0)\setminus\Gamma_{\mathrm{dir}}(P,\varepsilon_0)\).
