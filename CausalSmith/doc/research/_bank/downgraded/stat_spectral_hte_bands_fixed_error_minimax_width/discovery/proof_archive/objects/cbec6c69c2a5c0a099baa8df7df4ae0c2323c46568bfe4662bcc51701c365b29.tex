Put
\[
 R_{\mathrm z}=(2^{k+4}k!)^{1/(k-2)}
 (\psi_\eta^2/\delta)^{1/(k-2)},\qquad R_+=R_{\mathrm z}+1,
\]
\[
 U_\psi=\lceil\max\{1,\psi_\eta\}\rceil,\qquad
 U_R=\lceil\max\{1,R_+\}\rceil,\qquad
 N_{\mathrm{cert}}=4U_\psi^2(U_R+2)^3,\qquad
 m_\circ=N_{\mathrm{cert}}+3.
\]
For \(q=0,\ldots,2^{m_\circ-1}\), set
\[
 \rho_q=R_{\mathrm z}+\frac14+q2^{-m_\circ},
 \qquad C_q=\{z\in\mathbb C:|z|=\rho_q\},
 \qquad \mathfrak C_0=\{C_q:0\le q\le2^{m_\circ-1}\},
\]
and set \(R_0=R_{\mathrm z}+3/4=\max_q\rho_q\).  Define
\[
 e_\circ=8U_RU_\psi^2(U_R+1)^2,\qquad
 d_\circ^{\mathrm{den}}=3(2U_R+1),
\]
\[
 u_\circ=2e_\circ+N_{\mathrm{cert}}(m_\circ+d_\circ^{\mathrm{den}}),
 \qquad \rho_M=2^{-u_\circ}>0,
\]
and, with \(A_M=\exp\{4\psi_\eta^2(R_0+1)^2\}\),
\[
 \Lambda_0=2\pi R_0\{1+2A_M+A_M/\rho_M\}.
\]
This finite noise-only construction uses no code, code-error radius, represented-data convention, or query to the unknown law.
