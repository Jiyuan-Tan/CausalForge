For \(n\ge2\), put \(n_1=\lfloor n/2\rfloor\), \(n_2=n-n_1\), split the indices deterministically into a pilot set \(I_1\) and an inference set \(I_2\), and put \(w_{i,v}=h_n^{-1}K((V_i-v)/h_n)\).  Fix \(v_{\mathrm{ref}}\in(v_-,v_+)\).  On the pilot define, for every bank circle \(C_j\),
\[
 \widehat F_{1j,v}(z)=n_1^{-1}\sum_{i\in I_1}w_{i,v}e^{zZ_{n,i}},\qquad
 \partial_z\widehat F_{1j,v_{\mathrm{ref}}}(z)
 =n_1^{-1}\sum_{i\in I_1}w_{i,v_{\mathrm{ref}}}Z_{n,i}e^{zZ_{n,i}}.
\]
Let \(\widehat j_n\) be the smallest \(j\) for which
\[
 \inf_{v\in\mathcal I,z\in C_j}|\widehat F_{1j,v}(z)|
 \ge5\rho_F/4,
 \qquad
 \widehat m_j=(2\pi i)^{-1}\oint_{C_j}
 \frac{\partial_z\widehat F_{1j,v_{\mathrm{ref}}}(z)}
 {\widehat F_{1j,v_{\mathrm{ref}}}(z)}\,dz
 \in\mathbb Z\setminus\{0\};
\]
set \(\widehat j_n=\varnothing\) if no such index exists.  On \(I_2\), for the selected \(j\), define
\[
 \widehat F_{2j,v}(z)=n_2^{-1}\sum_{i\in I_2}w_{i,v}e^{zZ_{n,i}},\qquad
 \widehat G_{2j,v}(z)=n_2^{-1}\sum_{i\in I_2}w_{i,v}Y_i e^{zZ_{n,i}}.
\]
If \(\inf_{v\in\mathcal I,z\in C_j}|\widehat F_{2j,v}(z)|<\rho_F/2\), return \([-C_\tau,C_\tau]\).  Otherwise define
\[
 \widehat\tau_n(v)=\operatorname{Re}\left\{(2\pi i\widehat m_j)^{-1}
 \oint_{C_j}\widehat G_{2j,v}(z)/\widehat F_{2j,v}(z)\,dz\right\}.
\]
Form centered plug-in scores by replacing \((F_{v,h_n},G_{v,h_n},m_j)\) in \(\psi^j_{v,h_n}\) by \((\widehat F_{2j,v},\widehat G_{2j,v},\widehat m_j)\).  Let \(\widehat s_n(v)\) be the larger of \(n^{-1}\) and their empirical standard deviation after multiplication by \(\sqrt{h_n}\).  With independent standard Gaussian multipliers \((e_i)_{i\in I_2}\), let \(\widehat c_{1-\alpha}\) be the conditional \((1-\alpha)\)-quantile of
\[
 \sup_{v\in\mathcal I}\left|n_2^{-1/2}\sum_{i\in I_2}e_i\sqrt{h_n}
 \{\widehat\psi_i(v)-\overline{\widehat\psi}(v)\}/\widehat s_n(v)\right|.
\]
On selector and inference-denominator success return
\[
 \mathcal B_n(v)=\left[\widehat\tau_n(v)\pm
 \left\{\widehat c_{1-\alpha}\widehat s_n(v)/\sqrt{n_2h_n}
 +B_{\mathrm{bias}}L_\tau h_n^\beta\right\}\right];
\]
on either failure return \([-C_\tau,C_\tau]\).  For \(n=1\), return the same fallback.  Contour integrals are limits of deterministic dyadic quadrature, so the construction is a total measurable sample map.
