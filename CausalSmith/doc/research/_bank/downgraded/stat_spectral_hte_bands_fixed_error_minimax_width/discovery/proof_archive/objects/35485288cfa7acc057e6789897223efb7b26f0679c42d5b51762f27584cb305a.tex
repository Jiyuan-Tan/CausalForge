For \(n\ge2\), put \(n_1=\lfloor n/2\rfloor\), \(n_2=n-n_1\), and split the indices deterministically into a pilot set \(I_1\) and an inference set \(I_2\) of these sizes.  Put \(w_{i,v}=h_n^{-1}K((V_i-v)/h_n)\).  On the pilot define
\[
 \widehat H_{1j}(z)=n_1^{-1}\sum_{i\in I_1}e^{zZ_{n,i}},\qquad
 \widehat H'_{1j}(z)=n_1^{-1}\sum_{i\in I_1}Z_{n,i}e^{zZ_{n,i}},
\]
and \(\widehat F_{1j,v}(z)=n_1^{-1}\sum_{i\in I_1}w_{i,v}e^{zZ_{n,i}}\).  Let \(\widehat j_n\) be the smallest bank index \(j\) for which
\[
 \inf_{z\in C_j}|\widehat H_{1j}(z)|\ge5\rho_M/8,
 \quad
 \inf_{v\in\mathcal I,z\in C_j}|\widehat F_{1j,v}(z)|\ge5\rho_Mc_V/8,
 \quad
 \widehat m_j=(2\pi i)^{-1}\oint_{C_j}\widehat H'_{1j}/\widehat H_{1j}\,dz\in\mathbb Z\setminus\{0\};
\]
set \(\widehat j_n=\varnothing\) if no such index exists.  On \(I_2\), for the selected \(j\), define
\[
 \widehat F_{2j,v}(z)=n_2^{-1}\sum_{i\in I_2}w_{i,v}e^{zZ_{n,i}},\qquad
 \widehat G_{2j,v}(z)=n_2^{-1}\sum_{i\in I_2}w_{i,v}Y_i e^{zZ_{n,i}}.
\]
If \(\inf_{v,z\in C_j}|\widehat F_{2j,v}(z)|<\rho_Mc_V/4\), use the full-range fallback band \([-C_\tau,C_\tau]\).  Otherwise set the un-clipped center
\[
 \widehat\tau_n(v)=\operatorname{Re}\left\{(2\pi i\widehat m_j)^{-1}\oint_{C_j}\widehat G_{2j,v}(z)/\widehat F_{2j,v}(z)\,dz\right\}.
\]
Form the plug-in scores by replacing \((F_{v,h_n},G_{v,h_n},m_j)\) in \(\psi^j_{v,h_n}\) by \((\widehat F_{2j,v},\widehat G_{2j,v},\widehat m_j)\), center them over \(I_2\), and let \(\widehat s_n(v)\) be the larger of \(n^{-1}\) and their empirical standard deviation after multiplication by \(\sqrt{h_n}\).  Given independent standard Gaussian multipliers \((e_i)_{i\in I_2}\), let \(\widehat c_{1-\alpha}\) be the conditional \((1-\alpha)\)-quantile of
\[
 \sup_{v\in\mathcal I}\left|n_2^{-1/2}\sum_{i\in I_2}e_i\sqrt{h_n}\{\widehat\psi_{i}(v)-\overline{\widehat\psi}(v)\}/\widehat s_n(v)\right|.
\]
On both success events return
\[
 \mathcal B_n(v)=\left[\widehat\tau_n(v)\pm\left\{\widehat c_{1-\alpha}\widehat s_n(v)/\sqrt{n_2h_n}+B_{\mathrm{bias}}L_\tau h_n^\beta\right\}\right];
\]
on either failure event return \([-C_\tau,C_\tau]\).  For \(n=1\), return the same full-range fallback.  This is a total measurable sample map; numerical contour integrals are understood as limits of deterministic dyadic quadrature along the finitely many piecewise smooth bank contours.
