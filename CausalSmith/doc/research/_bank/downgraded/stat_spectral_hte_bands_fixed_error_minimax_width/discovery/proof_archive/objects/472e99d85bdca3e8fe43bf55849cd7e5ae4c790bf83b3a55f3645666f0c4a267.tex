The closed theorems fix \(\beta\in(0,1]\), a known H\"older radius, an interior modifier interval, fixed positive cumulant separation, and fixed modifier-shift regularity \((\gamma_D,L_D)\). The law class is procedure-independent. Honesty is uniform over primitive laws and every external code fixed before inference whose discrepancy from \(g_0\) decomposes into a bounded \(\gamma_D\)-H\"older modifier-only shift and a uniformly conditionally \(L^1\)-small remainder. The former direct conditional-\(L^1\) class is included by \(d=0\); strict inclusion is claimed only under the explicit compatibility that \(\mathcal G\) contains a nonzero constant code \(-a\) with \(\varepsilon_0<a\le C_g\), for which the witness is \(d\equiv a\). The procedure neither knows this witness nor estimates \(q_0\), and no auxiliary-sample learning guarantee is claimed. The accepted scalar bank class and this modifier-indexed band class are not globally comparable. Unknown-smoothness adaptation, boundary bands, multivariate modifiers, and sharp dependence on vanishing cumulant separation remain outside the closed result.
