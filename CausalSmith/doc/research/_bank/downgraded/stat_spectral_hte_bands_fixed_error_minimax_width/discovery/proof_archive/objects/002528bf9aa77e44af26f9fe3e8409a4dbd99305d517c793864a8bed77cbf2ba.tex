\textbf{Proof.}
Let \(\mathcal E_{1n},\mathcal E_{2n}\) be the events supplied by the corrected stochastic lemma.  On their intersection, the conditional Gaussian and multiplier approximation, anti-concentration, studentization consistency, and the Bahadur remainder imply
\[
 \liminf_{n\to\infty}\inf_{Q\in\mathcal Q_{\mathrm{spec},n}}
 P_Q\left\{
 |\widehat\tau_n(v)-\Theta_{v,h_n}|
 \le\frac{\widehat c_{1-\alpha}\widehat s_n(v)}{\sqrt{n_2h_n}}
 \text{ for every }v\in\mathcal I\right\}\ge1-\alpha. \tag{1}
\]
The localized-bias lemma gives, on the same event,
\[
 \sup_{v\in\mathcal I}|\Theta_{v,h_n}-\tau_0(v)|
 \le B_{\mathrm{bias}}L_\tau h_n^\beta. \tag{2}
\]
The triangle inequality in (1)--(2) is exactly simultaneous containment in the implemented band on its two actual success events.  On either actual failure event the procedure returns \([-C_\tau,C_\tau]\), which contains \(\tau_0(v)\) for every \(v\) by the slope-range assumption.  Since the additional bad-pilot set in \(\mathcal E_{1n}^c\) has probability \(o(1)\), (1)--(2) prove
\[
 \liminf_{n\to\infty}\inf_{Q\in\mathcal Q_{\mathrm{spec},n}}
 P_Q\{\tau_0(v)\in\mathcal B_n(v)\text{ for every }v\in\mathcal I\}
 \ge1-\alpha. \tag{3}
\]

For expected width, on the two success events the supremum width is at most
\[
 \frac{2\widehat c_{1-\alpha}\sup_v\widehat s_n(v)}{\sqrt{n_2h_n}}
 +2B_{\mathrm{bias}}L_\tau h_n^\beta, \tag{4}
\]
whereas on a fallback event it equals \(2C_\tau\).  The stochastic moment and fallback bounds therefore give, uniformly in \(Q\),
\[
 W_n(\mathcal B,Q)
 \le C\sqrt{\frac{\log n}{n_2h_n}}
 +2B_{\mathrm{bias}}L_\tau h_n^\beta+o(r_n). \tag{5}
\]
For \(h_n=c_h(\log n/n)^{1/(2\beta+1)}\), direct algebra yields
\[
 \sqrt{\frac{\log n}{n_2h_n}}\asymp
 \left(\frac{\log n}{n}\right)^{\beta/(2\beta+1)}=r_n,
 \qquad h_n^\beta=c_h^\beta r_n. \tag{6}
\]
Equations (5)--(6) establish the asserted \(Cr_n\) inequality for all sufficiently large \(n\).  The construction visibly uses only the supplied fixed code and empirical contour transforms; it contains no estimate of \(q_0\).  The class restriction permits every fixed \(\varepsilon_0\in(\varepsilon_{\mathrm{app}},\varepsilon_\star]\), and no step treats the external code as learned from the inference sample. \(\square\)
