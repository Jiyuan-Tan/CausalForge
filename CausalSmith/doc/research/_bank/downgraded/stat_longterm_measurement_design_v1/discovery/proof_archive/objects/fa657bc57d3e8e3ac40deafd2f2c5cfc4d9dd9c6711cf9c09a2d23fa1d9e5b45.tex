On an observational full-catalogue pilot from the binary witness family, order the records with \(G=O\) by their original pilot indices and split them deterministically into a training half \(\mathcal I_{m,O}^{\mathrm{tr}}\) and a validation half \(\mathcal I_{m,O}^{\mathrm{va}}\), whose cardinalities differ by at most one. For each \(d\in\mathcal D\) and each cell \(v=(a,x,z_{M_d})\), define the saturated training-half regression
\[
 \widehat f_{d,m}^A(v)=
 \frac{\sum_{i\in\mathcal I_{m,O}^{\mathrm{tr}}}
 \mathbf 1\{(A_i,X_i,Z_{M_d,i})=v\}Y_i}
 {\sum_{i\in\mathcal I_{m,O}^{\mathrm{tr}}}
 \mathbf 1\{(A_i,X_i,Z_{M_d,i})=v\}},
\]
with value zero when the denominator vanishes. Define the held-out treatment-aware risk estimator
\[
 \widehat R_{d,m}^A=
 \frac{1}{|\mathcal I_{m,O}^{\mathrm{va}}|}
 \sum_{i\in\mathcal I_{m,O}^{\mathrm{va}}}
 \{Y_i-\widehat f_{d,m}^A(A_i,X_i,Z_{M_d,i})\}^2,
\]
with value zero if the validation half is empty, and let \(\widehat d_m^A\) be the deterministically tie-broken element of \(\arg\min_{d\in\mathcal D}\widehat R_{d,m}^A\). This is a measurable finite-cell rule using only the independently funded full-catalogue pilot; it does not fit a bridge or use main-study outcomes.
