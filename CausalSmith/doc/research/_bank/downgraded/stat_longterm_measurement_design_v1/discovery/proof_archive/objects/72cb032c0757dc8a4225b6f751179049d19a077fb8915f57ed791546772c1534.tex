Theorem~\(\mathrm{thm{:}budget\text{-}profile}\) and Assumption~\(\mathrm{ass{:}nondegenerate\text{-}components}\) imply that every arm-normalized profiled value is finite and strictly positive. Source-arm positivity gives \(0<1-p_{g,1}<1\), so every IKM-normalized source component and profiled value is likewise finite and strictly positive. Since \(\mathcal D\) is finite and nonempty, both treatment-aware selector sets are nonempty. Substituting the profiled arm-normalized formula into the definition of \(\rho_{\mathrm{pred}}^A(P)\) proves (1), and the IKM definition gives (2). In each case, the selected index set is a subset of \(\mathcal D\), so the ratio lies in \([1,\infty)\), and division by the positive global minimum proves that it is the smallest best-tie constant.

For either positive profile \(w_d\), let

 C_A(P)=\max_{\substack{d,d'\in\mathcal D:\,R_d^A(P)\le R_{d'}^A(P)}}\frac{w_d}{w_{d'}}. \tag{1}
\]
The index set is finite and contains every diagonal pair. Any valid pairwise constant must dominate every ratio indexed by this set, while \(C_A(P)\) plainly makes every implication valid. This proves exactness of the third display.
