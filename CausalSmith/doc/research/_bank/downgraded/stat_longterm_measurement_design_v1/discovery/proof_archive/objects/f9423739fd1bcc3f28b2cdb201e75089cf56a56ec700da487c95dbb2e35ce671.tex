Let \(\mathcal I_{E,B}\) and \(\mathcal I_{O,B}\) be the experimental and observational main-study index sets, of sizes \(N_{E,B}\) and \(N_{O,B}\). Use a fixed integer \(L\ge2\) and a deterministic balanced observational-only partition
\[
 \mathcal I_{O,B}=\bigsqcup_{\ell=1}^L\mathcal I_{O,B,\ell}.
\]
For every \(d\in\mathcal D\), train \(\widehat h_{d,B}^{(-\ell)}\) on \(\mathcal I_{O,B}\setminus\mathcal I_{O,B,\ell}\), and train \(\widehat q_{d,B}^{(-\ell)}\) on \(\mathcal I_{E,B}\cup(\mathcal I_{O,B}\setminus\mathcal I_{O,B,\ell})\). Any fit whose fitting problem is degenerate is assigned a fixed measurable value.

For \(a\in\{0,1\}\), define the arm counts
\[
 e_{B,a}=\sum_{i\in\mathcal I_{E,B}}\mathbf 1\{A_i=a\},
 \qquad
 o_{B,\ell,a}=\sum_{i\in\mathcal I_{O,B,\ell}}\mathbf 1\{A_i=a\},
\]
the empirical arm probabilities
\[
 \widehat p_{E,a}=\frac{e_{B,a}}{N_{E,B}},
 \qquad
 \widehat p_{O,\ell,a}=\frac{o_{B,\ell,a}}{|\mathcal I_{O,B,\ell}|},
\]
and the experimental bridge arm means
\[
 \widehat\mu_{d,a}^{(-\ell)}
 =\frac1{e_{B,a}}
 \sum_{i\in\mathcal I_{E,B}}\mathbf 1\{A_i=a\}
 \widehat h_{d,B}^{(-\ell)}(S_{3d,i},S_{2d,i},a,X_i).
\]
Each displayed quantity is assigned the value zero if one of its displayed denominators is zero.

Whenever the required denominators are positive, define
\[
\begin{aligned}
 \widehat\mu_{B,d}(a)
 &=\frac1L\sum_{\ell=1}^L\widehat\mu_{d,a}^{(-\ell)}\\
 &\quad+\frac1L\sum_{\ell=1}^L\frac1{o_{B,\ell,a}}
 \sum_{i\in\mathcal I_{O,B,\ell}}\mathbf 1\{A_i=a\}
 \widehat q_{d,B}^{(-\ell)}(S_{2d,i},S_{1d,i},a,X_i)\\
 &\hspace{35mm}\times
 \{Y_i-\widehat h_{d,B}^{(-\ell)}(S_{3d,i},S_{2d,i},a,X_i)\},
\end{aligned}                                               \tag{1}
\]
and
\[
 \widehat\tau_B(d,\alpha)
 =\widehat\mu_{B,d}(1)-\widehat\mu_{B,d}(0).               \tag{2}
\]
For \(i\in\mathcal I_{E,B}\), define the exact experimental plug-in score
\[
\begin{aligned}
 \widehat\phi_{E,d,B,i}
 =\frac1L\sum_{\ell=1}^L\sum_{a=0}^1(-1)^{1-a}
 \frac{\mathbf 1\{A_i=a\}}{\widehat p_{E,a}}
 \{&\widehat h_{d,B}^{(-\ell)}(S_{3d,i},S_{2d,i},a,X_i)\\
 &-\widehat\mu_{d,a}^{(-\ell)}\}.
\end{aligned}                                               \tag{3}
\]
For \(i\in\mathcal I_{O,B,\ell}\), define the exact observational plug-in score
\[
\begin{aligned}
 \widehat\phi_{O,d,B,i}
 &=\sum_{a=0}^1(-1)^{1-a}
 \frac{\mathbf 1\{A_i=a\}}{\widehat p_{O,\ell,a}}
 \widehat q_{d,B}^{(-\ell)}(S_{2d,i},S_{1d,i},a,X_i)\\
 &\hspace{22mm}\times
 \{Y_i-\widehat h_{d,B}^{(-\ell)}(S_{3d,i},S_{2d,i},a,X_i)\}.
\end{aligned}                                               \tag{4}
\]
Every summand in (3)--(4) with a zero empirical arm probability is assigned the value zero. Set
\[
 \widetilde V_{E,d,B}
 =\frac1{N_{E,B}}\sum_{i\in\mathcal I_{E,B}}
 \widehat\phi_{E,d,B,i}^2,
 \qquad
 \widetilde V_{O,d,B}
 =\frac1{N_{O,B}}\sum_{\ell=1}^L
 \sum_{i\in\mathcal I_{O,B,\ell}}
 \widehat\phi_{O,d,B,i}^2,                                 \tag{5}
\]
with value zero when the corresponding source count is zero.

At \((d,\alpha)=(\widehat d_m,\widehat\alpha_m)\), let
\[
\begin{aligned}
 \mathsf D_B
 ={}&\{N_{E,B}\ge1,\ N_{O,B}\ge1\}
 \cap\bigcap_{a=0}^1\{e_{B,a}\ge1\}\\
 &{}\cap\bigcap_{\ell=1}^L\bigcap_{a=0}^1
 \{o_{B,\ell,a}\ge1\}.
\end{aligned}                                               \tag{6}
\]
This event contains every source, treatment-arm, fold-arm, empirical-probability, bridge-mean, correction, and variance denominator appearing in (1)--(5). Under the zero-denominator conventions, define
\[
 \widehat s_B^2
 =\mathbf 1\{\mathsf D_B\}B\left\{
 \frac{\widetilde V_{E,\widehat d_m,B}}{N_{E,B}}
 +\frac{\widetilde V_{O,\widehat d_m,B}}{N_{O,B}}
 \right\},                                                 \tag{7}
\]
and
\[
 \mathsf G_{\mathrm{tot}}
 =\mathsf D_B\cap\{\widehat s_B^2>0\}.                    \tag{8}
\]
Let \(s_{0,B}\) be the nonnegative square root of
\[
 s_{0,B}^2
 =B\left\{
 \frac{V_{E,\widehat d_m}}{N_{E,B}}
 +\frac{V_{O,\widehat d_m}}{N_{O,B}}
 \right\}                                                  \tag{9}
\]
when both source counts are positive, and set \(s_{0,B}=0\) otherwise. On \(\mathsf G_{\mathrm{tot}}\), set \(\widehat s_B=(\widehat s_B^2)^{1/2}\), use the value in (2) as \(\widehat\tau_B\), define
\[
 \mathsf T_B
 =\frac{\sqrt B\{\widehat\tau_B-\theta_{\widehat d_m}(P)\}}
 {\widehat s_B},                                            \tag{10}
\]
and set
\[
 I_B=\left[
 \widehat\tau_B-z_{1-\eta/2}\frac{\widehat s_B}{\sqrt B},
 \widehat\tau_B+z_{1-\eta/2}\frac{\widehat s_B}{\sqrt B}
 \right].                                                   \tag{11}
\]
On \(\mathsf G_{\mathrm{tot}}^c\), set \(\widehat\tau_B=0\), \(\widehat s_B=0\), \(\mathsf T_B=0\), and \(I_B=[0,0]\). Under common identification, \(\theta_{\widehat d_m}(P)=\tau\), so the numerator in (10) is equivalently \(\sqrt B(\widehat\tau_B-\tau)\). These conventions make every estimator, score moment, statistic, and interval a fixed measurable map on the entire sample space.
