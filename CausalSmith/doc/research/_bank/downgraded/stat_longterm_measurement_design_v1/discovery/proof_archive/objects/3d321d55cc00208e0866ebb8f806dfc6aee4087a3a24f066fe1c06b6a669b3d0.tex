Let \(\mathcal I_{E,B}\) and \(\mathcal I_{O,B}\) be the experimental and observational main-study index sets, of sizes \(N_{E,B}\) and \(N_{O,B}\). Use a fixed observational-only fold count \(L\ge2\) and a deterministic balanced partition \(\mathcal I_{O,B}=\bigsqcup_{\ell=1}^L\mathcal I_{O,B,\ell}\). The outcome-bridge fit \(\widehat h_{d,B}^{(-\ell)}\) is trained on the observational training indices \(\mathcal I_{O,B}\setminus\mathcal I_{O,B,\ell}\). The selection-bridge fit \(\widehat q_{d,B}^{(-\ell)}\) may additionally use all experimental indices \(\mathcal I_{E,B}\), because it is evaluated only on the held-out observational fold. Each fit is assigned a fixed measurable value if its fitting problem is degenerate.

For \(a\in\{0,1\}\), set
\[
 N_{E,a,B}=\sum_{i\in\mathcal I_{E,B}}\mathbf 1\{A_i=a\},
 \qquad
 N_{O,\ell,a,B}=\sum_{i\in\mathcal I_{O,B,\ell}}\mathbf 1\{A_i=a\},
\]
and define
\[
 \widehat p_{E,a,B}=\frac{N_{E,a,B}}{N_{E,B}},
 \qquad
 \widehat p_{O,\ell,a,B}
 =\frac{N_{O,\ell,a,B}}{|\mathcal I_{O,B,\ell}|},
\]
with value zero whenever the displayed denominator is zero. Define the bridge arm mean
\[
 \widehat\mu_{d,a,B}^{(-\ell)}
 =\frac{1}{N_{E,a,B}}
 \sum_{i\in\mathcal I_{E,B}}\mathbf 1\{A_i=a\}
 \widehat h_{d,B}^{(-\ell)}(S_{3d,i},S_{2d,i},a,X_i),
\]
with value zero when \(N_{E,a,B}=0\).

For \(i\in\mathcal I_{E,B}\), define the exact source-indexed plug-in score
\[
 \widehat\phi_{E,d,B,i}^{(-\ell)}
 =\sum_{a=0}^1(-1)^{1-a}
 \frac{\mathbf 1\{A_i=a\}}{\widehat p_{E,a,B}}
 \left\{\widehat h_{d,B}^{(-\ell)}(S_{3d,i},S_{2d,i},a,X_i)
 -\widehat\mu_{d,a,B}^{(-\ell)}\right\}.
\]
For \(i\in\mathcal I_{O,B,\ell}\), define
\[
 \widehat\phi_{O,d,B,i}^{(-\ell)}
 =\sum_{a=0}^1(-1)^{1-a}
 \frac{\mathbf 1\{A_i=a\}}{\widehat p_{O,\ell,a,B}}
 \widehat q_{d,B}^{(-\ell)}(S_{2d,i},S_{1d,i},a,X_i)
 \left\{Y_i-\widehat h_{d,B}^{(-\ell)}(S_{3d,i},S_{2d,i},a,X_i)\right\}.
\]
Every summand containing a zero estimated probability is defined to be zero. The experimental score used for variance estimation is the average \(L^{-1}\sum_{\ell=1}^L\widehat\phi_{E,d,B,i}^{(-\ell)}\), because experimental observations are not split and are evaluated with every observationally trained fit. Set
\[
 \widetilde V_{E,d,B}
 =\frac1{N_{E,B}}\sum_{i\in\mathcal I_{E,B}}
 \left\{\frac1L\sum_{\ell=1}^L
 \widehat\phi_{E,d,B,i}^{(-\ell)}\right\}^2,
\]
\[
 \widetilde V_{O,d,B}
 =\frac1{N_{O,B}}\sum_{\ell=1}^L
 \sum_{i\in\mathcal I_{O,B,\ell}}
 \left\{\widehat\phi_{O,d,B,i}^{(-\ell)}\right\}^2,
\]
using value zero when the corresponding source count is zero.

On the event that all treatment-arm denominators below are positive, define the raw selected doubly robust value by
\[
 \widehat\tau_B^\circ
 =\frac1L\sum_{\ell=1}^L\sum_{a=0}^1(-1)^{1-a}
 \left[
 \widehat\mu_{\widehat d_m,a,B}^{(-\ell)}
 +\frac1{N_{O,\ell,a,B}}
 \sum_{i\in\mathcal I_{O,B,\ell}}\mathbf 1\{A_i=a\}
 \widehat q_{\widehat d_m,B}^{(-\ell)}(S_{2\widehat d_m,i},S_{1\widehat d_m,i},a,X_i)
 \left\{Y_i-\widehat h_{\widehat d_m,B}^{(-\ell)}(S_{3\widehat d_m,i},S_{2\widehat d_m,i},a,X_i)\right\}
 \right],
\]
and set \(\widehat\tau_B^\circ=0\) otherwise. Define
\[
 \widehat s_B^2
 =B\left\{
 \frac{\widetilde V_{E,\widehat d_m,B}}{N_{E,B}}
 +\frac{\widetilde V_{O,\widehat d_m,B}}{N_{O,B}}
 \right\}
\]
when both source counts are positive, set \(\widehat s_B^2=1\) otherwise, and take the nonnegative root \(\widehat s_B=(\widehat s_B^2)^{1/2}\). Let
\[
 \mathsf G_{m,B}^{\mathrm{tot}}
 =\{N_{E,B}\ge1,N_{O,B}\ge1,\widehat s_B^2>0\}
 \cap\bigcap_{a=0}^1\{N_{E,a,B}\ge1\}
 \cap\bigcap_{\ell=1}^L\bigcap_{a=0}^1\{N_{O,\ell,a,B}\ge1\}.
\]
All denominators introduced by \(\widehat p\), \(\widehat\mu\), and the doubly robust correction are positive on this event. The total formula for \(\widehat s_B^2\) above is retained as its fixed measurable extension on the complement. Define
\[
 \widehat\tau_B
 =\widehat\tau_B^\circ\mathbf 1\{\mathsf G_{m,B}^{\mathrm{tot}}\},
\]
so the estimator has the fixed value zero on the complement. Define
\[
 I_B=\left[
 \widehat\tau_B-z_{1-\eta/2}\frac{\widehat s_B}{\sqrt B},
 \widehat\tau_B+z_{1-\eta/2}\frac{\widehat s_B}{\sqrt B}
 \right]
\]
on \(\mathsf G_{m,B}^{\mathrm{tot}}\), and set \(I_B=[0,0]\) on its complement. The studentized statistic equals its displayed ratio on \(\mathsf G_{m,B}^{\mathrm{tot}}\) and equals zero on the complement. These conventions make the estimator, variance estimator, interval, and statistic fixed measurable maps on the entire sample space.
