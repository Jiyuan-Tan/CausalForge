For each source \(g\in\{E,O\}\), index the realized main-study observations by \(\mathcal I_g\), with \(|\mathcal I_E|=N_{E,B}\) and \(|\mathcal I_O|=N_{O,B}\). Fix \(L\ge2\). Before observing outcomes, partition each \(\mathcal I_g\) measurably into folds \(\mathcal I_{g,1},\ldots,\mathcal I_{g,L}\) whose sizes differ by at most one, and write \(\ell_g(i)\) for the fold of observation \(i\), \(\mathcal I_{g,-\ell}=\mathcal I_g\setminus\mathcal I_{g,\ell}\),
\[
 N_{g,-\ell}=|\mathcal I_{g,-\ell}|,
 \quad
 N_{g,-\ell,a}=\sum_{i\in\mathcal I_{g,-\ell}}\mathbf 1\{A_i=a\},
 \quad
 N_{O,\ell,a}=\sum_{i\in\mathcal I_{O,\ell}}\mathbf 1\{A_i=a\},
 \quad
 N_{E,a}=\sum_{i\in\mathcal I_E}\mathbf 1\{A_i=a\}.
\]
The bridge learners \(\widehat h_{d,B}^{(-\ell)}\) and \(\widehat q_{d,B}^{(-\ell)}\) are trained using only observational observations in \(\mathcal I_{O,-\ell}\); if that training set or a learner-specific denominator is empty, use the identically zero function. Define, with zero-denominator value \(1/2\),
\[
 \widehat p_{g,a}^{(-\ell)}
 =\begin{cases}
 N_{g,-\ell,a}/N_{g,-\ell},&N_{g,-\ell}>0,\\
 1/2,&N_{g,-\ell}=0,
 \end{cases}
\]
and, with zero-arm-denominator value \(0\),
\[
 \widehat\mu_{d,a}^{(-\ell)}
 =\begin{cases}
 N_{E,-\ell,a}^{-1}
 \displaystyle\sum_{i\in\mathcal I_{E,-\ell}}
 \mathbf 1\{A_i=a\}
 \widehat h_{d,B}^{(-\ell)}(S_{3d,i},S_{2d,i},a,X_i),
 &N_{E,-\ell,a}>0,\\
 0,&N_{E,-\ell,a}=0.
 \end{cases}
\]
For an experimental observation \(i\in\mathcal I_E\), set
\[
 \widehat\phi_{E,d,i}
 =\sum_{a=0}^1(-1)^{1-a}
 \frac{\mathbf 1\{A_i=a\}}{\widehat p_{E,a}^{(-\ell_E(i))}}
 \left\{
 \widehat h_{d,B}^{(-\ell_E(i))}(S_{3d,i},S_{2d,i},a,X_i)
 -\widehat\mu_{d,a}^{(-\ell_E(i))}
 \right\},
\]
where a fraction with \(\widehat p_{E,a}^{(-\ell_E(i))}=0\) is assigned the value \(0\). For an observational observation \(i\in\mathcal I_O\), set
\[
 \widehat\phi_{O,d,i}
 =\sum_{a=0}^1(-1)^{1-a}
 \frac{\mathbf 1\{A_i=a\}}{\widehat p_{O,a}^{(-\ell_O(i))}}
 \widehat q_{d,B}^{(-\ell_O(i))}(S_{2d,i},S_{1d,i},a,X_i)
 \left\{Y_i-
 \widehat h_{d,B}^{(-\ell_O(i))}(S_{3d,i},S_{2d,i},a,X_i)
 \right\},
\]
again assigning value \(0\) to a fraction with zero estimated treatment probability. Define the source second moments by the globally measurable conventions
\[
 \widetilde V_{g,d,B}
 =\frac{1}{N_{g,B}\vee1}
 \sum_{i\in\mathcal I_g}\widehat\phi_{g,d,i}^2,
 \qquad N_{E,B}=|\mathcal I_E|,
 \quad N_{O,B}=|\mathcal I_O|.
\]
The raw selected doubly robust contrast is
\[
 \widehat\theta_{d,B}^{\mathrm{raw}}
 =\sum_{a=0}^1(-1)^{1-a}\left[
 \frac{1}{N_{E,B}\vee1}\sum_{i\in\mathcal I_E}
 \frac{\mathbf 1\{A_i=a\}}{\widehat p_{E,a}^{(-\ell_E(i))}}
 \widehat h_{d,B}^{(-\ell_E(i))}(S_{3d,i},S_{2d,i},a,X_i)
 \right.
\]
\[
 \left.
 +\frac{1}{N_{O,B}\vee1}\sum_{i\in\mathcal I_O}
 \frac{\mathbf 1\{A_i=a\}}{\widehat p_{O,a}^{(-\ell_O(i))}}
 \widehat q_{d,B}^{(-\ell_O(i))}(S_{2d,i},S_{1d,i},a,X_i)
 \left\{Y_i-
 \widehat h_{d,B}^{(-\ell_O(i))}(S_{3d,i},S_{2d,i},a,X_i)
 \right\}
 \right],
\]
using the same zero-fraction convention. Define
\[
 \widehat s_B^2
 =B\left\{
 \frac{\widetilde V_{E,\widehat d_m,B}}{N_{E,B}\vee1}
 +\frac{\widetilde V_{O,\widehat d_m,B}}{N_{O,B}\vee1}
 \right\},
 \qquad
 \widehat s_B=(\widehat s_B^2)^{1/2},
\]
and the total event
\[
 \mathcal G_{\mathrm{tot}}
 =\{N_{E,B}\ge1,N_{O,B}\ge1,\widehat s_B^2>0\}
 \cap\bigcap_{a=0}^1\{N_{E,a}>0\}
 \cap\bigcap_{\ell=1}^L\bigcap_{a=0}^1\{N_{O,\ell,a}>0\}
\]
\[
 \hspace{2em}\cap
 \bigcap_{g\in\{E,O\}}\bigcap_{\ell=1}^L\bigcap_{a=0}^1
 \{N_{g,-\ell}>0,N_{g,-\ell,a}>0\}.
\]
Thus every denominator used by \(\widehat p_{g,a}^{(-\ell)}\) or \(\widehat\mu_{d,a}^{(-\ell)}\), both experimental treatment arms, and every observational fold-treatment arm are nonempty on \(\mathcal G_{\mathrm{tot}}\). Give all final objects fixed measurable extensions on the complement:
\[
 \widehat\tau_B
 =\mathbf 1\{\mathcal G_{\mathrm{tot}}\}
 \widehat\theta_{\widehat d_m,B}^{\mathrm{raw}},
\]
\[
 \mathsf T_B
 =\begin{cases}
 \sqrt B\{\widehat\tau_B-(\mu_{\widehat d_m,1}-\mu_{\widehat d_m,0})\}/\widehat s_B,
 &\mathcal G_{\mathrm{tot}},\\
 0,&\mathcal G_{\mathrm{tot}}^c,
 \end{cases}
\]
and
\[
 I_B=\begin{cases}
 [\widehat\tau_B-z_{1-\eta/2}\widehat s_B/\sqrt B,
 \widehat\tau_B+z_{1-\eta/2}\widehat s_B/\sqrt B],
 &\mathcal G_{\mathrm{tot}},\\
 [-z_{1-\eta/2}/\sqrt B,z_{1-\eta/2}/\sqrt B],
 &\mathcal G_{\mathrm{tot}}^c.
 \end{cases}
\]
The conventions with \(N_{g,B}\vee1\), value \(1/2\) for an empty source-training denominator, value \(0\) for an empty treatment-arm mean or a zero estimated treatment probability, and the displayed complement values make the estimator, variance estimator, interval, and studentized statistic total measurable maps.
