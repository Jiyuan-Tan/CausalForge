For a realized assignment, define the signed observed-outcome stack without inverse-probability weighting by
\[
 \widehat Y^{\mathrm{obs}}
 =\bigl(D_{1,1}Y_1(W),\ldots,D_{n,1}Y_n(W),
 -D_{1,0}Y_1(W),\ldots,-D_{n,0}Y_n(W)\bigr)^{\top}.
\]
For any published-domain basis, Zhao's observable coefficient map is
\[
 \widehat\gamma^{\mathrm{HT}}(B)
 =(B^{\top}\Omega B)^+B^{\top}\Omega\Pi^{-1}\widehat Y^{\mathrm{obs}}.
\]
Put \(\widehat 1_a=n^{-1}\sum_{i=1}^nD_{i,a}/\pi_{i,a}\) and define
\[
 \widehat\gamma^{\mathrm{SN}}_a(B)=
 \begin{cases}
 \widehat\gamma^{\mathrm{HT}}_a(B)/\widehat 1_a,&\widehat 1_a>0,\\
 0,&\widehat 1_a=0.
 \end{cases}
\]
The deployed estimator is
\[
 \widehat\tau_B^{\mathrm{CV}}
 =\widehat\tau^{\mathrm{HT}}
 -\widehat\gamma^{\mathrm{SN}}(B)^{\top}
 \left\{n^{-1}B^{\top}D-\mathbb E_\nu[n^{-1}B^{\top}D]\right\},
 \qquad
 \widehat\tau^{\mathrm{HT}}=n^{-1}\mathbf1^{\top}\Pi^{-1}\widehat Y^{\mathrm{obs}}.
\]
The zero-denominator convention makes the map total.  Coefficient estimation can introduce finite-sample bias; this is imported deployment machinery, not a new limit theorem.
