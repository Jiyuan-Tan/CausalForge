The universal certified-solver conclusion is false for the interface \(\mathfrak I_{\mathrm{cert}}\) as defined.  In particular, let \(n=3\), let \(W_1,W_2,W_3\) be independent Bernoulli \(1/2\) variables under \(\nu\), and set \(f_i(w)=w_i\).  With \(\kappa=1/8\) and \(\varepsilon=1/10\), the two marginal pairs \((F_1,F_0)=(\delta_0,\delta_0)\) and \((F_1,F_0)=(\delta_1,\delta_0)\) produce the same encoded tuple
\[
\Pi=\tfrac12 I_6,\qquad
\Omega=\tfrac14\begin{bmatrix}I_3&-I_3\\-I_3&I_3\end{bmatrix},
\qquad c_L=c_U=0,
\]
but their robust values satisfy \(v^\star=0\) and \(v^\star\ge1/3\), respectively.  Consequently, no algorithm whose only input is \(\mathfrak I_{\mathrm{cert}}\) can always return rational bounds \(L_{\varepsilon}\le v^\star\le U_{\varepsilon}\) with \(U_{\varepsilon}-L_{\varepsilon}\le\varepsilon\); hence the conjunction requested in oeq:certified-global-basis does not hold.
