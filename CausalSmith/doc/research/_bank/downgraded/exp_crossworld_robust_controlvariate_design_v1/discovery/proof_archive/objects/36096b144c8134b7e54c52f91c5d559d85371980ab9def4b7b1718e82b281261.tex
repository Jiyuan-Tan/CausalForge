For every \(B\in\mathcal B_Z\), the ordinary-inverse loss has the exact intercept--slope form
\[
w(B)=h(0)-a_B+p_\xi(b_B).
\]
Suppose the ordinary-domain zero-covariance and minimax extrema are attained.  Then
\[
\Delta_Z=
\max_{B\in\mathcal B_Z}\{a_B-p_\xi(b_B)\}
-\left[a^\star-\min_{B:\,a_B=a^\star}p_\xi(b_B)\right].
\]
Consequently strict ordinary-domain improvement holds if and only if \(\Delta_Z>0\), equivalently if and only if there is \(B\in\mathcal B_Z\) for which
\[
\min_{C:\,a_C=a^\star}p_\xi(b_C)-p_\xi(b_B)
>a^\star-a_B.
\]
Thus some slope-penalty advantage must strictly exceed the sacrificed zero-covariance gain.  Through \(q_Z\), all displayed values are unchanged on \(\widetilde{\mathcal B}_Z\), and every attained optimizer correspondence there is exactly the inverse image of its projective correspondence.  No universal strictness, minimax interchange, singular completion, or semidefinite reduction is asserted.
