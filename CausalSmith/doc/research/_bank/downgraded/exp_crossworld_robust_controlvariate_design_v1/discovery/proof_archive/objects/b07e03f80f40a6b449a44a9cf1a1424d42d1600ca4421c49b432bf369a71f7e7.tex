\textbf{Proof.}
The two named assumptions ensure that the endpoint losses are well defined: ass:exposure-positivity makes \(\Pi^{-1}\) available, and ass:frechet-covariance-domain makes \(c_L\) and \(c_U\) the feasible covariance endpoints.  Put
\[
V_+=\inf_{[B]_+\in\mathcal B_Z^+}w^+(B),
\qquad
V_Z=\inf_{C\in\mathcal B_Z}w(C).
\tag{1}
\]
These are infima; no attainment is used.

\emph{First inequality.}
For every \(C\in\mathcal B_Z\), lem:zhao-rank-two-stratum-identification gives
\[
w^+(\iota(C))=w(C).
\tag{2}
\]
Because \(\iota(C)\in\mathcal B_Z^+\), equations (1)--(2) imply
\[
V_+\le V_Z.
\tag{3}
\]

\emph{Reverse inequality.}
Fix an arbitrary \([B]_+\in\mathcal B_Z^+\).  If \(\operatorname{rank}(S_B)=2\), lem:zhao-rank-two-stratum-identification supplies a unique \(C\in\mathcal B_Z\) with \([B]_+=\iota(C)\), and hence
\[
V_Z\le w(C)=w^+(B).
\tag{4}
\]
If \(\operatorname{rank}(S_B)\le1\), lem:rank-stratified-projector-reduction supplies a sequence \(C_j\in\mathcal B_Z\) such that
\[
\limsup_{j\to\infty}w(C_j)\le w^+(B).
\tag{5}
\]
Since \(V_Z\le w(C_j)\) for every \(j\),
\[
V_Z\le\liminf_{j\to\infty}w(C_j)
\le\limsup_{j\to\infty}w(C_j)
\le w^+(B).
\tag{6}
\]
Thus \(V_Z\le w^+(B)\) for every completion point.  Taking the infimum over \(\mathcal B_Z^+\) yields \(V_Z\le V_+\), which together with (3) proves
\[
V_+=V_Z.
\tag{7}
\]
By the corrected definition of \(v_{\mathrm{mm}}^+\), the left side of (7) is \(v_{\mathrm{mm}}^+\).  Prop:kappa-value-exhaustion now gives
\[
v_{\mathrm{mm}}^+
=\inf_{C\in\mathcal B_Z}w(C)
=\inf_{\substack{\kappa>0:\,\mathcal B_\kappa\ne\varnothing}}
\min_{C\in\mathcal B_\kappa}w(C).
\tag{8}
\]
The index set in the final infimum is nonempty: choose any \(C\in\mathcal B_Z\), which exists by hypothesis, and apply prop:kappa-exhaustion.  The fixed-threshold minimum in (8) exists because the same proposition gives compactness of \(\mathcal B_\kappa\), while def:gain-loss and the positive lower eigenvalue bound give continuity of \(w\) there.

\emph{Rank-two equality set.}
Suppose first that \([B]_+=\iota(C)\in\mathcal A_{\mathrm{mm}}^+\) for some \(C\in\mathcal B_Z\).  Equations (2), (7), and the definition of the equality set give
\[
w(C)=w^+(\iota(C))=v_{\mathrm{mm}}^+=V_Z,
\tag{9}
\]
so \(C\) attains the ordinary-domain infimum.  By prop:kappa-exhaustion, \(C\in\mathcal B_{\kappa_C}\) for some \(\kappa_C>0\).  Hence, using (8)--(9),
\[
v_{\mathrm{mm}}^+
\le\min_{A\in\mathcal B_{\kappa_C}}w(A)
\le w(C)
=v_{\mathrm{mm}}^+.
\tag{10}
\]
Both inequalities in (10) are equalities, so \(C\in\mathcal A_{\mathrm{mm}}(\kappa_C)\) and the fixed-threshold minimum equals \(v_{\mathrm{mm}}^+\).  This proves containment of the left-hand rank-two set in the displayed union.

Conversely, suppose \(C\in\mathcal A_{\mathrm{mm}}(\kappa)\) for a nonempty threshold class whose minimum equals \(v_{\mathrm{mm}}^+\).  Then (2) gives
\[
w^+(\iota(C))=w(C)=v_{\mathrm{mm}}^+.
\tag{11}
\]
Thus \(\iota(C)\in\mathcal A_{\mathrm{mm}}^+\cap\iota(\mathcal B_Z)\).  This proves the exact rank-two identity.  It also proves both conditional attainment statements: ordinary attainment produces a rank-two completion equality point by (2) and (7), while a rank-two completion equality point produces ordinary attainment by (9).

\emph{Singular equality set and boundary condition.}
Lem:rank-stratified-projector-reduction shows that every completion point has rank zero, one, or two, and lem:zhao-rank-two-stratum-identification identifies the rank-two stratum exactly with \(\iota(\mathcal B_Z)\).  Removing that stratum from the equality set therefore gives
\[
\mathcal A_{\mathrm{mm}}^+\setminus\iota(\mathcal B_Z)
=\{[B]_+\in\mathcal B_Z^+:\operatorname{rank}(S_B)\le1,\ w^+(B)=v_{\mathrm{mm}}^+\}.
\tag{12}
\]
For a singular equality point, (5) supplies only an ordinary minimizing sequence.  It supplies no ordinary point attaining the infimum, so no such implication is claimed.  Equations (1)--(12) likewise never invoke lower semicontinuity of the Moore--Penrose loss across a rank drop; consequently the proof asserts neither nonemptiness of \(\mathcal A_{\mathrm{mm}}^+\) nor existence of a singular equality point.  All completion objects used are those defined by the note, not objects attributed to Zhao. \(\square\)

\textbf{Sanity check.}
If an ordinary minimizer exists, (9)--(11) place its image in the completion equality set and recover it in a value-attaining fixed-threshold class.  If no ordinary minimizer exists, (7) remains valid because the singular approximation argument compares infima, while the equality sets in (12) may consistently be empty.
