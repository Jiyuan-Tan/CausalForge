\textbf{Proof.}
By the corrected definition of the completion value,
\[
v_{\mathrm{mm}}^+=\inf_{[B]_+\in\mathcal B_Z^+}w^+(B). \tag{1}
\]
The completion is nonempty because \(\mathcal B_Z\ne\varnothing\) and the carrier map \(\iota\) sends every ordinary class into its rank-two stratum.

Set
\[
m_Z=\inf_{[C]\in\mathcal B_Z}w(C).
\]
For every \([C]\in\mathcal B_Z\), lem:zhao-rank-two-stratum-identification gives
\[
w^+(\iota(C))=w(C).
\]
Since \(\iota(C)\in\mathcal B_Z^+\), equation \((1)\) therefore implies
\[
v_{\mathrm{mm}}^+\le m_Z. \tag{2}
\]

For the reverse inequality, fix an arbitrary \([B]_+\in\mathcal B_Z^+\).  If \(\operatorname{rank}(S_B)=2\), lem:zhao-rank-two-stratum-identification supplies a unique \([C]\in\mathcal B_Z\) such that \([B]_+=\iota(C)\), and hence
\[
m_Z\le w(C)=w^+(B). \tag{3}
\]
If \(\operatorname{rank}(S_B)\le1\), lem:rank-stratified-projector-reduction supplies a sequence \([C_j]\in\mathcal B_Z\) satisfying
\[
\limsup_{j\to\infty}w(C_j)\le w^+(B). \tag{4}
\]
Because \(m_Z\le w(C_j)\) for every \(j\),
\[
m_Z\le\liminf_{j\to\infty}w(C_j)
\le\limsup_{j\to\infty}w(C_j)
\le w^+(B). \tag{5}
\]
Thus \(m_Z\le w^+(B)\) for every completion class, whether rank two or singular.  Taking the infimum over \([B]_+\) in \((3)\)--\((5)\) and using \((1)\) yields
\[
m_Z\le v_{\mathrm{mm}}^+. \tag{6}
\]
Equations \((2)\) and \((6)\) prove
\[
v_{\mathrm{mm}}^+=m_Z.
\]
This step uses no continuity of the Moore--Penrose loss across rank changes and asserts no attainment.  Finally, prop:kappa-value-exhaustion gives
\[
m_Z
=\inf_{\substack{\kappa>0:\,\mathcal B_\kappa\ne\varnothing}}
\min_{B\in\mathcal B_\kappa}w(B),
\]
which proves the three-way value identity.  The displayed minima exist because each nonempty fixed-threshold class is compact and the ordinary-inverse loss is continuous there, as established in prop:kappa-value-exhaustion and its dependency prop:kappa-exhaustion.

We next prove the rank-two equality-set formula in both directions.  Let
\([X]_+\in\mathcal A_{\mathrm{mm}}^+\cap\iota(\mathcal B_Z)\).  By lem:zhao-rank-two-stratum-identification there is a unique \([C]\in\mathcal B_Z\) with \([X]_+=\iota(C)\).  Membership in the equality set and the value identity give
\[
w(C)=w^+(X)=v_{\mathrm{mm}}^+=m_Z. \tag{7}
\]
Thus \([C]\) attains the ordinary-domain infimum.  Prop:kappa-exhaustion supplies \(\kappa_C>0\) for which \([C]\in\mathcal B_{\kappa_C}\).  Since \(\mathcal B_{\kappa_C}\subseteq\mathcal B_Z\), equation \((7)\) gives
\[
v_{\mathrm{mm}}^+=m_Z
\le \min_{B\in\mathcal B_{\kappa_C}}w(B)
\le w(C)=v_{\mathrm{mm}}^+. \tag{8}
\]
All inequalities in \((8)\) are equalities.  Consequently
\[
C\in\mathcal A_{\mathrm{mm}}(\kappa_C),
\qquad
\min_{B\in\mathcal B_{\kappa_C}}w(B)=v_{\mathrm{mm}}^+.
\]
This proves inclusion of the left-hand rank-two equality set in the displayed image of the union.

Conversely, suppose that \([C]\in\mathcal A_{\mathrm{mm}}(\kappa)\) for a nonempty threshold class satisfying
\[
\min_{B\in\mathcal B_\kappa}w(B)=v_{\mathrm{mm}}^+.
\]
Then lem:zhao-rank-two-stratum-identification and the definition of the fixed-threshold argmin imply
\[
w^+(\iota(C))=w(C)=v_{\mathrm{mm}}^+.
\]
Hence \(\iota(C)\in\mathcal A_{\mathrm{mm}}^+\cap\iota(\mathcal B_Z)\), proving the reverse inclusion and the exact rank-two identity.  The same two directions prove the stated conditional ordinary-attainment conclusions.

It remains only to identify the singular equality set.  Lem:rank-stratified-projector-reduction gives \(\operatorname{rank}(S_B)\in\{0,1,2\}\), while lem:zhao-rank-two-stratum-identification says that rank two is equivalent to membership in \(\iota(\mathcal B_Z)\).  Therefore a completion class lies outside \(\iota(\mathcal B_Z)\) exactly when \(\operatorname{rank}(S_B)\le1\).  Intersecting that stratum with the defining equality \(w^+(B)=v_{\mathrm{mm}}^+\) for \(\mathcal A_{\mathrm{mm}}^+\) proves
\[
\mathcal A_{\mathrm{mm}}^+\setminus\iota(\mathcal B_Z)
=\{[B]_+\in\mathcal B_Z^+:\operatorname{rank}(S_B)\le1,\ w^+(B)=v_{\mathrm{mm}}^+\}.
\]
This is an equality-set decomposition only: neither stratum is asserted to be nonempty without the corresponding attainment condition, and the approximation argument in \((4)\) does not turn a singular equality point into an ordinary minimizer. \(\square\)
