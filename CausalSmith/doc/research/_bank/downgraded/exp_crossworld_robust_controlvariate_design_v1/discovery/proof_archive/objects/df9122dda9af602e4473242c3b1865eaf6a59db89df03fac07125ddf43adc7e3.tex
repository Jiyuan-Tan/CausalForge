Endpoint moment matrices are necessary for a universal certified solver.  Consider the restriction of the corrected interface \(\mathfrak I_{\mathrm{cert}}\) in which \(Q(c_L)\) and \(Q(c_U)\) are deleted, so that an algorithm receives only \((\Pi,\Omega,c_L,c_U,\kappa,\varepsilon)\).  Let \(n=3\), let \(W_1,W_2,W_3\) be independent Bernoulli \(1/2\) variables under \(\nu\), and set \(f_i(w)=w_i\).  With \(\kappa=1/8\) and \(\varepsilon=1/100\), the marginal pairs \((F_1,F_0)=(\delta_0,\delta_0)\) and \((F_1,F_0)=(\operatorname{Bernoulli}(1/2),\delta_0)\) have the same restricted input
\[
\Pi=\tfrac12 I_6,\qquad
\Omega=\tfrac14\begin{bmatrix}I_3&-I_3\\-I_3&I_3\end{bmatrix},
\qquad c_L=c_U=0,
\]
but their minimax residual values are, respectively,
\[
\min_{B\in\mathcal B_\kappa}w(B)=0
\qquad\text{and}\qquad
\min_{B\in\mathcal B_\kappa}w(B)=\frac1{36}.
\]
Consequently, no algorithm restricted to those six inputs can always return rational bounds \(L_{\varepsilon}\le\min_{B\in\mathcal B_\kappa}w(B)\le U_{\varepsilon}\) with \(U_{\varepsilon}-L_{\varepsilon}\le\varepsilon\).  This obstruction does not establish either existence or finite termination of a solver supplied with the corrected moment-complete interface.
