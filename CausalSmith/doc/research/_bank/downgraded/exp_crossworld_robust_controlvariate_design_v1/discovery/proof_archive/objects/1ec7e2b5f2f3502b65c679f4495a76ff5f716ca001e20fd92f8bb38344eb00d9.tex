\textbf{Proof.}
Let
\[
V_+=\inf_{[B]_+\in\mathcal B_Z^+}w^+(B),
\qquad V_Z=\inf_{B\in\mathcal B_Z}w(B).
\]
Rank-two identification gives \(V_+\le V_Z\).  Conversely, for a rank-two published class the same lemma gives \(V_Z\le w^+(B)\).  For a singular class, lem:rank-stratified-projector-reduction supplies \(B_j\in\mathcal B_Z\) with \(\limsup_jw(B_j)\le w^+(B)\), and hence
\[
V_Z\le\liminf_jw(B_j)\le\limsup_jw(B_j)\le w^+(B).
\]
Taking the infimum over all published classes proves \(V_Z=V_+=v_{\mathrm{mm}}^+\).  Prop:kappa-value-exhaustion gives the fixed-threshold exhaustion equality.

If \(\iota(C)\in\mathcal A_{\mathrm{mm}}^+\), rank-two equality shows that \(C\) attains \(V_Z\).  Prop:kappa-exhaustion places it in some \(\mathcal B_{\kappa_C}\), whose minimum is then squeezed between \(V_Z\) and \(w(C)=V_Z\).  The converse follows identically: a threshold minimizer whose threshold value equals \(v_{\mathrm{mm}}^+\) maps to a published-class equality point.  This proves the displayed rank-two equality-set identity.  The complement of the rank-two image consists exactly of ranks zero and one, which gives the singular equality-stratum formula.  The approximation argument supplies only a minimizing sequence at a singular point; it proves neither full-class nor ordinary attainment. \(\square\)
