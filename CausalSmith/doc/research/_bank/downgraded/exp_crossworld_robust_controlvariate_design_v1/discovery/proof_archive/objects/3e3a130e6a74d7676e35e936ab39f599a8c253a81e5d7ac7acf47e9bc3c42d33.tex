The project proves the endpoint reduction for nondegenerate Zhao-type bases and studies minimax worst-copula residual variance on the explicitly regularized compact subclass \(\mathcal B_\kappa\). It proves almost-sure uniform objective convergence, value consistency, and the one-sided outer-limit inclusion for the corresponding optimizer set. The current certificate interface is shown insufficient because it omits the endpoint moment matrices; a corrected moment-complete finite-\(\varepsilon\) solver remains open.
