\textbf{Proof.}
If \(B\in\widetilde{\mathcal B}_Z\), then \(S_B\succ0\), so each arm column is nonzero and def:zhao-basis-class defines \([B]\in\mathcal B_Z\).  Conversely, every \([C]\in\mathcal B_Z\) has a block-separable representative with \(C^{\top}\Omega C\succ0\), hence a preimage in \(\widetilde{\mathcal B}_Z\).  Thus \(q_Z\) is onto.  The definition of the projective quotient says exactly that two representatives have the same class if and only if \(C=BT\) for a diagonal \(T=\operatorname{diag}(t_1,t_0)\) with \(t_1t_0\ne0\), proving the fiber formula.

For such \(T\),
\[
S_{BT}=T^{\top}S_BT,
\qquad
S_{BT}^{-1}=T^{-1}S_B^{-1}(T^{\top})^{-1}. \tag{1}
\]
Substitute (1) and \(BT\) into def:gain-loss.  Cyclicity of trace cancels \(T\) and \(T^{-1}\):
\[
\begin{aligned}
n^2g_{q_Z(BT)}(c)
&=\operatorname{tr}\!\left[T^{-1}S_B^{-1}(T^{\top})^{-1}
T^{\top}B^{\top}\Omega\Pi^{-1}Q(c)\Pi^{-1}\Omega BT\right]\\
&=\operatorname{tr}\!\left[S_B^{-1}B^{\top}\Omega\Pi^{-1}Q(c)\Pi^{-1}\Omega B\right]
=n^2g_{q_Z(B)}(c).
\end{aligned}
\]
The uncontrolled term \(h(c)\) does not depend on \(B\), so the endpoint losses and their maximum are invariant as well.  An invariant function is constant on every fiber of a surjection.  Its image values over \(q_Z^{-1}(K)\) therefore equal its values over \(K\), proving equality of infima and suprema; if an extremum is attained, a matrix is an optimizer exactly when its quotient class is, giving the inverse-image correspondence. \(\square\)
