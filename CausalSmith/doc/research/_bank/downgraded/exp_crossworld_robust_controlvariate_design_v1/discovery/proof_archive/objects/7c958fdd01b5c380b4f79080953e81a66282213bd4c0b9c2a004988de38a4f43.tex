Suppose ass:exposure-positivity holds and \(\mathcal B_Z\ne\varnothing\).  If \(0<\kappa_1\le\kappa_2\) and both regular classes are nonempty, then
\[
\min_{B\in\mathcal B_{\kappa_1}}w(B)
\le
\min_{B\in\mathcal B_{\kappa_2}}w(B).
\]
Moreover,
\[
\inf_{\substack{\kappa>0:\,\mathcal B_\kappa\ne\varnothing}}
\min_{B\in\mathcal B_\kappa}w(B)
=
\inf_{B\in\mathcal B_Z}w(B).
\]
If the right-hand infimum is attained by some \(B_Z^\star\in\mathcal B_Z\), then there is \(\kappa_0>0\) such that, for every \(0<\kappa\le\kappa_0\),
\[
\min_{B\in\mathcal B_\kappa}w(B)=\inf_{B\in\mathcal B_Z}w(B).
\]
This value transfer concerns only the nonsingular ordinary-inverse projective class \(\mathcal B_Z\), not singular or pseudoinverse bases or Zhao's larger unquotiented domain.
