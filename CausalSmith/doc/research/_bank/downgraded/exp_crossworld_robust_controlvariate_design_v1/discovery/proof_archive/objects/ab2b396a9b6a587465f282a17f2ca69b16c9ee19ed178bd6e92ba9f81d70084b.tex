\textbf{Proof.}
Set
\[
 V_+=\inf_{[B]_+\in\mathcal B_Z^+}w^+(B),
 \qquad V_Z=\inf_{B\in\mathcal B_Z}w(B).
\]
Rank-two identification gives \(V_+\le V_Z\).  Conversely, for a rank-two completion class, the same lemma yields \(V_Z\le w^+(B)\).  For a singular class, lem:rank-stratified-projector-reduction supplies \(B_j\in\mathcal B_Z\) with
\[
V_Z\le\liminf_jw(B_j)\le\limsup_jw(B_j)\le w^+(B).
\]
Taking the infimum over all completion classes proves \(V_Z=V_+=v_{\mathrm{mm}}^+\).  Proposition prop:kappa-value-exhaustion supplies the remaining value equality.

If \(\iota(C)\in\mathcal A_{\mathrm{mm}}^+\), rank-two equality implies that \(C\) attains \(V_Z\).  Proposition prop:kappa-exhaustion puts it in some \(\mathcal B_{\kappa_C}\), and that class's minimum is squeezed between \(V_Z\) and \(w(C)=V_Z\).  Conversely, a threshold minimizer whose threshold value equals \(v_{\mathrm{mm}}^+\) maps to a completion equality point.  This proves the displayed rank-two equality-set identity.  Its complement consists exactly of classes with \(\operatorname{rank}(S_B)\le1\), which proves the singular-stratum formula.  The approximation argument supplies only a minimizing sequence and therefore asserts no extra attainment. \(\square\)
