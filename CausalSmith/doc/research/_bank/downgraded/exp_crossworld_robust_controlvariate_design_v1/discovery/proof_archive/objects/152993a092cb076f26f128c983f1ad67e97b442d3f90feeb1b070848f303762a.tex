\textbf{Proof.}
If \(0<\kappa_1\le\kappa_2\), the common normalization and eigenvalue inequalities give
\[
 \mathcal B_{\kappa_2}\subseteq\mathcal B_{\kappa_1}.
\]
Minimizing the same function over the larger set proves the first inequality.  Compactness from prop:kappa-exhaustion and continuity of the ordinary-inverse loss show that each displayed minimum is attained.

By prop:kappa-exhaustion,
\[
 \mathcal B_Z=\bigcup_{\kappa>0}\mathcal B_\kappa.
\]
The infimum of an arbitrary real function over a union is the infimum of the infima over its nonempty members.  Therefore
\[
 \inf_{B\in\mathcal B_Z}w(B)
 =\inf_{\substack{\kappa>0:\,\mathcal B_\kappa\ne\varnothing}}
 \min_{B\in\mathcal B_\kappa}w(B).
\]

If \(B_Z^\star\) attains the right-hand infimum, prop:kappa-exhaustion supplies \(\kappa_0>0\) with \(B_Z^\star\in\mathcal B_{\kappa_0}\).  For every \(0<\kappa\le\kappa_0\), nesting and \(\mathcal B_\kappa\subseteq\mathcal B_Z\) imply
\[
 \inf_{B\in\mathcal B_Z}w(B)
 \le\min_{B\in\mathcal B_\kappa}w(B)
 \le w(B_Z^\star)
 =\inf_{B\in\mathcal B_Z}w(B),
\]
which proves equality throughout.  This argument concerns only the rank-two stratum; the full Moore--Penrose value and its singular equality set require the separate rank-stratified transfer theorem. \(\square\)
