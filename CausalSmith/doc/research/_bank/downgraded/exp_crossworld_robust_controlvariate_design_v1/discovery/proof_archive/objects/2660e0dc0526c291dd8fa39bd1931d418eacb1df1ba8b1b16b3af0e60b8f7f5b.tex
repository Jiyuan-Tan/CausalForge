\(\mathcal B_Z^+=\{[B]_+:B=\begin{bmatrix}b_1&0\\0&b_0\end{bmatrix},\ b_1,b_0\in\mathbb R^n\}\), where two representatives are equivalent when, separately for each arm, both columns are zero or one is a nonzero scalar multiple of the other.  Each class is represented with each nonzero arm column having squared norm \(n\), while a zero arm remains zero.  This is a novel rank-zero/rank-one/rank-two Moore--Penrose completion of the frozen nondegenerate ordinary-inverse class \(\mathcal B_Z\); it is not Zhao's published domain and attributes no singular carrier or pseudoinverse construction to Zhao.
