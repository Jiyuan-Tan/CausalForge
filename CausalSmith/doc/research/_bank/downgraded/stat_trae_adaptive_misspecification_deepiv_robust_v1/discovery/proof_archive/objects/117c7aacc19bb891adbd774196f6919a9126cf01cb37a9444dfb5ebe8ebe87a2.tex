\begin{proof}
Set \(b=\bar\beta\) and \(s=s_{k_0,n}\). For \(0<s\le1\), define \(t=s^{1/(1+b)}\), so \(0<t\le1\). The grid contains \(1\), successive points differ by a factor of two, and \(\texttt{ass:grid-coverage}\) says that its smallest point is at most \(t/2\). Hence there is \(\lambda_t\in\Lambda_n\) such that
\[
 \frac{t}{2}\le\lambda_t\le t.
\]
It follows that
\[
 \inf_{\lambda\in\Lambda_n}
 \left\{\lambda^b+\frac{s}{\lambda}\right\}
 \le \lambda_t^b+\frac{s}{\lambda_t}
 \le t^b+\frac{2s}{t}
 =3s^{b/(1+b)}.
\]
This proves the deterministic grid inequality.

The zero-defect equalities do not turn this numerical optimization into an error bound for the selected estimator. Apply \(\texttt{thm:common-audit-oracle-impossibility}\) with \(B=1\) and \(\gamma=1/32\). Its benchmark has \(\varepsilon_{H,k_0}=\varepsilon_{A,k_0}=\alpha_{k_0,n}=0\), its optimized functional tends to zero, and every trained path is zero, whereas
\[
 \|\widehat h-h^\dagger\|_{L_2(P_X)}^2
 =\gamma B^2=\frac1{32}
\]
almost surely. The same theorem supplies the logically separate deterministic bound
\[
 \|\widehat h-h^\dagger\|_{L_2(P_X)}^2\le4B^2.
\]
Finally, \(b=\min\{\beta,1\}\), so \(b/(1+b)=\beta/(1+\beta)\) for \(\beta\le1\), while \(b/(1+b)=1/2\) for \(\beta>1\).
\end{proof}
