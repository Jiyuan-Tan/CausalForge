\begin{proof}
By \(\texttt{lem:parameterized-blind-path-witness}\), for every realization in the constructed configurations,
\[
 \widehat h_{k,\lambda}=0
 \qquad\text{for every }(k,\lambda)\in\mathcal K\times\Lambda_n.
\]
Thus the set of already-trained path elements is the singleton \(\{0\}\). Every measurable map valued in this set equals zero, regardless of whether its index is chosen using the sample, the population law \(P\), auxiliary randomness, or any combination of them.

Because \(\mathcal K\times\Lambda_n\) is finite, let \(\omega_{k,\lambda}\) be arbitrary finite real-valued coefficients, possibly random, data-dependent, or oracle-dependent. Pointwise,
\[
 \sum_{k\in\mathcal K,\lambda\in\Lambda_n}
 \omega_{k,\lambda}\widehat h_{k,\lambda}
 =\sum_{k\in\mathcal K,\lambda\in\Lambda_n}
 \omega_{k,\lambda}0
 =0.
\]
This proves the assertion for every signed linear combination. It also proves it for every affine combination, for which imposing \(\sum_{k,\lambda}\omega_{k,\lambda}=1\) does not alter the calculation.

The witness therefore gives, for every procedure covered by the proposition,
\[
 \|0-h^\dagger\|_{L_2(P_X)}^2=\gamma B^2.
\]
For any \(\rho\in(0,B^2]\), choosing \(\gamma=\rho/B^2\in(0,1]\) makes this error exactly \(\rho\). The construction retains its two distinct support atoms, each of probability \(1/2\), also at \(\rho=B^2\). The maximality part of \(\texttt{lem:parameterized-blind-path-witness}\) shows that the source conditions force every collapsed-zero path to have squared strong error at most \(B^2\), so the endpoint is exact. Every operation considered above combines only the already-trained zero path elements. Nothing in the argument covers refitting a candidate or constructing a new function outside that path.
\end{proof}
