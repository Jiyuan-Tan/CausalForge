The witness lemma proves, sample by sample, that
\[
 \widehat h_{k,\lambda}=0
 \quad\text{for every }(k,\lambda)\in\mathcal K\times\Lambda_n.
\]
Thus the finite trained path is the singleton \(\{0\}\). Any map with values in this set equals zero, regardless of whether its weights or index choices depend measurably on the data, on the population law, or on both. Likewise, if \(\omega_{k,\lambda}\ge0\) and \(\sum_{k,\lambda}\omega_{k,\lambda}=1\), then
\[
 \sum_{k,\lambda}\omega_{k,\lambda}\widehat h_{k,\lambda}=0.
\]
The witness lemma therefore gives squared strong error \(\gamma B^2\) for either operation. Given \(\rho\in(0,B^2)\), choose \(\gamma=\rho/B^2\in(0,1)\); then the error is \(\rho\) and both support points have positive probability. Letting \(\gamma\uparrow1\) makes the error tend to \(B^2\). Equality would require \(\gamma=1\), which removes the first support point, so the endpoint is not attained inside the stated genuine two-point family.
