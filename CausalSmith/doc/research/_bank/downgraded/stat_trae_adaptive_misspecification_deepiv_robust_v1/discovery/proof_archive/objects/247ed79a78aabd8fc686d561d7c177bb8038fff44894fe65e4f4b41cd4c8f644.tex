\begin{proof}
Put \(a=\bar\beta\) and \(s=s_{k_0,n}\). By hypothesis, \(a\in(0,1]\) and \(s\in(0,1]\). Define
\[
 x=s^{1/(1+a)}.
\]
Then \(x\in(0,1]\). The grid contains \(1=2^0\), while \(\texttt{ass:grid-coverage}\) gives
\[
 2^{-J_n}\le \frac{x}{2}<x.
\]
Consequently the set \(\{j\in\{0,\ldots,J_n\}:2^{-j}\le x\}\) is nonempty. Let \(j_*\) be its least element and set \(\lambda_*=2^{-j_*}\). If \(j_*=0\), then \(x=1\) and \(\lambda_*=x\). If \(j_*>0\), minimality gives \(2^{-(j_*-1)}>x\), and hence \(\lambda_*>x/2\). Thus in all cases
\[
 \frac{x}{2}<\lambda_*\le x.
\]
It follows that
\[
 \lambda_*^a+\frac{s}{\lambda_*}
 \le x^a+\frac{2s}{x}
 =s^{a/(1+a)}+2s^{a/(1+a)}
 =3s^{a/(1+a)}.
\]
Taking the infimum over \(\lambda\in\Lambda_n\) proves the displayed grid inequality. Notice that this argument optimizes only a deterministic numerical functional; it makes no assertion about the trained path or the selected estimator.

The replacement theorem \(\texttt{thm:common-audit-oracle-impossibility}\) supplies configurations with \(\varepsilon_{H,k_0}=\varepsilon_{A,k_0}=\alpha_{k_0,n}=0\) for which the same oracle functional tends to zero but
\[
 \|\widehat h-h^\dagger\|_{L_2(P_X)}^2=\frac1{32}
\]
almost surely. Hence the numerical optimization cannot, under the declared class alone, be promoted to an estimator rate. The same theorem gives the independent deterministic bound
\[
 \|\widehat h-h^\dagger\|_{L_2(P_X)}^2\le4B^2.
\]
Finally, since \(a=\min\{\beta,1\}\),
\[
 \frac{a}{1+a}
 =\begin{cases}
 \dfrac{\beta}{1+\beta},&0<\beta\le1,\\[4pt]
 \dfrac12,&1<\beta\le2.
 \end{cases}
\]
This proves the claimed exponent and its Tikhonov saturation at \(1/2\).
\end{proof}
