Fix \(\varnothing\ne\mathcal K\subseteq\{(g,t):2\le g\le t\le T\}\). The aggregate formed from the Ortiz-Villavicencio--Sant'Anna componentwise-GMM ATT estimators using the prespecified weights is joint-optimal if and only if \(N^{\prime}\Omega b^{\mathrm{sep}}=0\), equivalently if and only if each block of \(\Omega b^{\mathrm{sep}}\) is constant across the comparison cohorts in that block. For every \(Q\in\mathcal M\), with \(P=Q_O\), \[V_{\mathrm{sep}}-V_{\mathrm{joint}}=(N^{\prime}\Omega b^{\mathrm{sep}})^{\prime}(N^{\prime}\Omega N)^{-1}(N^{\prime}\Omega b^{\mathrm{sep}})=(b^{\mathrm{sep}}-b^{\mathrm{joint}})^{\prime}\Omega(b^{\mathrm{sep}}-b^{\mathrm{joint}}).\] Thus \(\widehat\tau_{\mathrm{joint}}\) has strictly smaller asymptotic variance than \(\widehat\tau_{\mathrm{sep}}\) exactly when the net cross-block covariance contribution is nonconstant across comparison cohorts within at least one group-event block. For \(g=2\), all covariance entries use the defined baseline period \(1\). If \(\mathcal K=\{k\}\), then \(N^{\prime}\Omega b^{\mathrm{sep}}=0\), \(b^{\mathrm{joint}}=b^{\mathrm{sep}}\), and \(V_{\mathrm{sep}}-V_{\mathrm{joint}}=0\), reproducing within-cell GMM optimality.
