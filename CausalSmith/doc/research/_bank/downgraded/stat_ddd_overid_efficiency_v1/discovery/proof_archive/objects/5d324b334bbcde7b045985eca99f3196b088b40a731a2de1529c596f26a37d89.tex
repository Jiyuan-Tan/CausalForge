For \(k=(g,t)\in\mathcal K\), where \(2\le g\le t\le T\), \(c\in\mathcal J_k\), and observation \(i\), first set \(\widetilde p_{a,s,i}=C_\varepsilon(\widehat p_{a,s,-f(i)}(X_i))\), \(\widetilde p_{g,1,i}=C_\varepsilon(\widehat p_{g,1,-f(i)}(X_i))\), \(\widetilde\pi_{g,1}=C_\varepsilon(n^{-1}\sum_{j=1}^n\mathbf 1\{G_j=g,S_j=1\})\), and \(\widehat d_{k,c,i}=\widehat m_{g,1,k,-f(i)}(X_i)-\widehat m_{g,0,k,-f(i)}(X_i)-\widehat m_{c,1,k,-f(i)}(X_i)+\widehat m_{c,0,k,-f(i)}(X_i)\). Define \[\widehat A_{i,k,c}=\mathbf 1\{G_i=g,S_i=1\}\widehat d_{k,c,i}+\widetilde p_{g,1,i}\sum_{(a,s)\in\{g,c\}\times\{0,1\}}\sigma_{a,s}^{g,c}\frac{\mathbf 1\{G_i=a,S_i=s\}}{\widetilde p_{a,s,i}}\{\Delta Y_{i,k}-\widehat m_{a,s,k,-f(i)}(X_i)\},\qquad \widehat\mu_{k,c}=\frac{n^{-1}\sum_{i=1}^n\widehat A_{i,k,c}}{\widetilde\pi_{g,1}},\] and display the fitted influence coordinate \[\widehat\Psi_{i,k,c}=\frac{1}{\widetilde\pi_{g,1}}\left[\mathbf 1\{G_i=g,S_i=1\}\{\widehat d_{k,c,i}-\widehat\mu_{k,c}\}+\widetilde p_{g,1,i}\sum_{(a,s)\in\{g,c\}\times\{0,1\}}\sigma_{a,s}^{g,c}\frac{\mathbf 1\{G_i=a,S_i=s\}}{\widetilde p_{a,s,i}}\{\Delta Y_{i,k}-\widehat m_{a,s,k,-f(i)}(X_i)\}\right].\] Stack \(\widehat\mu_{k,c}\) and \(\widehat\Psi_{i,k,c}\). Set \(\widehat\Omega^{\mathrm{raw}}=n^{-1}\sum_i\widehat\Psi_i\widehat\Psi_i^{\prime}\), \(\widehat\Omega=\Pi_{\mathbb S_+^M}(\widehat\Omega^{\mathrm{raw}})\), and \(\widehat\Omega_\lambda=\widehat\Omega+n^{-1/4}I_M\). For each \(k\), set \(\widehat b_k^{\mathrm{sep}}=\omega_k\widehat\Omega_{\lambda,kk}^{-1}\mathbf 1/(\mathbf 1^{\prime}\widehat\Omega_{\lambda,kk}^{-1}\mathbf 1)\), and set \(\widehat b^{\mathrm{joint}}=\widehat\Omega_\lambda^{-1}B(B^{\prime}\widehat\Omega_\lambda^{-1}B)^{-1}\omega\). Finally, \(\widehat\tau_{\mathrm{sep}}=(\widehat b^{\mathrm{sep}})^{\prime}\widehat\mu\), \(\widehat\tau_{\mathrm{joint}}=(\widehat b^{\mathrm{joint}})^{\prime}\widehat\mu\), and \(\widehat V_{\mathrm{joint}}=(\widehat b^{\mathrm{joint}})^{\prime}\widehat\Omega\widehat b^{\mathrm{joint}}\). Every denominator and inverse in this construction is defined for every realized sample.
