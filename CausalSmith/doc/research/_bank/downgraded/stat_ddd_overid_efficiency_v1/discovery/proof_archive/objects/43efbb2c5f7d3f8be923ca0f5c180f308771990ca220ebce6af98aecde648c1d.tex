Ortiz-Villavicencio and Sant'Anna prove minimum variance within each group-time comparison block and then aggregate, while Hsieh proves valid fixed-weight stacked-DDD inference when comparison units are reused. Neither result states the exact equality frontier for joint covariance weighting of all retained covariate-adjusted comparison-cohort scores, provides a feasible diagnostic for the resulting aggregate variance loss, or classifies the labelled shared-cell structures that attain a strict gain.
