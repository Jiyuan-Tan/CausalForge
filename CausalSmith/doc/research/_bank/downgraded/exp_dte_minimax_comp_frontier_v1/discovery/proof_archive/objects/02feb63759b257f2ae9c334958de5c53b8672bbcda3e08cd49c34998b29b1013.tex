\textbf{Proof.}
Given a supplied nonempty clique \(Q\), form the clique partition whose one nonsingleton candidate block is \(Q\) and whose remaining \(n-|Q|\) blocks are the singleton vertices in \(V_n\setminus Q\).  If \(|Q|=1\), this is simply the all-singleton partition.  The partition functional in \(\mathrm{prop{:}clique\text{-}partition\text{-}rademacher\text{-}converse}\) is therefore
\[
\left(\frac{|Q|}{n}\right)^2
+(n-|Q|)\left(\frac1n\right)^2
=\frac{|Q|^2+n-|Q|}{n^2}.
\]
This proves the witness bound.  Choosing a maximum clique gives \(|Q|=\omega(G)\) by definition.  The calculation uses a supplied clique and does not provide an algorithm for finding one. \(\square\)
