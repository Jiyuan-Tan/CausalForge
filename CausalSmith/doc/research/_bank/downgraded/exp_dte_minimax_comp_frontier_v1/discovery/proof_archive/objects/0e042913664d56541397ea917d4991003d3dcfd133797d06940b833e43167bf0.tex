\textbf{Proof.}
Fix \(G\) and a clique partition \(\mathcal P\), and write
\[
a_B=\frac{|B|}{n},\qquad B\in\mathcal P.
\tag{1}
\]

\textbf{Construction and support.}
For every sign array \(\xi=(\xi_{B,k}:B\in\mathcal P,k\in\{0,1\})\), define a complete schedule on \(H_{\mathcal P}\) as follows.  If \(i\in B\), put
\[
Y_i^{\xi}(z)=
\begin{cases}
\xi_{B,0},&z|_B\equiv0,\\
\xi_{B,1},&z_i=1\text{ and }z_j=0\text{ for all }j\in B\setminus\{i\},\\
0,&\text{otherwise}.
\end{cases}
\tag{2}
\]
By \(\text{def:clique-partition-subgraph}\), the closed neighborhood of \(i\) in \(H_{\mathcal P}\) is exactly \(B\).  Hence (2) depends only on the required closed-neighborhood assignment and satisfies arbitrary neighborhood interference.  Moreover,
\[
Y_i^{\xi}(\mathbf0)=\xi_{B,0},
\qquad
Y_i^{\xi}(\mathbf e_i)=\xi_{B,1}.
\tag{3}
\]
Consequently every atom satisfies both separate global layer restrictions with equality:
\[
\frac1n\sum_{i\in V_n}Y_i^{\xi}(\mathbf0)^2
=\frac1n\sum_{B\in\mathcal P}|B|=1,
\qquad
\frac1n\sum_{i\in V_n}Y_i^{\xi}(\mathbf e_i)^2=1.
\tag{4}
\]
Thus all \(4^{|\mathcal P|}\) atoms belong to \(\mathcal M_2(H_{\mathcal P})\) by \(\text{def:general-published-q2-class}\).  Give them the uniform prior, so all \(\xi_{B,k}\) are mutually independent Rademacher signs.  Equations (3) and \(\text{def:general-dte-primitives}\) give
\[
\tau_{\mathrm{DTE}}^{H_{\mathcal P}}(Y^{\xi})
=\sum_{B\in\mathcal P}a_B(\xi_{B,1}-\xi_{B,0}).
\tag{5}
\]

\textbf{Posterior obstruction.}
Fix any binary assignment \(z\).  Within a block \(B\), if \(z|_B\equiv0\), the observation reveals \(\xi_{B,0}\) but not \(\xi_{B,1}\).  If exactly one unit is treated, its outcome reveals \(\xi_{B,1}\), while every other observed outcome in the block is the fixed value zero, so \(\xi_{B,0}\) is not revealed.  If at least two units are treated, every observed outcome in the block is zero and neither sign is revealed.  This exhaustive case split also covers singleton blocks.  No assignment therefore reveals both signs from any block.

All unrevealed signs remain conditionally independent Rademacher variables.  Hence
\[
\operatorname{Var}_{\xi}\!\left(
\tau_{\mathrm{DTE}}^{H_{\mathcal P}}(Y^{\xi})
\mid z,Y^{\xi}(z)
\right)
=\sum_{B\in\mathcal P}a_B^2N_B(z),
\tag{6}
\]
where \(N_B(z)\in\{1,2\}\) is the number of unrevealed signs in block \(B\).  Thus (6) is at least \(\sum_Ba_B^2\).  In a maximal target-exposure observation, maximality within each disjoint clique block selects either the all-control exposure, which reveals \(\xi_{B,0}\), or one isolated-treatment exposure, which reveals \(\xi_{B,1}\).  It therefore leaves exactly one sign unrevealed per block, and (6) is exactly \(\sum_Ba_B^2\).

For squared loss and every measurable estimator value \(t\), conditional completion of the square gives
\[
\mathbb E_{\xi}\!\left[(\tau-t)^2\mid z,Y^{\xi}(z)\right]
=\operatorname{Var}_{\xi}(\tau\mid z,Y^{\xi}(z))
+\{\mathbb E_{\xi}(\tau\mid z,Y^{\xi}(z))-t\}^2
\geq\sum_{B\in\mathcal P}a_B^2.
\tag{7}
\]
Integrating over an arbitrary assignment law shows that every design--estimator pair has Bayes risk at least \(\sum_Ba_B^2\).  Worst-case risk over the class dominates this finite-prior Bayes risk, and taking the infimum in \(\text{def:general-dte-minimax-risk}\) yields
\[
R_2(H_{\mathcal P})\geq\sum_{B\in\mathcal P}a_B^2.
\tag{8}
\]
Because \(H_{\mathcal P}\subseteq G\) is spanning, \(\text{lem:published-network-risk-monotonicity}\) gives
\[
R_2(G)\geq R_2(H_{\mathcal P}).
\tag{9}
\]
Combining (8) and (9) proves the certificate for every clique partition.  The finite set \(V_n\) has only finitely many set partitions, so maximizing over those whose blocks induce cliques gives the displayed finite enumeration.  This argument makes no polynomial-time claim.  At the boundary \(n=1\), the unique singleton block leaves exactly one of two signs unrevealed under either assignment, and (6) equals one, agreeing with the certificate. \(\square\)
