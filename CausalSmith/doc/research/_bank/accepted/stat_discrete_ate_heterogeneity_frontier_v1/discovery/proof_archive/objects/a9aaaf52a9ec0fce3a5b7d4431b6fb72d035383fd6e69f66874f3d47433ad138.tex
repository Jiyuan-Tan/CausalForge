For every fixed \(0<\epsilon<1/2\), there are \(C_{\epsilon},c_{\epsilon},\rho_{\epsilon}>0\) and a finite \(N_{\epsilon}\) for which the following explicit total estimator is defined.  Put \(L=\log(en)\), split the sample into \(I_0=\{1,\ldots,\lfloor n/2\rfloor\}\) and its complement \(I_1\), and write \(m_j=|I_j|\).  Set
\[
 \lambda_0=256,\quad b_0=4096,\quad D_6=8\log(27/4),\quad
 \alpha_0=\min\left\{1,\frac1{64\log6},\frac1{512D_6}\right\}.
\]
When \(n\ge N_{\epsilon}\) and \(d\le\rho_{\epsilon}nL\), set \(K=\lfloor\alpha_0L\rfloor\ge2\), \(B=b_0L/m_1\), classify
\[
 \widehat{\mathcal H}:=\left\{k:\sum_{i\in I_0}\mathbf 1\{X_i=k\}>\lambda_0L\right\},
 \qquad \widehat{\mathcal L}:=\widehat{\mathcal H}^{c},
\]
use the statistics \(\widehat P_k\) of Lemma~\(\mathrm{lem:linear\text{-}mark\text{-}factorial\text{-}covariance}\) on block \(I_1\), and put
\[
 \widehat h_k:=\frac{N_k^{(1)}}{m_1}\left\{
 \frac{\sum_{i\in I_1}V_i\mathbf 1\{X_i=k,A_i=1\}}{N_{1k}^{(1)}}\mathbf 1\{N_{1k}^{(1)}>0\}
 -\frac{\sum_{i\in I_1}V_i\mathbf 1\{X_i=k,A_i=0\}}{N_{0k}^{(1)}}\mathbf 1\{N_{0k}^{(1)}>0\}
 \right\}.
\]
Define
\[
 T_n^{\mathrm{poly}}:=M\operatorname{clip}_{[-1,1]}\!\left(
 \sum_{k\in\widehat{\mathcal H}}\widehat h_k+
 \sum_{k\in\widehat{\mathcal L}}\widehat P_k\right).
\]
When \(n<N_{\epsilon}\) or \(d>\rho_{\epsilon}nL\), set \(T_n^{\mathrm{poly}}=0\).  Then, for every \(0\le\sigma\le2\) and every \(1\le d\le c_{\epsilon}n^2/L\),
\[
 \sup_{P\in\mathcal P_{d,\epsilon,M,\sigma}}
 E_{Q_P^{(n)}}[(T_n^{\mathrm{poly}}-\tau(P))^2]
 \le C_{\epsilon}M^2\left\{\frac1n+\min\left(1,\frac{d^2}{n^2L^2}\right)\right\}.
\]
The estimator uses \(O(dK^2)\) arithmetic operations after cell aggregation and has bounded fallbacks on every division boundary.
