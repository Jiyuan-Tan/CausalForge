The first display is a change of notation in Theorem~\(\mathrm{thm:sharp\text{-}two\text{-}sided\text{-}minimax}\).  If \(s=0\), its expression is \(b\).  If \(s=4\), or more generally \(s\) is bounded above and below by positive constants, it is order-equivalent to \(b+\min(1,u)\).  If \(u\ge1\), then \(\min(1,u)=1\), giving \(b+s\).  If \(u\le Cb\), then \(s\min(1,u)\le4Cb\); if instead \(s\min(1,u)\le Cb\), the same conclusion is immediate.  These identities prove the exact-homogeneity, unrestricted, fixed-radius, saturation, small-alphabet, and both parametric-dominance assertions.

Inside the formerly residual wedge one has \(u<1\), so the theorem's expression is exactly \(b+su\).  For \(d_n=n\), write \(L_n:=\log(en)\).  Then
\[
 b_n=2/n,\qquad u_n=L_n^{-2},\qquad s_n=L_n^{-1},
\]
\[
 b_n+s_nu_n=2/n+L_n^{-3}\asymp L_n^{-3}.
\]
The former selector benchmark was \(n^{-1}+\min\{u_n,s_n+n^{-1}\}\asymp L_n^{-2}\), so its ratio to the sharp rate is of order \(L_n\).  All claims follow by these algebraic identities; no asymptotic normality, coverage, or adaptation conclusion is involved.
