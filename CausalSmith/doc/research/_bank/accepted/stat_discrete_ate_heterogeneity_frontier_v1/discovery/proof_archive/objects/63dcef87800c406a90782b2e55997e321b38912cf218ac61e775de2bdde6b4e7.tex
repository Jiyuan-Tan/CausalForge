Write
\[
 u:=\frac{d^2}{n^2\log^2(en)},\qquad h:=\sigma^2+\frac d{n^2}.
\]
The theorem resolving \(\mathrm{oeq:robust\text{-}upper\text{-}construction}\) supplies
\[
 \sup_PE[(T_n^{\mathrm{poly}}-\tau(P))^2]
 \le C_{\epsilon}M^2\{n^{-1}+\min(1,u)\}
\tag{1}
\]
and
\[
 \sup_PE[(T_n^{\mathrm{col}}-\tau(P))^2]
 \le C_{\epsilon}M^2(n^{-1}+h).
\tag{2}
\]
All suprema here and below are over \(P\in\mathcal P_{d,\epsilon,M,\sigma}\).

If \(h\le\min\{1,u\}\), Definition~\(\mathrm{def:total\text{-}estimator}\) selects \(T_n^{\mathrm{col}}\), and (2) equals the claimed order because \(\min\{1,u,h\}=h\).  If \(u<\min\{1,h\}\), the selector uses \(T_n^{\mathrm{poly}}\); then \(u<1\), and (1) equals the claimed order because \(\min\{1,u,h\}=u\).  If neither inequality holds, then \(\min\{1,u,h\}=1\): if that minimum were smaller than one, either \(h\le u\) would trigger the first case or \(u<h\) would trigger the second.  In the remaining case the selector is zero.  Lemma~\(\mathrm{lem:scale\text{-}sanity}\) gives \(|\tau(P)|\le M\), and hence
\[
 E[(0-\tau(P))^2]\le M^2\le M^2\{n^{-1}+\min(1,u,h)\}.
\tag{3}
\]
Equations (1)--(3), with the largest component constant, prove the risk display uniformly over the stated support, radius, and dimension boundaries.

For the comparison clause, the new remainder \(\min\{1,u,h\}\) is always at most the collision remainder \(h\).  If \(d=o(n\log(en))\), then \(u=o(1)\).  If in addition \(u=o(h)\), eventually \(u<\min\{1,h\}\), so the selected remainder is \(u=o(h)\).  This proves the asserted strict order improvement without making an inference or adaptation claim.
