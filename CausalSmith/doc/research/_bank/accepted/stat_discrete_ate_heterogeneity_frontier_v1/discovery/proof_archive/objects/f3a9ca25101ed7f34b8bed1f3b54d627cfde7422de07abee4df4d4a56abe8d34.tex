Let \(u=d^2/[n^2\log^2(en)]\) and \(h=\sigma^2+d/n^2\).  The deterministic selector algebra is complete: a polynomial bound \(C_{\epsilon}M^2\{n^{-1}+\min(1,u)\}\), the proved occupancy-collision bound \(C_{\epsilon}M^2(n^{-1}+h)\), and the fallback bound \(M^2\) imply
\[
 \sup_P E[(\widehat\tau_n^{\star}-\tau(P))^2]
 \le C_{\epsilon}M^2\{n^{-1}+\min(1,u,h)\}.
\]
The comparison clause then follows because the minimum is no larger than \(h\), while \(d=o(n\log(en))\) implies \(u=o(1)\), so \(u=o(h)\) makes the improvement strict in order.  Only the polynomial input and the pending collision-definition correction prevent attachment of this argument as a proof of the frozen theorem.
