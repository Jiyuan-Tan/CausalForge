For \(t\in\{0,1\}\), \(x\in\mathcal B_P\), and \(h>0\), define
\[
 \widehat\mu_{t,h}(x)=
 \frac{\sum_{i=1}^n\mathbf1\{(2t-1)D_{P,x,i}>0\}
 K_\triangle(|D_{P,x,i}|/h)Y_i}
 {\sum_{i=1}^n\mathbf1\{(2t-1)D_{P,x,i}>0\}
 K_\triangle(|D_{P,x,i}|/h)}
\]
when the denominator is positive, and set \(\widehat\mu_{t,h}(x)=0\) otherwise.  At \(D_{P,x,i}=0\), assign the observation to neither arm.  Set
\[
 \widehat\tau^{\mathrm{LC}}_{n,h}(x)=\widehat\mu_{1,h}(x)-\widehat\mu_{0,h}(x).
\]
Strict sign, absolute value, the fixed kernel, finite sums, the positive-denominator ratio, and the zero branch make this a pointwise Borel function of \(U_{n,P}(x)\); it does not observe \(T\) separately.
