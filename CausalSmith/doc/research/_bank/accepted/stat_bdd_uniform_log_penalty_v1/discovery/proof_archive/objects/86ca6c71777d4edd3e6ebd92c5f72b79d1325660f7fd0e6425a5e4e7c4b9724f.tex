Fix \(x\in\mathcal B_P\) and \(t\in\{0,1\}\).  On the Borel subsets \(A\) of \((0,\infty)\), define the finite observable radial measure
\[
 \nu_{t,P,x}(A)
 =P\{T=t,\ \lVert X-x\rVert_2\in A\}.
\]
Score absolute continuity and polar coarea imply \(\nu_{t,P,x}\ll ds\).  Define \(Q_{t,P,x}:(0,\infty)\to[0,\infty)\) to be one fixed finite Borel-measurable Radon--Nikodym version
\[
 Q_{t,P,x}(s)=\frac{d\nu_{t,P,x}}{ds}(s).
\]
For Lebesgue-almost every radial index \(s>0\), this fixed version agrees with the coarea identity
\[
 Q_{t,P,x}(s)
 =\int_{\partial B_2(x,s)\cap\mathcal E_{t,P}\cap\mathcal X_P}
 f_P(z)\,d\mathcal H^1(z).
\]
No equality with the displayed circle integral is stipulated at exceptional radii.
