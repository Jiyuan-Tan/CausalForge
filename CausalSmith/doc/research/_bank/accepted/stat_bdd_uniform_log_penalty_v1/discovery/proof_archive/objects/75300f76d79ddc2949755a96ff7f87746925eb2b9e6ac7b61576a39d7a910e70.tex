The coordinatewise distance experiment has a sharp first-order uniform frontier even when the assignment boundary and outcome regressions are arbitrarily smooth.  On the enlarged primitive rectifiable class defined by compact support, rectifiability, bounded density, and arm-specific two-sided design thickness, but no separate boundary-length premise, \(R_n^{\mathrm{dist}}(\mathcal P_{\mathrm{rect}})\asymp(\log n/n)^{1/4}\).  The same rate holds on the endpoint-trimmed smooth class because bounded continuous score densities have no common angular modulus.  On the identical straight geometry, full locations attain \((\log n/n)^{q/(2q+2)}\); coordinatewise distances have the first-order rate when \(L>4\), but recover the same H\"older rate when \(L=4\).  Under an order-\(m\) joint normalized-coarea remainder, the promoted stabilized local-polynomial estimator attains \((\log n/n)^{m/(2m+2)}\) for every \(m\leq\min\{q,\iota\}\).  The contained-bump converse is proved only in the valid case \(m=q\); tightness for \(m<q\) is not claimed.  None of these results resolves the Cattaneo--Titiunik--Yu conjecture on its original class.
