For every integer \(p\geq1\), there is a finite \(L_0=L_0(p)\) such that, for every \(L\geq L_0\), there are constants \(0<c\leq C<\infty\) satisfying, for all sufficiently large \(n\),
\[
 c\left({\log n\over n}\right)^{1/4}
 \leq R^{12,\pm}_n(p,2,L)
 \leq Cn^{-1/4}(\log n)^{1/3}.
\]
Thus the fourth-moment endpoint has a proved two-sided bracket under exactly the same class; the residual logarithmic gap is not claimed to be tight.
