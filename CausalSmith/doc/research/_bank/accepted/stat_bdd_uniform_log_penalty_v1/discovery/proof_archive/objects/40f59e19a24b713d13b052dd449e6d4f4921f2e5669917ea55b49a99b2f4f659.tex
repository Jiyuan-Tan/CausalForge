Because \(K_\triangle(u)=1-|u|\) on \([-1,1]\),
\[
 K_\triangle(u)\geq\frac12\mathbf 1\{|u|\leq1/2\}.
\]
Moreover, on \(\{T=t\}\), \(|D_{P,x}|=\lVert X-x\rVert_2\).  Thus, whenever \(0<h\leq2r_0\),
\[
\begin{aligned}
 \Psi^{(0)}_{t,P,x}(h)
 &=h^{-2}\mathbb E_P\!\left[K_\triangle(D_{P,x}/h)\mathbf 1\{T=t\}\right]\\
 &\geq\frac{1}{2h^2}P\{X\in\mathcal A_{t,P}\cap B_2(x,h/2)\}\\
 &\geq\frac{1}{2h^2}c_-\left(\frac h2\right)^2
 =\frac{c_-}{8}.
\end{aligned}
\]
The last inequality is \(\mathrm{ass:uniform\text{-}two\text{-}sided\text{-}thickness}\).  It holds for every boundary point in the rectifiable class and, a fortiori, for every point of \(\mathcal B_{P,\delta}\subseteq\mathcal B_P\) in the smooth class.  Taking \(\kappa_0=c_-/8\) proves both displays.  The dependence on \(r_0\) is only through the phrase ``sufficiently small,'' namely \(h\leq2r_0\).
