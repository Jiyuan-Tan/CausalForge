The nonparametric logarithm is caused by simultaneous information loss across many boundary locations, not by forcing one estimator map to serve every location.  The proof first controls a measurable finite packing maximum and then uses monotonicity of outer expectation, so no joint measurability of \(x\mapsto T_{n,x}\) is needed.  On the causal signed-distance class, the same rate is attainable for all \(L\geq4\), while the matched lower certificate currently requires \(L\geq L_0(p)\).  Calling the nonparametric corollary ``same-class'' means only that it uses the same \(\mathcal P_{\mathrm{NP}}(L,q)\) law class; the decision class is the literal displayed common-map class just described.
