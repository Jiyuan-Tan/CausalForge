For every set \(A\subseteq\mathbb R^2\), \(\operatorname{bd}(A)\cap\operatorname{int}(A)=\varnothing\).  Consequently, if the curve in Theorem~6 is \(\operatorname{bd}(\mathcal X_P)\) and is nonempty, it cannot also satisfy Assumption~2(i)'s requirement that the same curve be contained in \(\operatorname{int}(\mathcal X_P)\).  In particular, the nonempty square support boundary in the angular packing is not an Assumption~2 assignment boundary without changing the statistical object.
