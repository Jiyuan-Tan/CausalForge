Fix \(P\in\mathcal P_{\mathrm{rect}}\cup\mathcal P_{\mathrm{sm}}\), \(x\in\mathcal B_P\), \(t\in\{0,1\}\), and \(r>0\).  Membership in either displayed class includes the density envelope, and \(X\) is supported on \(\mathcal X_P\).  Therefore, using only nonnegativity and the upper density bound,
\[
\begin{aligned}
 P\{X\in\mathcal A_{t,P}\cap B_2(x,r)\}
 &=\int_{\mathcal A_{t,P}\cap\mathcal X_P\cap B_2(x,r)}f_P(z)\,dz\\
 &\leq L\,\operatorname{Leb}_2\{B_2(x,r)\}
 =\pi Lr^2.
\end{aligned}
\]
The argument is valid for every \(r>0\); it requires neither a boundary regularity condition nor a lower mass condition.
