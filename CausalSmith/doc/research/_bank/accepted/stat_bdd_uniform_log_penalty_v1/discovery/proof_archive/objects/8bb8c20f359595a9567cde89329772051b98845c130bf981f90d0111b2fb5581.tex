For each \(t\in\{0,1\}\), \(x\in\mathcal B_P\), and bandwidth \(h\), let
\[
 \widehat\Psi_{t,x}(h)={1\over nh^2}\sum_{i=1}^n\mathbf1\{D^{\pm}_{P,x,i}\in I_t\}K_\square(D^{\pm}_{P,x,i}/h)r_p(D^{\pm}_{P,x,i}/h)r_p(D^{\pm}_{P,x,i}/h)^\top
\]
and
\[
 \widehat m_{t,x}(h)={1\over nh^2}\sum_{i=1}^n\mathbf1\{D^{\pm}_{P,x,i}\in I_t\}K_\square(D^{\pm}_{P,x,i}/h)r_p(D^{\pm}_{P,x,i}/h)Y_i.
\]
If \(\lambda_{\min}(\widehat\Psi_{t,x}(h))\geq(2L)^{-1}\), set \(\widehat\beta_{t,x}=\widehat\Psi_{t,x}(h)^{-1}\widehat m_{t,x}(h)\); otherwise set \(\widehat\beta_{t,x}=0\).  With \(e_1=(1,0,\ldots,0)^\top\), define
\[
 \widehat\tau^{12,\mathrm{LP}}_{n,h}(x)=\Pi_{[-2L,2L]}\{e_1^\top(\widehat\beta_{1,x}-\widehat\beta_{0,x})\},
\]
where \(\Pi_{[-2L,2L]}\) is Euclidean projection.  This is a jointly Borel member of \(\mathcal T^{12,\pm}_n\).
