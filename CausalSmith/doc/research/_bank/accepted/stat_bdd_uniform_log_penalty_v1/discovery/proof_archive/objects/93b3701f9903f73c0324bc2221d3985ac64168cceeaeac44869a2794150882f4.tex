By definition,
\[
 \operatorname{bd}(A)=\overline A\setminus\operatorname{int}(A).
\]
Therefore \(\operatorname{bd}(A)\cap\operatorname{int}(A)=\varnothing\).  If \(B=\operatorname{bd}(\mathcal X_P)\) and also \(B\subseteq\operatorname{int}(\mathcal X_P)\), then
\[
 B\subseteq\operatorname{bd}(\mathcal X_P)\cap\operatorname{int}(\mathcal X_P)=\varnothing,
\]
so \(B=\varnothing\).  For \(S=[-1/2,1/2]^2\), the set \(\operatorname{bd}(S)\) contains, for example, \((1/2,0)\), and is therefore nonempty.  Hence the square witness cannot make its support boundary satisfy the cited Assumption~2(i) condition while retaining Theorem~6's definition of the target curve.  This is a scope incompatibility, not a failure of regularity of the square.
