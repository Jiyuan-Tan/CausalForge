For \(|u|\leq1/2\), the triangular kernel satisfies \(K_\triangle(u)\geq1/2\).  Let \(0<h\leq2r_0\).  For any law in either displayed class, any permitted boundary point \(x\), and either arm \(t\), deterministic assignment gives
\[
\begin{aligned}
\Psi^{(0)}_{t,P,x}(h)
&=h^{-2}\mathbb E_P\!\left[K_\triangle(D_{P,x}/h)\mathbf 1\{T=t\}\right]\\
&\geq\frac{1}{2h^2}P\{X\in\mathcal A_{t,P}\cap B_2(x,h/2)\}\\
&\geq\frac{1}{2h^2}c_{-}(h/2)^2
=\frac{c_{-}}8.
\end{aligned}
\]
The last inequality is precisely uniform two-sided thickness, applicable because \(h/2\leq r_0\).  Therefore one may take \(\kappa_0=c_{-}/8\).  The second infimum is over the smaller set \(\mathcal B_{P,\delta}\subseteq\mathcal B_P\), so the same calculation proves it without an endpoint exception.
