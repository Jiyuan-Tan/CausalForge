Fix \(n\) and \(P\in\mathcal P_{\mathrm{NG},n}^{\mathrm{ACE}}\). All norms below are with respect to \(P_X\). If \(r\le s<\infty\), Jensen's inequality for the concave map \(u\mapsto u^{r/s}\) gives, for every measurable \(f\),
\[
 E_P[|f(X)|^r]
 =E_P[(|f(X)|^s)^{r/s}]
 \le\{E_P[|f(X)|^s]\}^{r/s}.
\]
Taking \(r\)-th roots yields
\[
 \|f\|_{L^r(P_X)}\le\|f\|_{L^s(P_X)}. \tag{1}
\]
For \(s=\infty\), the almost-sure inequality \(|f(X)|\le\|f\|_{L^\infty(P_X)}\), followed by integration, proves \((1)\) again. Applying \((1)\) to the two code errors and using \(\text{def:ace-comparison-subclass}\) gives
\[
 \|\bar g_n-g_0\|_{L^r(P_X)}\le\varepsilon_{1,n},
 \qquad
 \|\bar q_n-q_0\|_{L^r(P_X)}\le\varepsilon_{2,n}. \tag{2}
\]
These are precisely the code restrictions in \(\text{def:jms-ace-class}\). Every other member condition of that class is inherited from \(\mathcal P_{\mathrm{NG},n}\). Hence
\[
 \mathcal P_{\mathrm{NG},n}^{\mathrm{ACE}}
 \subseteq\mathcal P_{\mathrm{ACE},n}^{\mathrm{JMS}}. \tag{3}
\]
The broad spectral class imposes neither the \(L^s(P_X)\) treatment-code condition nor an outcome-code condition, so \((3)\) yields no inclusion or equality involving the broad class.

Assume next that \(\mathsf E_n^{\mathrm{JMS}}\) holds. Its displayed logarithms are defined, so \(\varepsilon_{1,n}>0\). If \(\varepsilon_{2,n}>0\), \(\text{lem:jms-ace-quantile-upper}\) and \((3)\) give
\[
 \sup_{P\in\mathcal P_{\mathrm{NG},n}^{\mathrm{ACE}}}
 Q_{P,1-\gamma}(|\widehat\theta_{\mathrm{ACE},r,n}-\theta_0(P)|)
 \le B_{\mathrm{ACE},n,\gamma}. \tag{4}
\]
If \(\varepsilon_{2,n}=0\), choose \(u\in(0,\varepsilon_{1,n})\) and enlarge only the outcome-code radius at index \(n\) from zero to \(u\). The zero-radius comparison subclass is contained in the enlarged published class. Because \(u<\varepsilon_{1,n}\), the maximum defining \(b_{2,n}\) is unchanged, so the same eligibility condition holds. The positive-radius theorem applied to the enlarged class gives
\[
\begin{aligned}
 &\sup_{P\in\mathcal P_{\mathrm{NG},n}^{\mathrm{ACE}}}
 Q_{P,1-\gamma}(|\widehat\theta_{\mathrm{ACE},r,n}-\theta_0(P)|)\\
 &\quad\le C_{\gamma}r!16^r\delta^{-1}
 \Big[\varepsilon_{1,n}^r u+C_{\theta}\varepsilon_{1,n}^{r+1}
 +64(C_g+\psi_{\eta})^r
 \{r^2(C_g+\psi_{\eta})+\psi_{\xi}+C_{\theta}\psi_{\eta}\}
 (\gamma n)^{-1/2}\Big].
\end{aligned}
\]
Letting \(u\downarrow0\) proves \((4)\) at the boundary, preserving the exact \(16^r\) and \(64\) constants.

Finally suppose \(\varepsilon_{1,n}\le\varepsilon_0\). Since \(\mathcal P_{\mathrm{NG},n}^{\mathrm{ACE}}\subseteq\mathcal P_{\mathrm{NG},n}\), \(\text{thm:adaptive-rootn-minimax}\) gives the spectral generalized-quantile bound on the comparison subclass. Put
\[
 A_n=\varepsilon_{1,n}^r\varepsilon_{2,n}+C_{\theta}\varepsilon_{1,n}^{r+1}.
\]
The definition of \(B_{\mathrm{ACE},n,\gamma}\) is a fixed positive multiple of \(A_n\) plus a fixed positive multiple of \(n^{-1/2}\). If \(A_n\gg n^{-1/2}\), the ratio of the spectral guarantee to \(B_{\mathrm{ACE},n,\gamma}\) tends to zero. This compares the two displayed upper guarantees only and supplies no lower bound for ACE.
