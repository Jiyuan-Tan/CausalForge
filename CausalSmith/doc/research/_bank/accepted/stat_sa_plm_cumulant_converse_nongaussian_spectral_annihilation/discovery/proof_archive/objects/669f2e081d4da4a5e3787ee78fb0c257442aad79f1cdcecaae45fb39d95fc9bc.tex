If \(\mathcal P_{\mathrm{NG},n}\neq\varnothing\), then it contains a one-dimensional submodel \(\{P_{n,\vartheta}:|\vartheta|\le c_0\}\) with the same law of \((X,T)\), the same \(g_0,q_0,\bar g_n,\bar q_n\), independent Gaussian outcome innovation of fixed positive variance not exceeding the \(\psi_{\xi}\) envelope, and \(Y_{\vartheta}=q_0(X)+\vartheta\eta+\xi_{\star}\). For \(|\vartheta_1-\vartheta_0|=h/\sqrt n\), \(D_{\mathrm{KL}}(P_{n,\vartheta_0}^{\otimes n}\|P_{n,\vartheta_1}^{\otimes n})\le C_0h^2\), where \(c_0,C_0\) depend only on fixed class constants.
