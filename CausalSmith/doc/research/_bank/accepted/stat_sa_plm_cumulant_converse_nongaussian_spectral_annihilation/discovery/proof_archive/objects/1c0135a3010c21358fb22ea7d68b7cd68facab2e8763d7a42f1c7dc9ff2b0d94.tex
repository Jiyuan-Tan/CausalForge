\[
 \mathfrak p=
 \bigl(k,\mathfrak d,\mathfrak p_{\eta},\mathfrak r_0,\mathfrak r_1\bigr),
\]
where \(k\) is exact and
\[
 \mathfrak d:\operatorname{Name}_{+}(\delta),\quad
 \mathfrak p_{\eta}:\operatorname{Name}_{+}(\psi_{\eta}),\quad
 \mathfrak r_0:\operatorname{Name}_{+}(R_0),\quad
 \mathfrak r_1:\operatorname{Name}_{+}(R_1),
\]
with the value contracts
\[
 k=r+1,\qquad
 R_0=(2^{k+4}k!)^{1/(k-2)}
       (\psi_{\eta}^2/\delta)^{1/(k-2)},
 \qquad R_1=R_0+1.
\]
Each positive name includes its rational positivity witness.  The construction reads only the supplied interval, modulus, and positivity fields.  It never reconstructs a name from an exact real.

Invoke the supplied moduli of \(\mathfrak p_{\eta}\) and \(\mathfrak r_1\) at error one.  If the returned intervals have rational upper endpoints \(u_{\psi}\) and \(u_R\), put
\[
 U_{\psi}=\left\lceil\max\{1,u_{\psi}\}\right\rceil,
 \qquad
 U_R=\left\lceil\max\{1,u_R\}\right\rceil,
 \qquad
 N_{\mathrm{cert}}=4U_{\psi}^2(U_R+2)^3.
\]
Set
\[
 m_{\star}=N_{\mathrm{cert}}+3,
 \qquad d_{\star}=2^{-m_{\star}},
 \qquad h_{\star}=d_{\star}/3,
 \qquad J=2^{m_{\star}-1}+1.
\]
For \(q=0,\ldots,2^{m_{\star}-1}\), use certified addition on the actual record \(\mathfrak r_0\) and the rational point record for \(1/4+q2^{-m_{\star}}\) to form
\[
 \mathfrak\rho_q
 =\mathfrak r_0+operatorname{Name}(1/4+q2^{-m_{\star}}).
\]
Its value is \(\rho_q=R_0+1/4+q2^{-m_{\star}}\).  Enumerate these radii increasingly and set \(C_j=\{z\in\mathbb C:|z|=\rho_j\}\).

Define the integers
\[
 e_{\star}=8U_RU_{\psi}^2(U_R+1)^2,
 \qquad
 d_{\star}^{\mathrm{den}}=3(2U_R+1),
\]
\[
 u_{\star}=2e_{\star}
 +N_{\mathrm{cert}}(m_{\star}+d_{\star}^{\mathrm{den}}),
 \qquad
 a_{\star}=2^{-u_{\star}}>0.
\]
Every output datum is obtained by the displayed finite modulus calls, rational endpoint operations, and primitive recursion over displayed integer bounds.  There is no unbounded search, \(\operatorname{Classical.choose}\), proof-selected \(\operatorname{Nat.find}\), exact-real inspection, or query to \(M\), \(\eta\), or its law.
